## アクセシビリティ注記

- **JS 無効**: 13人の一覧・年表・数字は HTML に静的埋め込みのためすべて見える。CSS に隠し状態を置かない方針のため、GSAP の対象も JS が隠す前は可視。CDN 不達でも同じく全表示
- **prefers-reduced-motion**: scenes.js が全停止。単語リビールと shimmer は CSS のメディアクエリでも停止（二重安全）。絞り込みは機能し続ける
- **aria**: SplitText 後の h1 には元文の `aria-label` を設定。単語 span は `aria-hidden`＋親に元文の aria-label。カウンターの演出中の数字は `aria-hidden`＋sr-only に完成値。絞り込みの結果行は `aria-live="polite"`、チップは `aria-pressed`
- **CDN**: GSAP 3.13.0（gsap.min.js・ScrollTrigger.min.js・SplitText.min.js）／anime.js 3.2.2（lib/anime.min.js）— いずれも MIT・バージョン固定。フッターに読み込み表記あり
- **転載**: ICS MEDIA 等からの転載なし。shimmer・hover など外部パターンはすべて自作再現
