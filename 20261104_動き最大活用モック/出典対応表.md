## アクセシビリティ注記（最大構成でも固定した点）

- **JS 無効**: 13人の一覧・年表・数字は HTML に静的埋め込み（実データ転記）のため全て見える。幕・カーソル・隠し状態は `.js-armed` / `.is-live` / `.cursor-on` が付かないため出現しない。カウンターも初期値が最終値
- **prefers-reduced-motion**: `@view-transition { navigation: none }`・幕とカーソルの非表示・scroll-driven と shimmer の停止・scenes.js の全停止（表示は崩さない）。style.css 側の smooth scroll も停止
- **カーソル**: `cursor: none` は JS が動作し `pointer: fine` のときのみ。kbd 操作・SR には影響しない
- **aria**: 絞り込みの結果行は `aria-live="polite"`、装飾 SVG・幕・カーソルは `aria-hidden`、チップは `aria-pressed`
- **遷移の二重化の回避**: `@view-transition` を chara/detail のみに分離（`css/vt.css`）し、index 発は筆ワイプ、chara ↔ detail は共有要素遷移、という役割分担にしている
- **CDN**: GSAP 3.13.0・anime.js 3.2.2（いずれも MIT）。ICS MEDIA 等の All Rights Reserved 源からの転載なし（パターンの自作再現のみ）

## 未検討事項の採否記録（追記2・2026-11-04）

参照調査で挙がった未検討ギャップのうち、本モックで採用した2件（#29 spring カーソル→#13／#8 円形リビール→#14）以外は、検討のうえ不採用とした:

- **燃焼遷移** — canvas マスクは重量が大きく、筆ワイプ幕が同機能を担う
- **横型タイムライン** — 縦型年表＋scroll-driven 縦線が同機能を担い、横型は出来事9件の重複になる
- **stagger random** — edges を採用（対応表 #8 のとおり、資料館の秩序として端から中央）
- **typewriter** — chars リビールと同系で読みが遅くなる
- **scale 入口系** — 出現は y＋opacity に統一（立ち上がりの方向を一貫）
- **スクロール単語リビール** — pin＋scrub の行マスク語りが同系
- **Anime.js v3 timeline API** — GSAP timeline で代替（ライブラリ混在を避ける）
- **WebGL・3D** — 素材なし・重量
- **動画ヒーロー** — 動画素材なし
- **絵本型めくり** — 3画面構成と不整合
- **Linear 型 UI モックアニメ** — 機能のないモックでは演出として空虚
- **TANE-be** — 実装要素でなく AI 実装プロンプトの依頼形式（手法は chars/reveal/縮退設計で充足）
- **VT Pagination** — ビュー切り替え型のページ送りで、3画面 MPA には適用対象が存在しない（SPA 化・ビュー切り替え UI を作るときに再検討）
