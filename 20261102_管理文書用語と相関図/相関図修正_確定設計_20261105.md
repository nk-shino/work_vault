## 2. 検証基準

1. **図形変更の合否**: collision_check の5分類(a重なり·b交差·cラベル·dラベル枠余裕·e印刷範囲)で **GRAND TOTAL 0** を必須とする。端点の TOUCH=2.0pt 許容内の接触のみ例外。中期横断は許容しない。(a)の重なり判定は**実描画子矩形基準**とする(エントリ43で確定): ノードのグループ bbox はタグ飛び出しを含む空虚包絡のため bbox 同士の重なりを衝突とみなさず、グループは子図形(box·txt·icon·tag)の矩形群で判定する。根拠: e05_l×n08 の虚検出(実描画間の離隔2.97ptを視覚cropで確認)。
2. **寸法·位置変更の裁定**: アプリ計測(boundW 余裕)は根拠にしない。**PDF 往復照合**(シート個別出力→テキスト抽出→旧stashとの行一致)で裁定する。アプリ計測と ExportAsFixedFormat の文字幅は一致しない(ERR-20261105-005)。なお Excel の Save 後に PDF を出力すると**テキスト抽出順(ストリーム順)のみが変化**する(視覚は同一·エントリ43で実証)。行単位照合は**座標正規化(ページ座標ソート)と行集合の一致の二重判定**で行い、抽出順の差を差分と誤認しない。
3. **checker の複製**: 入力先·live COM 読み取り先·参照ファイルを全て明示差し替える。drift は「意図した変更数」と照合して一致した時だけ有効と判定する。
4. **drift の意味**: drift=0 は「意図変更なしまたは適用済み」。意図変更を行った後は drift=意図変更数であることを確認してから 0 に戻す。
5. **SHA の正手法**: メディア照合のハッシュは **SHA-256 先頭16桁**(`a1_sha.py` と同一手法)で計算する。MD5 等の別手法で算出した記載値は照合に使わない(エントリ43の fix34_backup.py 初版での MD5 誤用を教訓に、記載値との照合は実物の再計算で行う)。

## 3. Excel COM 手続

- 短命インスタンス(DispatchEx)·Visible=False·DisplayAlerts=False·上書き保存(形式維持)·Save後に Close。
- `wb.AutoSaveOn` はローカルファイルで −2146827284 例外(AutoSave は OneDrive 配下のみ有効)のため try/except で包む。
- Shape.Flip の MsoFlipCmd は 0 基底(0=水平·1=垂直)。反転解除は flip 属性でなく矢頭の付け替えが確実。
- Range.Replace は禁止。セル値の変更は 0 件とする。
- プロセス終了は PID 特定後の PID 指定のみ。孤立 automation Excel は CommandLine(/automation)·CreationDate で特定する。

## 4. 冊PDF 再生成手続

- 確定手順のみ: シート個別出力 + `pypdf` 結合。LNB は cred頁2頁(28-29)を TEMP 副本上で相関図_old 非表示の冊出力からスポット抽出。
- ワークブック一括出力は描画が一致しないため使わない(①頁の縮尺差·切れ文字差)。
- ExportAsFixedFormat は OneDrive 配下パスの直接指定で失敗する(−2146827284)。ローカル TEMP 出力後に反映する。
- 再生成後の合格条件: 頁数(Pana 49/LNB 31)·①頁テキスト旧 stash 完全一致·③頁テキスト同一·②頁の EE 行stash一致·相関図_old 漏出 0(LNB)。

## 5. バックアップ手続

- バックアップ作成は**新規名(目的+時刻)のみ**。既存名の再利用(上書き)は禁止する(ERR-20261105-002)。
- 作成直後に内容 SHA16 を期待値(適用前)と照合してから作業へ進む。
- ファイル状態の判定は実物のプローブ(幾何照合·COM読み取り)で行い、記録や要約の SHA 文字列を根拠にしない。
- delta 加算型スクリプトの再実行前に適用済み判定(probe)を必須とする。
- **メディア SHA 照合の正基準は直近の適用前スナップショット `stash2_20261105`(エントリ43適用前の4成果物)とする**(エントリ43で更新)。一つ前の基準「相関図23前_20261105」はエントリ42までの状態であり、エントリ43以降の差分の年代特定用にのみ使う。G10前基準は過去エントリの意図変更(image2.png の差し替えなど)を含むため、さらに古い差分の年代特定用にのみ使う。
