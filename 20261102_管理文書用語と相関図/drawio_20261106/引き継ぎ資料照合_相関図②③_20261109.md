# 引き継ぎ資料と相関図②③の照合記録(2026-11-09)

## 1. 目的

相関図②③(両管理手順書のPanaCIM環境図·ライン設備図)の記載内容を、前任者引継ぎ資料と突き合わせ、記載の裏付けと追加できる情報を確実度付きで整理する。本記録は採用候補の起案であり、図面への反映はGate2(合同目視)の判断を待つ。

## 2. 照合の方法と範囲

- 対象資料: `workvault-sync\09_佐藤さん引継ぎ\佐藤(勇)\引き継ぎ資料.xlsx`(13シート)
- 読み取り範囲: 次の11シート。メモ / PC必須設定 / タスク一覧 / Pana-CIM EGPro関連 / 各種システム一覧 / nksv1359 / よくある不具合 / ユーザー登録関係 / 共有Excelリセット方法 / Job割り込み手順 / 昔の不具合対応メモ
- 読み取らなかったシート: [各種ログイン情報](4)·[PowerQuery認証設定](10)。認証情報を含むため、存在の確認のみを行った
- 方法: Excel COM(読み取り専用)でセル値を取得。相関図側の図形テキストは、編集冊(TEMP配下)の内部XML(xl/drawings/drawingN.xml)を直接読んで取得した
- 判定記号: **A**=一致·裏付け / **B**=傍証(直接一致ではない) / **C**=新規情報 / **D**=引き継ぎ資料に記載なし(矛盾はなし)
