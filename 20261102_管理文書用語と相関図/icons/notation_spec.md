# 相関図 注記線 表記仕様(notation_spec)

- 対象: Pana-CIM/LNB 管理手順書の相関図(Stage 5·白地·A4横·FitToPages 1×1·約85%縮小印刷)
- 前提: 遠隔ラベル10枚(逸脱D5·S2実測38〜499pt)と、未描画エッジE11(逸脱D4)への対応。注記線の追加と交差数の増加はユーザー承認済み
- スコープ: 表記仕様の確定まで。座標·経路の幾何確定と図形追加の実装は別レーンが行う
- 参照: corr_pana_15_resolution_report.md·corr_lnb_resolution_report.md(2026-11-02時点)

## 1. 線の仕様

| 項目 | 規定 |
|---|---|
| 線種 | 点線(Excel: 角丸ドット msoLineRoundDot) |
| 色 | #595959(中グレー·新色は導入しない) |
| 太さ | 0.5pt(既存エッジ1ptの半分) |
| 矢頭 | なし(両端とも) |
| 終端マーカー | 対象端のみ実円·直径2.25pt(#595959·枠なし·直線とは別図形) |
| 形状 | 原則直線。帯見出し·ラベル群を避けるための折れは1回まで。2回以上の迂回は対象外とする |
| 両端の処理 | ラベル端は無印。ラベル文字inkの近い辺から2pt離して開始。対象端は対象から2pt離した位置に終端マーカーを置く |

ラベル端と対象端の役割の対応: 線は「ラベル→対象」の一方向の参照を示すが、矢頭では向きを主張せず、対象端の実円だけが参照先を示す。

## 2. 判断理由(白黒印刷での区別)

既存の線と注記線の区別は、線種·太さ·終端の3点で手がかりを重ねて担保する。

- 実線(濃色·1pt·確定接続)との区別: 連続と点の差に加え、太さが半分である。85%縮小後も実線は連続帯として視認でき、点線は途切れた細線として区別できる
- グレー破線(1pt·推定接続)との区別: 破線は一定長のダッシュ区間の反復であり、点線は点の連続である。縮小後もダッシュとドットの差は残る。太さ差(0.5pt/1pt)と矢頭の有無(推定エッジの一部は矢頭あり)も手がかりになる
- 破線帯(ネットワーク帯)との区別: 帯は領域を囲む太い破線であり、注記線は細い点線が帯を横切るだけである。構造上混同しない
- 採用しなかった案: 細い実線は「実線=確定」の体系を壊すため不採用。一点鎖線は中心線·基準線の連想があり接続と誤読される恐れがあるため不採用。新色の導入は既存の視覚言語を広げすぎるため不採用
- 色の扱い: #595959 は既存のグレー階調の内側にある。既存エッジの実測色との近さは実装時に読み戻して確認し、近い場合も線種と太さの差で区別を維持する

## 3. 凡例への追記文案

凡例本体は Stage 6 で再計画中(旧凡例帯は東ラベルに占有済み)。前置き部の凡例行に次の1文を追加する。既存の「実線=確定/グレー破線=推定(未確認)」の形式に合わせた。

## 4. 対象の見極め方針

**原則: 遠隔ラベル10枚(D5: E02/E05/E06/E07/E10/E13/E14/E15/E16/E18)はすべて注記対象とする。** 対象エッジは機械権威(ENDPOINTS/ROUTES)で一意に確定済みであり、ラベルの意味は自エッジの説明である。

見送り基準(次のいずれかに該当する場合は見送り·理由を逸脱台帳に記録する):

1. 対象が一意に確定しない(今回の10枚は該当なし)
2. 直進または1回の折れで経路が成立しない(ノード内部の貫通·帯見出し文字inkの横断·ラベル群の連続横断が必要になる)
3. 横断距離が長く交差の増加が過大である(目安: 距離300pt超)

初期判定(S2の実測距離に基づく。最終確定は実装レーンの幾何判定):

| 判定 | ラベル(距離) |
|---|---|
| 引く | E13(38pt)/E06(122pt)/E02(146pt)/E07(159pt)/E18(200pt)/E10(250pt)/E14(268pt) |
| 幾何判定で確定(長距離のため経路成立を要確認) | E16(319pt)/E05(352pt)/E15(499pt) |

**E11(未描画エッジ「表示内容はPana-CIM由来?」)は注記対象外とする。** 理由:

- E11はラベルも未配置(D4·ラベル用スロットなし)であり、注記線の前提である「既存ラベルと対象の対応付け」が成立しない
- E11の意味は起点変更P-1(E09起点N02→N03)や会議確認事項X02-①と連動している。注記線を本来のエッジ位置に引くと接続経路として読まれ、確定(実線)でも推定(グレー破線)でもない線が接続を主張する状態が生じる
- E11を図へ復活させる場合は注記線ではなくエッジ本来の線種(確定なら実線·推定ならグレー破線)で描く別案件とし、会議確認後に処理する

## 5. 実装への注意(Excel図形)

- 追加方式: 既存エッジと同じ作図方式(フリーフォーム直線)で1線1図形とする。図形名は AN01〜 の接頭辞(既存のE##/N##/band_*と衝突しない)。終端マーカーは楕円図形を別に追加する(直線の終端スタイルに楕円はない)
- アンカー: ラベル側は不可視ラベル箱ではなく文字inkの近い辺+2pt。対象側は対象エッジの端点またはエッジ上の近傍点+2pt。対象をノード縁とする場合は縁の外側2pt(ノード内部に入れない)
- 避けること: 既存エッジとの2pt未満の併走·帯見出し文字inkの横断·ノード内部の貫通·ラベル文字inkとの2pt未満の接触·帯境界線上の併走。既存エッジとの直交交差は承認済みであり可
- 注記線が複数本同じレーンを通る場合はy座標を2pt以上ずらす(東ラベル列からの横断線の集中を分散させる)
- validator: 注記線は新集合(AN)として登録し、既存の交差期待値10件とA0〜A8の判定は変更しない。注記線用の検査(注記線同士·注記線×ラベルinkの2pt規則など)を別途追加する
- グリッド·印刷: 図形はセルグリッドに追従する(move-and-size)ため、列幅2.0字·行高7.7ptは変更しない。印刷プレビュー(FitToPages 1×1·約85%)で点線の視認と4者(実線/グレー破線/破線帯/細点線)の区別を確認する。視認が不足する場合は0.75ptへ上げ、変更を逸脱記録する
- アンカー点·経路の具体的座標は、幾何権威(corr_pana_14_result.json·tables.py)とvalidatorを用いて実装レーンが確定する
