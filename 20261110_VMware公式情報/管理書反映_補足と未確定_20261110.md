- 外部監視の経路、ログ転送の要否。
- ハードウェアファームウェアの基線の固定(PCI 21 項目・パッケージ 152 項目はキャプチャ時点の件数)。

## 3. 管理形態と前提

- キャプチャは Host Client(`https://172.25.253.45/ui/`)への root ログインで取得されており、vCenter の画面は含まれない。**単独ホスト運用と推定しているが、vCenter の有無は未確認。**
- 管理書 §4-3-1 の「vCenter 管理下では vCenter を先に更新」は公式手順の一般論として残した。単独ホストの場合、この記述は適用外。
- ロックダウンモード、HA、DRS、vMotion、分散スイッチは vCenter 依存のため §4-3-7 で対象外とした。単独ホストの確定を前提にした記述ではない。

## 4. バージョンの食い違い

- 2026-11-09 のキャプチャはビルド 8169922(6.7 GA、2018-04-17)を示す。現行はビルド 17167734(6.7 P04、2020-11-19)。キャプチャは 2020-12-23 の導入直後の状態で、その後 P04 が適用されたとみられる。
- キャプチャの件数(PCI 21、パッケージ 152、詳細設定 1092、データストア 4.36TB)は 2020-12-23 時点の値。現行値は CLI で再取得が必要。
- マッピング(2026-11-09)の「ビルド8169922=6.7 U3系」は誤り。8169922 は 6.7 GA。6.7 U3 は 14320388。マッピングに訂正注記を追加した(2026-11-10)。
