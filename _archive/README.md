# _archive — 完了トピックの退避先

- ワークスペース直下の `YYYYMMDD_<topic>/` は、稼働中のトピックだけを残し、完了したものを月別に退避する
- 配置規則: `_archive/YYYYMM/YYYYMMDD_<topic>/`
- 退避は移動のみで行い、ファイルの内容は変更していない。各トピックの実行ログはフォルダ内にある
