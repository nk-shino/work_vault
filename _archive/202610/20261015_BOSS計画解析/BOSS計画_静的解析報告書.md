# 5. 検出した不整合

boss_deep.txt から、次の 3 点を確認した。

## 5.1 サイクルタイム重複 typeID 3 件

サイクルタイムシート (1,269 行) で、同一 typeID が複数行に登録されているのは次の 3 件である。値は evidence の記録値のまま示す。

| typeID | 行位置 | 1枚あたり平均サイクルタイム (列D) |
|---|---|---|
| URS-4558 | r2 / r972 | 106 / 99.057999999999993 |
| URS-4559 | r3 / r973 | 212 / 80.124400000000009 |
| UR-0610-03 | r4 / r428 | 46.963999999999999 / 47.640166666666666 |

容量計算シート I1 には「警告:複数サイクルタイムがあります｡上の行が優先されます｡」の記載がある (sheets_detail.txt)。この仕様では上方の行 (r2 / r3 / r4) の値が採用される。重複自体はデータとして残るため、意図しない値の採用がないかの確認対象になり得る。

## 5.2 基準終了日が基準開始日より前の行: 16 行

BOSS シートで基準終了日が基準開始日より前の行が 16 行ある。対象行の指図番号一覧は evidence に記録されていない。

## 5.3 祝日データの最終日が 2026-12-31

祝日シートは 71 件で、範囲は 2023-11-23 ～ 2026-12-31 である (keys_check.txt)。解析日 (2026-10-15) 以降に含まれる祝日は 5 件で、2027-01-01 以降の祝日は未登録である。メールシートは WORKDAY 関数に祝日一覧を渡して営業日を算出している (formulas_detail.txt)。2027 年以降の日付では休日の除外が働かない可能性があるが、これは推定として区別する。

## 5.4 その他の確認結果

- グループシート: グループ名の重複 5 件 (keys_check.txt)。同一品目が複数行に現れるケースは 0。
- 準備工数シート: #N/A が 6,802 セル、エラーを含む行は 179 行 (formulas_detail.txt)。
