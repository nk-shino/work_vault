## 指示6

- **指示:** 「mobbinを使用して、より良いUIを検討します。」
- **実施:**
  1. セッションに mobbin のツールが読み込まれていないことを確認。エンドポイントへ curl で初期化要求 → **401（Bearer 必須）**。Mobbin ドキュメント確認 → MCP は **OAuth（ブラウザ認証）・Pro/Team/Enterprise プラン限定**。Kohden Code の社内ドキュメント上、remote MCP は headers 認証のみで OAuth ブラウザフローに非対応と判断
  2. 対策として OAuth を代行するローカルブリッジ **mcp-remote 0.15.2** を採用し、opencode.json の mobbin を remote から local（`npx -y mcp-remote@0.15.2 https://api.mobbin.com/mcp --transport http-only`）に変更。トークンは `~/.mcp-auth` にキャッシュされ更新も自動
  3. 検討作業自体はツール接続後に開始（画面の自然言語検索 → 用語集アプリのUIに適用するパターン抽出）
- **成果物:** opencode.json の mobbin 設定変更
- **状態:** 設定完了。**再起動 → 初回接続時にブラウザで Mobbin へのログインと認可**（Pro プランの契約が必要）ができればツールが使える
