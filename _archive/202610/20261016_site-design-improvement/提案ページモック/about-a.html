このサイトについて

閲覧に先立って知っておくべきことを、定義の形でまとめる。badge の意味はここが唯一の正式な場所。

1. サイトの位置づけ

ある音楽プロジェクトの非公式資料サイト。公式の資料ではない。掲載する数値・題・日付は模擬データであり、実在の作品・人物とは無関係である。

2. 検証状態の定義

確認済
日付のある出典に当たり、記載と一致を確認した。
要補足
出典に当たったが、日付や一部の記載が不足していて補いが必要。
未検証
出典照合をまだ行っていない。黙って混ぜないために状態をそのまま示す。
出典なし
現時点で根拠になる出典が存在しない。作品本文からの記録待ち。
日付なし
出典に日付の記載が無い。空欄とせず、そのまま明示する。

3. IDの運用

目録の ID（W-001・E-005 など）は資料からの参照に固定する。題を直しても ID は動かない。出典の ID（s01-001 など）も同様に固定で、照合の内訳はこの ID で開示する。

4. データの原典

表示は data/ 配下の JSON を唯一の原典にする。頁ごとに手で写した値は置かない。更新はデータの更新のみで行い、確認の跡は検証の記録に残す。
