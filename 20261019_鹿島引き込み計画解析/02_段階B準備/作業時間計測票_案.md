# 段階B 作業時間計測票(案) — 実測が必要な項目の測定設計

- 作成日: 2026-10-19 ／ 原則: 現場計測の**前に実績データ分析を優先**(PanaCIM/MySQLに既存実績があるため)。実績で埋まらない部分のみ現場計測とする
- 制約: 計測は現場の協力が前提。この票は提案であり、実施には現場・担当者の合意が必要

## 1. 計測が必要になる理由(未記録情報)

| 項目 | 現状(仮定) | 実測で確定させること |
|---|---|---|
| CT代替値(量産56秒/試作75秒) | コード埋込の仮値。実態との差不明 | CT未登録品目の実際の1台当たり時間 |
| 段取600秒/指図 | 固定値。品目・ライン差の有無不明 | 段取の実分布(ロット・品目・担当別) |
| H-09 占有時間の定義 | 「SMTライン占有時間」の中身が口頭のみ | 段取・生産・停止・待ちの区分時間 |
| 1.4倍CT | 現場判断で適用済み。根拠実測なし | 引き込み品目の実測CTとの比較(将来) |

## 2. 実績データ分析(現場計測の代替として最優先)

| データ | 所在 | 抽出内容 | 制約 |
|---|---|---|---|
| PanaCIM実績 | 実装機のみ(リフロー除外)・E-04 | 生産開始〜終了の機械時間・指図単位 | アクセス手段未確認(H-09担当者に確認) |
| MySQL QCD.CycleTime_Points | nksv1359 | 品目×面のCT実績(PQ定義と同一条件) | DBアクセス権限未確認 |
| Asprova作業テーブル | ジョブ作成時データテーブル一覧.xlsx(96行サンプル済) | 段取10M/14M17S・X+AA≈AEの精度(84%一致済) | サンプルが小さい→追加抽出候補 |

## 3. 現場計測票(実績で埋まらない場合)

### 測定条件の組合せ(スクリーニング設計)

- 品目: ①CT登録あり×量産 ②CT登録なし(代替値対象)×量産 ③試作品目 — 各最低1品目
- ライン: L1・L3(両方が動ける品目のみ2ライン比較)
- ロット: 小(<300台)・中(300〜1000)・大(>1000) — 各最低1ロット
- 担当者: 熟練者1名・標準1名(同一条件を2名で)
- 面: 片面/両面品目を区別して記録

### サンプル数の提案

- 各条件最低**3回×3日**(日違いでばらつきを確認)。計28〜30測定点/品目
- 初期は1品目×1ラインでパイロット計測し、ばらつき(変動係数)が大きければサンプルを増やす

### 記録様式(1測定=1行)

| 列 | 内容 |
|---|---|
| 測定日・時刻 | 開始/終了の実時刻 |
| 品目/指図番号 | BOSS指図と突合可能な形 |
| ライン/装置 | L1 or L3・機種 |
| 担当者 | 熟練/標準の区分 |
| ロット台数 | 数量 |
| 段取時間 | 準備開始→生産開始(分) |
| 生産時間 | 生産開始→完了(分) |
| 停止/待ち | 発生時間と理由 |
| 備考 | 異常・手直し等 |

### 記録ルール

- 実測値と推定値を混ぜない。中断した測定は「中断」と記録し破棄しない
- 計測者・確認者を各行に記録。集計は別シートで行い、元測定値を修正しない
