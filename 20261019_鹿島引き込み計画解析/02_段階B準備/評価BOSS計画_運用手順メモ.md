## 2. 手順としての再構成(計画調整フロー)

| Step | 操作 | 基準・ルール |
|---|---|---|
| 1. 調整要否の判定 | ①負荷が「-」表示の日があれば調整する ②右側のPowerBIリストで赤線を超える日があれば調整する | 「-」=負荷なし日の表示と推定(H-18で定義確認) |
| 2. まとめ方 | 同じ色でまとまるように可能な限りする。色別で同じ日にまとめる | 「色」の定義(グループ名色分け?)はH-19 |
| 3. 対象日設定 | **容量計算シートのG2に調整したい日付を入力→実行ボタン** | G2=exp-5で「隠れ引数」と指摘したSheet_Cal2!G2(782行読取↔1297行書込) |
| 4. 生産時間の確認 | 希望日の生産時間を**容量計算のB列**で確認する | **算出方法は調査対象**(どの列を合算し準備工数を含むか:H-20) |
| 5. 品目割当 | **フリー・試作の品目を選択し「選択して実行」ボタン** | 基準: **フリー・試作とも空きスロットが10以上あること** |
| 6. 除外 | 外すときは**「選択したもの効率計算」ボタン** | 効率計算=Cal_Fee系と対応(exp-5: 選択セル収集I4/I6/I8→N/O列出力) |
| 7. 再調整 | 選択し直して「選択して実行」。**一番上のものを除外する相談を行う。S付属品目を優先して除外する** | 除外優先度の業務ルール |
| 8. 確定 | **カスタム設定シートで仮置き場に登録→「計算」シートのマクロ実行ボタン** | カスタム設定=Sheet_Custom(仮置き場の列位置はH-19) |

## 4. 新たに判明した業務ルール(前提条件台帳P-29〜P-34へ登録)

1. 調整トリガ: 「-」日・PowerBI赤線超過日の2条件(+色まとめの任意条件)
2. 空きスロット基準: フリー・試作とも10以上
3. 除外優先度: 一番上のものを除外する相談 → **S付属品目を優先して除外**
4. 確定フロー: カスタム設定の仮置き場登録 → 計算シートMain実行(=P-20の日次更新とは別の手動調整経路)

## 5. リファクタリング・再設計への含意(リスト反映)

- 調整フローが**手作業+4ボタン+シート往復**で構成(G2入力→実行→B列確認→選択→実行→除外→効率計算→カスタム設定→計算)。新ツールでは Step3-8 を1フローに統合する候補(確実性優先)
- 「一番上を除外する相談」は判定が人手 → S付属品目優先除外を**自動提案**にできる(効率)
- 右側PowerBIリストの参照は F-01(稼働計画_生産管理共有用PBIX・DatasetId 3eac4238…)との連携設計が必要 — 赤線=容量基準線の定義はH-18
- Cal_Fee_btnがアクティブシート前提で動く(exp-5 高)ことと、このフローで頻用されることの組合せは操作リスク → 改修提案の優先度根拠になる
