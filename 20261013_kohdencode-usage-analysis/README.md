# Kohden Code 利用者分析 — データ収集計画

作成日: 2026-10-13
目的: 年齢層 / 時間帯 / 所属部署 / 利用用途 / 処理時間の 5 軸でグラフ付き分析レポートを作る

## 0. 現時点で判明していること（ドキュメント調査: 事実）

- 利用ログは社内（Azure Application Insights）で取得されている → [セキュリティと制限](https://gai-appdocs.dokploy.nihonkohden.biz/developers/kohden-code/security)
- ログの直接閲覧は運用チームのみ。一般社員向けは「利用状況確認 Power BI レポート」（nk365）と「生成AI 利用状況」ページ（litellm-budget）
- アプリ識別ヘッダー `X-GAI-App-Name` / `X-GAI-App-Feature` は今後 Power BI レポートに反映予定 → 利用用途の分析軸になる
- 年齢層は利用者識別が Entra ID / API キー単位のため、現状データとして存在しない可能性が高い
- 混雑状況ダッシュボードは未公開（公開検討中）

## 1. データソース候補と入手方法

| # | データソース | 取得できる軸 | 入手方法 | 入手可否メモ |
|---|---|---|---|---|
| 1 | 利用状況確認 Power BI レポート | アプリ別・期間別の利用量 | nk365 GAI ポータル → エクスポート（CSV） | 一般社員も閲覧可。エクスポート可否は要確認 |
| 2 | 生成AI 利用状況ページ (litellm-budget) | ユーザー別利用額・上限・リセット時刻 | https://litellm-budget.dokploy.nihonkohden.biz/ | 自分の分は見える。全員分は運用チーム |
| 3 | Application Insights 生ログ | 時間帯 / レイテンシ / モデル別 / ヘッダー別 | 運用チーム（AI戦略・デジタルイノベーション推進課）に KQL クエリ実行を依頼 | 一般社員は直接閲覧不可 |
| 4 | LEAP 受講者データ | 年齢層の代理（受講者属性） | LEAP 管理者に依頼 | 個人情報の扱いに注意。集計値のみで依頼する |

## 2. 運用チームへの依頼内容（たたき台）

依頼先: 経営戦略統括部 経営戦略部 AI戦略・デジタルイノベーション推進課

依頼する集計（個人を特定しない集計値のみ）:

1. **時間帯別**: Kohden Code（クライアントアプリ識別）の API 呼び出しを 1 時間単位で集計したヒストグラム（平日/土日別だとさらに良い）
2. **部署別**: 利用ユーザーの Entra ID 属性（部署コード）別の月次利用量上位 10 部署
3. **利用用途別**: `X-GAI-App-Feature` / セッション数の用途内訳（取得できない場合は代替案: FAQ・問い合わせカテゴリ別件数）
4. **処理時間別**: モデル別の p50 / p95 レイテンシと、コンテキスト圧縮発生回数
5. **規模**: MAU / WAU / DAU の推移

依頼時の注意: 生成AIガイドラインに沿い、個人が特定できる生ログではなく集計値で受け取る。

## 3. 受領後の作業（このフォルダで実施）

1. CSV を `data/` に置く
2. `analysis.ipynb` または Python スクリプトで集計・可視化（matplotlib, 日本語フォント対応）
3. グラフ付きレポート（Markdown or HTML）をこのフォルダに作成
4. 傾向・課題（FAQ ベースの定性分析は本日の調査で済み）と突き合わせて解釈
