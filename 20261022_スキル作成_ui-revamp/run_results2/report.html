ui-revamp — Skill Description Optimization

Optimizing your skill's description. This page updates automatically as Kohden Code tests different versions of your skill's description. Each row is an iteration — a new description attempt. The columns show test queries: green checkmarks mean the skill triggered correctly (or correctly didn't trigger), red crosses mean it got it wrong. The "Train" score shows performance on queries used to improve the description; the "Test" score shows performance on held-out queries the optimizer hasn't seen. When it's done, Kohden Code will apply the best-performing description to your skill.
