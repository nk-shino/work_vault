## アクセシビリティ注記

- **JS 無効**: 13人の一覧・年表・数字は HTML に静的埋め込みのためすべて見える。出現まち・typewriter の隠し状態は `.js-armed` 配下のみで、JS がない環境では付かない。scroll-driven の4種は CSS のみで機能し、未対応環境では完成形の静止表示
- **prefers-reduced-motion**: js-armed を付けないため出現まち・typewriter・カウンターは発火しない。scroll-driven と caret は CSS のメディアクエリで停止（二重安全）。絞り込みは機能し続ける
- **aria**: typewriter は完成文を `aria-label` と sr-only に退避し、視覚の 1 字ずつの span は `aria-hidden`。カウンターの演出中の数字は `aria-hidden`＋sr-only に完成値。絞り込みの結果行は `aria-live="polite"`、チップは `aria-pressed`
- **フォーカス**: `:focus-visible` に朱の輪郭。hover と同じ枠の変化を受け取れる
- **CDN**: なし（外部リクエスト 0件）。Web フォントも読まない（システムの明朝にフォールバック）
- **転載**: ICS MEDIA 等からの転載なし。全パターン自作
