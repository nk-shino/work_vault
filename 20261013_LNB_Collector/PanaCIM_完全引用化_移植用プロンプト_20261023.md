対象セッションに丸ごと貼り付けて使う。経緯・仕様・最終セル値・検証基準をすべて含む。

## 4. 対象ファイルを扱うときの絶対規則(ボタン・マクロ保護)

1. 編集前に `wb.SaveCopyAs` またはファイルコピーでバックアップを作る。
2. 既存のボタン・マクロ・図形・入力規則・条件付き書式を削除しない。`ws.Shapes.Count` を編集前に記録し、編集後は「記録値+新規作成分」で一致させる。
3. セル位置は本プロンプトの値をそのまま仮定しない。対象シートで「PanaCIM」「再起動」「Route Editer」等のキーワード検索と、書き込み予定範囲の空き確認(Range.Value が空か)を行ってから決める。§5の行番号(案での位置)は参考実装として示す。
4. フローチャートの描画領域が既存ボタンと重なる場合は、描画開始行(y0)を下げて回避する。重なり確認は PDF→PNG 描画で目視する。
5. OneDrive上のファイルは `wb.AutoSaveOn = False` を最初に設定する(設定しないと部分保存でロックや破損の原因になる)。COM操作は try/finally で Quit を保証し、失敗時はリトライする。リトライでプロセスが残ったら `Get-CimInstance Win32_Process -Filter "Name='EXCEL.EXE'"` で CommandLine を確認し、`/automation -Embedding` のプロセスだけを PID 指定で終了する。ユーザーが開いているExcel(MainWindowTitleあり)は終了しない。
6. 保存前に文字列検証(§7)を実施し、合格後のみ保存する。

### 7.1 様式(参照元の仕様)

- 参照元: `0494-913473 実装プログラム手順(DGS)` のネイティブ図形フローチャート。
- 処理箱: 塗り #0070C0(COMへはBGRで 0x00C07000)、文字白。開始/終端: 同色・白文字。矢印・枠線: 黒・太さ1.0・終端矢印。判断: **白塗り**・黒文字。
- フォント: HG丸ｺﾞｼｯｸM-PRO(半角カタカナの「ｺﾞｼｯｸ」)。**「HG丸丸丸丸ｺﾞｼｯｸM-PRO」のように丸が二重になる誤記をしない**(正=HG丸+半角カタカナ)(本実装で一度やったタイポ)。処理箱9.5pt、Continue箱8.5pt、判断8.0pt、はい7.5pt、いいえ8.0pt。

### 7.4 実装上の制約(描画検査で判明した落とし穴。順守必須)

1. **ノード文言は全角10字/行まで、2行まで**。nodeW=114ptの内側は約100ptで、9.5ptのHG丸ゴシックは約10全角字。行高はフォントサイズの約1.7倍なので、40ptの箱に入るのは2行まで。3行目は表示されずに切れる(エラーにならない)。
2. **ダイヤ(63)の文字領域は内接矩形(幅・高さとも半分)**。シェープ自身にテキストを入れると1行も入らず切れる。解決: ダイヤは白塗りの空シェープにし、文字は**枠なし・塗りなしのテキストボックスで重ね置き**する。
3. **テキストボックスの既定余白は左右7.2pt**。小さいラベル(はい/いいえ等)では MarginLeft/MarginRight/MarginTop/MarginBottom = 0 を必ず設定する(しないと「はい」が欠ける)。
4. **矢印の向きは座標の並びで決まる**。BeginArrowhead ではなく EndArrowheadStyle=2 を使う前提で、矢印の根元→先の順に(x1,y1)→(x2,y2)を渡す。右から左へ向く矢印は x2 < x1 で描く。
5. 図形名を付ける(fc_L1〜fc_L6, fc_R7〜fc_R13, fc_dia, fc_14, fc_side, fc_start, fc_end 等)。再実行時は同名を削除してから作り直す(冪等)。
6. 描画後は `ws.Shapes.Count` が「編集前記録値+42」であることを確認する。
7. **Continue合流コネクタの向き**: 根元=Continue降下線の下端(fc_side中心x, y14+nodeH/2)、矢先=手順14の右辺(x2<x1で描く)。逆向き(根元=手順14右辺・矢先=合流点)に描くと、Continue経路が手順14を迂回してENDに至るように見える(本実装で一度やったミス。全数目視検証で発見・修正記録6)。

## 9. 検証(必須。合格しないまま保存・報告をしない)

### 9.1 文字列突合(保存前)

原票と対象シートを openpyxl で読み、21セル(手順14+注記7)が一致することを確認する。期待差分は伏字2か所のみ。加えて:
- C28が原票B6+C7を**部分文字列として含む**こと。
- 原票D12/D149のパスワード原文字列が、対象ブック全体のどのセルにも残っていないこと(ブック全体を走査)。
- 伏字セルの数が2であること。

```python
# 骨子
import openpyxl, re
src = openpyxl.load_workbook(SRC)["PanaCIM"]   # 原票
dst = openpyxl.load_workbook(TGT)["異常時の対応"]  # 対象
pairs = [("B9","C42"),("B11","C43"),("D12","C44"),("B31","C45"),("B60","C46"),
         ("D61","C47"),("B82","C48"),("D83","C49"),("B114","C50"),("B128","C51"),
         ("D129","C52"),("B148","C53"),("D149","C54"),("D151","C55"),("B169","C56"),
         ("B180","C57"),("B201","C58"),("B223","C59"),("B235","C60"),("D253","C61"),
         ("B277","C62")]
pw = re.findall(r"「([^」]+)」", str(src["D149"].value))  # 動的抽出・出力しない
redact = lambda t: re.sub(r"「[^」]+」", "「［認証情報：伏字］」", str(t))
ok = all((redact(src[s].value) == dst[d].value) if s in ("D12","D149")
         else (src[s].value == dst[d].value) for s, d in pairs)
```

- 原票の行番号(B9/B11/…)は対象環境の原票コピーで確認し、ずれがあれば値で突き合わせる。

### 9.2 描画検査(保存後)

1. 対象シートを `ExportAsFixedFormat(0, pdf)` で出力(シート単体でよい)。
2. PyMuPDF(`fitz`/`pymupdf`)でPNG化する。pdftoppm/ImageMagick が無い環境でも動く。全体は80dpi、細部(突合ブロック・図解)は200dpiのクリップで確認する。
3. 目視確認項目: 手順文が原票どおり(伏字含む)/ノードが2行以内で3行目の切れがない/ダイヤの文言が読める/はい・いいえ・Continue箱が欠けていない/図解が印刷範囲からはみ出ていない/既存ボタンと重なっていない。
