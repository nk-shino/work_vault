## 4. 再実行の手順（Phase 3 で使用）

1. 新しい検証DBのパスを指定してサーバーを起動する。bash のプロセスツリーから切り離すため、WMI で起動する（手順は `.learnings/ERRORS.md` の ERR-20261105-008）
2. register_terms.js、operate_flows.js、check_state.js の順に実行する。書き込みを含む前の2本は1回だけ実行する
3. サーバーを動かしたまま、アプリ直下で import を実行する
   `DATABASE_URL="sqlite:///<検証DB>" GLOSSARY_DATA_DIR="<作業先>" SOURCE_BACKEND=export LLM_BACKEND=mock .venv/Scripts/python.exe tasks.py import "<TOPIC>/検証データ/資料"`
   出力が文字化けする場合は `PYTHONIOENCODING=utf-8` を付ける（未検証）
4. shoot_pages.js（撮影先は `globalThis.__GLOSSARY_ROUND` で切り替える）、queue_flows.js の順に実行する
