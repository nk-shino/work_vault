### 調整記録（イージング最適化・2026-11-05）

- **指示**: HEAD（コミット 3dc8d0a）に対する独立検証の実測に基づき、ワイプ出発の欠陥1件の修正・hover の押し/離しの分離・未使用トークンの削除を行う。幕とフローの duration 全体設計は変更しない。コミットはしない。
- **実施**:
  - **欠陥修正 — ワイプ出発時に幕が画面外から走ってくる**: CSS の `.flow { transform: translateX(-101%) }`（motion.css）が gsap の引き取り時に計算済み行列として px 化されて x に残留し、`gsap.set({ xPercent: -101 })` と二重に効いていた（実測: inline が `translate(-101%,0%) translate(-1292.8px,0px)` の二重化 → 実効 -202%）。出発 tween は xPercent -101→0 のため、tween 完了後も x の残留 -101% が残り、フロー層が画面外のまま — 幕が見えないまま 0.5〜0.63 秒後に page swap していた。修正は `takeOverCurtain` と `wipeNavigate` の両入口で `gsap.set(el, { x: 0, xPercent: ... })` と x を明示して残留を潰す方式。CSS 側の `translateX(-101%)` は JS 無効時の保障として**削除していない**。扉（.door-left / .door-right）も同機構（-102% + xPercent -102 = -204%）だったため同じく x: 0 を明示した（cover 経路では見えない位置での潜在不具合）。
  - hover の押し/離しの分離: 押し込み（:active）のみ transform を 0.12秒に短縮し、離しは既定の 0.18秒。根拠実測 — 押し・離しがともに 133ms で同速だったため、触感として前後差を作った。押し込みの scale 0.98 と曲線は変更なし。
  - トークン衛生: 未使用の CSS トークン `--ease-out-back`（style.css）を削除。出現系の out-back は GSAP の `back.out(1.4)` のみで運用されている（`--ease-in-out-expo` は motion.css で使用中のため温存）。style.css 冒頭の役割分担コメントを現状どおりに更新。
