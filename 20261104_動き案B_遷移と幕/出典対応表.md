# 出典対応表 — 動き案B「遷移と幕」

破棄前提の多様性案。上限案（`20261104_動き最大活用モック`）と同じ体裁・実データで、動きのプロパティ軸と種類軸を系統的に変更する。対照の基準は上限案の実装と、ギャラリー検討時に記録した採用・不採用リスト。

## 規約の踏襲（上限案・実データサンプルと共通）

- 内容は `data/*.json` の実データのみ。HTML に静的に埋め込み、fetch を使わない（noscript でも全内容が表示される）
- 隠し状態は JS（`gsap.set`）だけが作る。CSS 側の出現前の隠しは持たない
- `prefers-reduced-motion` では幕・push-in・進捗を含め全停止（`vt.css` の `@view-transition: none` 含む）
- 幕の取り残し防止: `scenes.js` が 1600ms 以内に起動しなければ状態クラスを解く。GSAP 未達でも起動時に解く
- `prep` 関数は先頭で `HAS_GSAP` を確認する。`playX` は `prepared` フラグを確認する（上限案修正1の教訓）
- ワイプ遷移は `is-live` を付与してから動かす（上限案修正2の教訓）
- `gsap.set` で x を 0・xPercent を明示してから tween する。CSS クラスの `translateX(-101%)` は gsap が計算済み行列として px 化して x に残留させ、xPercent と二重に効く（実測: 出発時に実効 -202% となり、幕が画面外から走ってくる。takeOverCurtain と wipeNavigate の両入口で `x: 0` を明示して修正）

## 選択と集中（本案で見送ったもの）

- カーソル連動（spring カーソル）— 上限案で採用済み。本案では画面の移動に集中するため外す
- shimmer / typewriter / stagger random — ギャラリーで不採用のまま
- 共有要素遷移（`view-transition-name` による題箋の morph）— VT はルートの円弧に集中させるため外す
- pin + scrub の語り・アーチ SVG の線画 — 本案の主題（遷移）と競合するため外す
- stagger — 一覧は群れで一度に立ち上げる（上限案との差別化も兼ねる）
