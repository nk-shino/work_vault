## 採用する指針

### 空状態（Atlassian Empty state / Carbon Empty states）
- 空状態は「タイトル＋（理由と次の操作の短い説明）＋（あれば1つの次アクション）」で書く（Atlassian: Header必須・Description・Buttons）
- データが入ったときに何が表示されるか、追加方法を具体的に書く（Carbon: No data 空状態）
- 検索結果ゼロは User action 型。フィルタ調整の次の手段を示す（Carbon）
- 複数のCTAを置かない。次アクションは1つに絞る（Atlassian Do/Don't、Carbon）
- 空状態は通常表示される要素と置き換える。表の空状態では列ヘッダーを含む表自体を表示しない（Carbon ベストプラクティス）
- 位置は左揃えのブロック（Carbon）

### 状態表示（Carbon Status indicators）
- 色だけで状態を示さない。色＋テキスト（または形状・記号）を組み合わせ、3:1 のコントラストを保つ（WCAG Use of Color を引用）
- 件数が分かる通知には数値入りバッジを使う（Badge indicator with number）。ドットは件数が不明・重要でないときの代替
- 深刻度で色を分ける。赤は危険・エラー、黄は通常の警告、青は情報・進行、灰は下書き・未着手（Status color palette・severity levels）

### タグ（Carbon Tag）
- タグのタイトルは短く（可能なら20字未満）、複数行に折り返さない
- タグはページ内の絞り込みに使える。別ページへの遷移リンクには使わない
- タググループの間隔は 8px 目安

### ボタンと操作（Atlassian Button）
- 1エリアの主CTAは1つにする
- ボタンは操作、リンクは移動に使う（要素を取り違えない）
- 送信ボタンを無効化して黙らせるより、バリデーションとエラー表示で導く（既存実装は required + サーバー側エラーで適合済み）

### フォーカス（Atlassian Focus ring）
- キーボードで操作できる UI すべてに、フォーカス位置が明確に分かるインジケータを表示する

## 採用しない指針（と理由）
- Atlassian Empty state のイラスト（スポットイラスト任意）: 学習用小アプリに絵を足すメリットが薄く、既存の紙風トーンを乱す。テキストのみで構成する
- Carbon のタグ色パレットの多色使い（カテゴリを色で分ける）: 既存のチップ配色変数（明暗両対応）を壊すため。色は既存変数経由のままにする
- Polaris の指針: 取得できず、根拠を示せないため一切採用しない

## 見送りとその理由

| 項目 | 理由 |
|---|---|
| 呼び出し元/先・同名リンクのチップ表記をリンク表記へ変更（Carbon: タグを別ページ遷移に使わない） | 実施済み（2026-10-29 追加実施）。詳細画面の呼び出し関係を `.ref-link`（accent 色・ホバーで下線・余白 10px）へ変更。未解決名の `<span class="chip">` はラベル表示のまま維持。タグ雲はページ内フィルタのため `.chip.link` を維持 |
| 履歴の日時表示を人間可読な形式へ整形 | 根拠となる usage ページを取得していない。今回の根拠収集の範囲外 |
| サイドバー・コマンドパレット等のレイアウト移植 | 部分採用の原則により最初から対象外。単一画面の学習ツールに不要 |
| 空状態へのイラスト追加 | Atlassian で任意要素。既存トーン維持のためテキストのみ |
| 既存の hover モーション・すりガラストップバー・明朝語義の変更 | 既存トーンの維持条件。触らない |

## テストが保護するもの（変更時の制約）

- 全ページ共通: `data-theme="auto"`、`pillnav`、`prefers-reduced-motion`（style.css）
- 文言: プロシージャ名（WaitMain / ImportData / WaitSeconds / ConnectDb）、`第 1 版`、`修正が必要`（見直しページ）、`待ち受け中の提案はありません`（詳細）、`混同注意`、`create` または `解析`（履歴）、ドラフト文が詳細に表示されること
- `dummy-pass-1234` は保留提案ページに現れてはいけない（マスキング維持）
- 件数・セレクタの基準値テストはない。テーブルをブロックに置き換える変更（候補5）はテストに影響しない（行が存在するときの表示は変わらない）
