# 音楽資格 用語集

## 対象資格と範囲

正式名称: MIDI検定 3級（MIDI: Musical Instrument Digital Interface）

主催: 一般社団法人音楽電子事業協会（AMEI）

位置付け: MIDI、デジタル音楽制作、楽典、デジタルオーディオの入門用。MIDI 2.0関連は補足であり、3級の試験細目を全て取得・保証したものではない。

確認時点: 2026-10-01。実施条件は公式サイトで取得できた令和8年度案内の範囲に限って照合した。

## 用語定義

### <a id="term-1"></a>1. MIDI

正式名称: Musical Instrument Digital Interface

意味: 音そのものではなく、演奏操作や音色指定を機器間で交換する通信規格である。受信側の音源や設定によって、同じデータでも音色・音量・表現が変わり得る。

### <a id="term-2"></a>2. MIDIチャンネル

正式名称: MIDI Channel

意味: MIDI 1.0では1本の接続内を16の論理チャンネルに分け、チャンネルボイスメッセージの宛先を指定する。チャンネル10はGMでパーカッション用に割り当てられるが、すべての非GM機器に一般化できない。

### <a id="term-3"></a>3. ノートオン

正式名称: Note On Message

意味: 音符番号とベロシティを指定して発音を開始するチャンネルボイスメッセージである。MIDI 1.0ではデータ値はいずれも7ビットで、通常0から127を取る。

### <a id="term-4"></a>4. ノートオフ

正式名称: Note Off Message

意味: 音符番号に対応する発音を終了させるメッセージで、リリースの開始を受信音源に指示する。ノートオンのベロシティ0もノートオフ相当として扱われるが、実装上は両形式を受け入れる必要がある。

### <a id="term-5"></a>5. ベロシティ

正式名称: Velocity

意味: ノートオン／オフに付く7ビット値で、鍵盤を押す速さなど演奏の強さを表す。音圧そのものの絶対値ではなく、受信音源の音量・音色応答に依存する。

### <a id="term-6"></a>6. ピッチベンド

正式名称: Pitch Bend Change

意味: 演奏中の音高を連続的に変化させるチャンネルボイスメッセージである。MIDI 1.0では2データバイトを結合した14ビット値を使い、中心は8192、範囲は0から16383である。

### <a id="term-7"></a>7. コントロールチェンジ

正式名称: Control Change (CC)

意味: ペダル、モジュレーション、音量など連続的または段階的な制御値を送るメッセージである。コントローラー番号と値はいずれもMIDI 1.0では7ビットで、番号ごとの意味は規格や機器実装で定められる。

### <a id="term-8"></a>8. プログラムチェンジ

正式名称: Program Change

意味: 受信側の音色プログラムを切り替えるチャンネルボイスメッセージである。MIDI 1.0のプログラム番号は7ビットだが、画面の1番表記と送信値0のような番号差に注意する。

### <a id="term-9"></a>9. バンクセレクト

正式名称: Bank Select

意味: プログラムチェンジの前にバンクを指定し、多数の音色集合から選択する仕組みである。通常はCC#0（MSB）とCC#32（LSB）を送り、その後にプログラムチェンジを送るが、対応方法は音源の仕様を確認する。

### <a id="term-10"></a>10. システムエクスクルーシブ

正式名称: System Exclusive (SysEx) Message

意味: メーカー固有または規格で定めた機器設定・大きなデータを送るシステムメッセージである。F0で始まりF7で終わる形式が基本で、メーカーIDや機器IDを含むため無関係な機器へ無差別に送るべきではない。

### <a id="term-11"></a>11. ランニングステータス

正式名称: Running Status

意味: 直前のチャンネルメッセージと同じステータスを省略してデータを続けるMIDI 1.0の伝送規則である。データ列の途中で別のステータスやシステムメッセージが現れた場合は状態を正しく更新する必要がある。

### <a id="term-12"></a>12. ステータスバイト

正式名称: Status Byte

意味: MIDI 1.0でメッセージ種別とチャンネルを示す1バイトで、最上位ビットが1になる。チャンネルボイスでは上位4ビットが種別、下位4ビットが0から15のチャンネル番号を表す。

### <a id="term-13"></a>13. データバイト

正式名称: Data Byte

意味: MIDI 1.0の値を運ぶバイトで、最上位ビットが0、値域は0から127である。メッセージ種別により必要なデータバイト数が異なり、プログラムチェンジは1個、ノートオンは2個である。

### <a id="term-14"></a>14. チャンネルボイスメッセージ

正式名称: Channel Voice Message

意味: 特定チャンネルの演奏表現を伝えるノート、CC、プログラムチェンジ、ピッチベンド等の総称である。GMのチャンネル10という慣例は、このメッセージの形式自体を変更するものではない。

### <a id="term-15"></a>15. システムメッセージ

正式名称: System Message

意味: チャンネルを特定せず、同期や機器間制御など接続全体に関わる情報を送るメッセージ群である。リアルタイム系、コモン系、SysExなどに分類される。

### <a id="term-16"></a>16. MIDIクロック

正式名称: Timing Clock

意味: テンポ同期のために1四分音符あたり24回送るMIDIリアルタイムメッセージである。これは24 PPQNの同期パルスであり、SMFの分解能（例えば480 ticks/四分音符）とは別の概念である。

### <a id="term-17"></a>17. スタート

正式名称: Start Message

意味: 外部同期を待つ機器に、曲を先頭から再生開始するよう指示するリアルタイムメッセージである。現在位置から再開するContinueとは意味が異なる。

### <a id="term-18"></a>18. ストップ

正式名称: Stop Message

意味: 外部同期中の再生を停止するリアルタイムメッセージである。停止後の位置を保持するか先頭へ戻るかは、機器のトランスポート実装によって異なる場合がある。

### <a id="term-19"></a>19. ソングポジションポインター

正式名称: Song Position Pointer

意味: MIDIクロック単位で、同期再生の現在位置を指定するシステムコモンメッセージである。送信値は14ビットで、StartやContinueと組み合わせて位置指定からの再生に使う。

### <a id="term-20"></a>20. MIDIポート

正式名称: MIDI Port

意味: MIDIデータの入力または出力の論理的な接続口である。物理端子、USBエンドポイント、ソフトウェアポートは同じ「ポート」でも経路と設定が異なる。

### <a id="term-21"></a>21. MIDIケーブル

正式名称: MIDI Cable

意味: MIDI信号を機器間で運ぶためのケーブルで、従来の5ピンDIN接続では送信と受信を別端子に接続する。オーディオ用ケーブルと同じ形状・配線とは限らないため、規格適合品を使う。

### <a id="term-22"></a>22. DIN端子

正式名称: 5-pin DIN Connector

意味: 従来のMIDI 1.0で使われる5ピンDINコネクターである。端子形状が同じでもMIDI配線とは限らず、MIDI IN/OUT/THRUの役割を確認する必要がある。

### <a id="term-23"></a>23. USB MIDI

正式名称: Universal Serial Bus MIDI

意味: USB経由でMIDIメッセージをコンピューターや機器間に運ぶトランスポートである。USB接続は音声を自動的に含む意味ではなく、MIDIとオーディオの経路は別に設定される。

### <a id="term-24"></a>24. MIDI 1.0

正式名称: MIDI 1.0 Specification

意味: 従来のMIDIメッセージ体系で、16チャンネル、7ビットのノート等、14ビットのピッチベンドを定義する。現在も広く使われ、MIDI 2.0が一律に廃止するものではない。

### <a id="term-25"></a>25. MIDI 2.0

正式名称: MIDI 2.0

意味: MIDI 1.0との相互運用を考慮しつつ、より高い分解能や双方向の機能を追加した世代である。MIDI検定3級の必須範囲と断定せず、この用語集では補足扱いとする。

### <a id="term-26"></a>26. MIDI Capability Inquiry

正式名称: MIDI-CI (MIDI Capability Inquiry)

意味: 機器同士が機能や対応範囲を問い合わせ、MIDI 2.0機能を安全に利用するための仕組みである。プロファイルやプロパティ・エクスチェンジの交渉に関係する。

### <a id="term-27"></a>27. Universal MIDI Packet

正式名称: Universal MIDI Packet (UMP)

意味: MIDI 2.0などのメッセージを共通のパケット表現で運ぶ形式である。グループによってアドレス空間を拡張できるが、従来のMIDI 1.0バイト列そのものと同一ではない。

### <a id="term-28"></a>28. MIDIプロファイル

正式名称: MIDI Profile

意味: 機器の特定用途に必要なメッセージ解釈や機能をまとめ、対応可否を機器間で扱いやすくする仕様である。対応プロファイルの有無を確認してから専用機能を使う。

### <a id="term-29"></a>29. プロパティ・エクスチェンジ

正式名称: Property Exchange

意味: MIDI-CIで機器のリソースやプロパティを問い合わせたり設定したりする仕組みである。SysEx形式のペイロードを使うが、一般的な音符イベントと混同しない。

### <a id="term-30"></a>30. Standard MIDI File

正式名称: Standard MIDI File (SMF)

意味: MIDIイベントを時間情報とともに保存し、シーケンス演奏データを交換するファイル形式である。音声波形を格納する形式ではなく、再生音は読み込む音源に依存する。

### <a id="term-31"></a>31. SMFフォーマット0

正式名称: Standard MIDI File Format 0

意味: 全チャンネルのイベントを1本のトラックチャンクにまとめて保存する形式である。単純な再生互換性に向くが、トラック別編集の情報はまとまりにくい。

### <a id="term-32"></a>32. SMFフォーマット1

正式名称: Standard MIDI File Format 1

意味: 複数トラックを同時刻軸で保存し、パートやテンポトラックを分けて扱える形式である。現在のDAWで編集しやすい代表的な形式である。

### <a id="term-33"></a>33. SMFフォーマット2

正式名称: Standard MIDI File Format 2

意味: 互いに独立した複数シーケンスを複数トラックチャンクに保存できる形式である。フォーマット0や1の単一曲・同時進行トラックとは用途が異なる。

### <a id="term-34"></a>34. SMF分解能

正式名称: SMF Timing Resolution

意味: SMFヘッダーで四分音符を何tickに分けるかを示す値で、例として480 ticks/quarter noteがある。これはMIDIクロックの24 PPQNとは別で、ファイル内の時間精度を決める。

### <a id="term-35"></a>35. tick

正式名称: MIDI Tick

意味: SMF内でイベントの相対時間を表す最小単位である。実時間への変換には分解能とテンポが必要で、単独のtick数だけでは秒数は決まらない。

### <a id="term-36"></a>36. PPQN

正式名称: Pulses Per Quarter Note

意味: 四分音符あたりのパルス数を表す略語で、文脈によりSMF分解能または同期クロックを指すことがある。SMFでは任意の分解能、MIDIクロックでは24 PPQNと明確に区別する。

### <a id="term-37"></a>37. テンポ

正式名称: Tempo

意味: 音楽が進む速さで、通常は1分あたりの拍数で指定する。BPMの拍は文脈上の基準音価であり、常に秒や四分音符と同一とは限らない。

### <a id="term-38"></a>38. BPM

正式名称: Beats Per Minute

意味: 1分間に何拍進むかを表す単位である。四分音符を1拍とする設定ならBPM 120は四分音符0.5秒だが、拍の基準音価を先に確認する。

### <a id="term-39"></a>39. 拍子

正式名称: Time Signature

意味: 小節内の拍の数と、基準となる音符の種類を示す記号である。6/8は単に6拍の4/4と同じではなく、通常は3つの二分割拍をまとめた複合拍子として感じる。

### <a id="term-40"></a>40. 拍

正式名称: Beat

意味: 拍子に基づく規則的な時間の単位で、強拍・弱拍のまとまりを作る。6/8では付点四分音符を大きな拍として感じる解釈が一般的だが、演奏文脈で細分の感じ方は変わる。

### <a id="term-41"></a>41. 小節

正式名称: Measure

意味: 拍子に従う拍のまとまりで、楽譜やシーケンスの位置を整理する単位である。小節線は時間を止めるものではなく、拍のグルーピングを示す。

### <a id="term-42"></a>42. 音程

正式名称: Musical Interval

意味: 二つの音の高さの隔たりで、度数と半音数などで表す。音名上の距離と実際の半音数は、調や表記によって別に確認する。

### <a id="term-43"></a>43. 半音

正式名称: Semitone

意味: 12平均律では隣り合う鍵盤の音程に相当する最小単位で、周波数比は2の1/12乗である。全ての音律でこの比率になるわけではないので、12平均律を前提として限定する。

### <a id="term-44"></a>44. 全音

正式名称: Whole Tone

意味: 12平均律で半音2個分に当たる音程である。長音階の隣接音程などに現れるが、音律や文脈を無視して周波数比を一般化しない。

### <a id="term-45"></a>45. 音名

正式名称: Pitch Name

意味: 音の高さをC、D、Eなどの文字や日本語音名で表す名前である。MIDIノート番号60を中央Cと呼ぶ慣習がある一方、C3/C4などのオクターブ表記は規格・ソフトで異なるため併記確認が必要である。

### <a id="term-46"></a>46. 音階

正式名称: Scale

意味: 一定の規則で並べた音の集合で、旋律や調性の素材になる。長音階・短音階など種類ごとに全音と半音の配置が異なる。

### <a id="term-47"></a>47. 長音階

正式名称: Major Scale

意味: 主音から全音・全音・半音・全音・全音・全音・半音の順で並ぶ7音の音階である。C長音階なら白鍵だけだが、他の主音では調号や臨時記号が必要になる。

### <a id="term-48"></a>48. 短音階

正式名称: Minor Scale

意味: 短調の音素材で、自然短音階・和声短音階・旋律短音階など複数の形がある。単に長音階を別の音から始めたものと決めつけず、種類を明示する。

### <a id="term-49"></a>49. 調

正式名称: Key

意味: 主音と、その曲で使われる音階・和音の中心を示す概念である。調号だけでは一時的な転調や旋法まで完全には決まらない。

### <a id="term-50"></a>50. 調号

正式名称: Key Signature

意味: 五線譜の冒頭で、曲全体の基本的なシャープやフラットを示す記号である。臨時記号や転調によって局所的に音が変わる場合は別途読む。

### <a id="term-51"></a>51. コード

正式名称: Chord

意味: 複数の異なる音を同時に鳴らした和音、またはその構成を示す記号である。コードネームは最低音やテンションまで必ず一意に決めるとは限らない。

### <a id="term-52"></a>52. 三和音

正式名称: Triad

意味: 根音・第三音・第五音を基本とする3音構成の和音である。長・短・減・増など第三音と第五音の関係で性質が変わる。

### <a id="term-53"></a>53. 七の和音

正式名称: Seventh Chord

意味: 三和音に根音から7度の音を加えた4音構成の和音である。属七、長七、短七など種類により7度の音程が異なる。

### <a id="term-54"></a>54. 転回形

正式名称: Chord Inversion

意味: 和音の構成音のうち根音以外を最低音に置いた配置である。コードの機能を保ちながらベースラインや声部進行を滑らかにできる。

### <a id="term-55"></a>55. ベース音

正式名称: Bass Note

意味: 和音やアレンジで最低域を担当する音、またはコードの最低音を指す。転回形では根音とベース音が一致しないことがある。

### <a id="term-56"></a>56. General MIDI

正式名称: General MIDI (GM)

意味: 音色番号、ドラム割り当て、基本的な応答を標準化し、異なるGM音源でSMFを鳴らしやすくする推奨仕様である。GMは音源の音質を統一・保証する規格ではなく、GMでない機器へチャンネル10のパーカッション規則を一般化できない。

### <a id="term-57"></a>57. 音源

正式名称: Sound Module / Tone Generator

意味: MIDI演奏情報を受けて、音声信号を生成する装置またはソフトウェアである。MIDIデータと音源は別物なので、同じノートでも音源プリセットやエフェクトで結果が変わる。

### <a id="term-58"></a>58. シンセサイザー

正式名称: Synthesizer

意味: 発振器、フィルター、エンベロープなどを組み合わせて音を合成・加工する楽器または音源である。方式には減算合成、FMなどがあり、単一方式に限定されない。

### <a id="term-59"></a>59. PCM音源

正式名称: Pulse Code Modulation Sound Source

意味: 録音した音声サンプルをPCMデータとして再生・加工する音源方式である。サンプルの品質やメモリ、再生処理が音の再現性に影響する。

### <a id="term-60"></a>60. FM音源

正式名称: Frequency Modulation Sound Source

意味: 発振器の周波数を別の発振器で変調し、倍音を作る合成方式である。変調周波数や変調量、アルゴリズムによって金属的な音からベル系まで変化する。

### <a id="term-61"></a>61. サンプラー

正式名称: Sampler

意味: 録音済みのサンプルを鍵盤範囲やベロシティに割り当てて再生・加工する装置またはソフトウェアである。元サンプルの権利やライセンスも制作前に確認する。

### <a id="term-62"></a>62. オシレーター

正式名称: Oscillator

意味: 周期的な波形を発生させ、シンセサイザーの音の素材を作る回路またはソフトウェア機能である。周波数が音高、波形と倍音構成が音色に関係する。

### <a id="term-63"></a>63. 波形

正式名称: Waveform

意味: 時間に対する信号の振幅変化の形で、音の倍音構成や音色に関係する。正弦波、鋸歯状波、矩形波などは理想化した例で、実機では加工や帯域制限がある。

### <a id="term-64"></a>64. エンベロープ

正式名称: Envelope

意味: 音量やフィルター周波数などのパラメーターを時間に沿って変化させる制御曲線である。ノートオンからノートオフ後までの応答を形作る。

### <a id="term-65"></a>65. ADSR

正式名称: Attack, Decay, Sustain, Release

意味: 音量などの時間変化を4段階で表すエンベロープ方式である。Attack・Decay・Releaseは時間、Sustainは保持中のレベルであり、Sustainを時間と取り違えない。

### <a id="term-66"></a>66. フィルター

正式名称: Audio Filter

意味: 周波数帯域を通過・減衰させ、音色を変える回路または処理である。ローパスならカットオフより上を主に減衰させるが、傾きや共振も結果に影響する。

### <a id="term-67"></a>67. カットオフ周波数

正式名称: Cutoff Frequency

意味: フィルターが通過させる帯域と減衰させる帯域の境界として設定する周波数である。具体的な減衰量の定義はフィルター形式により異なる。

### <a id="term-68"></a>68. レゾナンス

正式名称: Resonance

意味: フィルターのカットオフ付近を強調する量で、音色に鋭いピークを作る。上げ過ぎると発振や耳に刺さる音になる場合がある。

### <a id="term-69"></a>69. LFO

正式名称: Low Frequency Oscillator

意味: 可聴域より低い周期信号を作り、音量・音高・フィルターなどを周期的に変調する。LFO自体を通常の音源オシレーターと同じ音として聴く目的ではない。

### <a id="term-70"></a>70. オートメーション

正式名称: Automation

意味: DAWなどで音量やプラグインパラメーターの変化を時間軸上のデータとして記録・再生する機能である。MIDI CCによる制御とオーディオミックスの制御は実装上別の場合がある。

### <a id="term-71"></a>71. DAW

正式名称: Digital Audio Workstation

意味: オーディオ録音・編集・ミックスとMIDI制作を統合するソフトウェア環境である。プロジェクト設定、プラグイン、オーディオインターフェースによって扱える機能が変わる。

### <a id="term-72"></a>72. シーケンサー

正式名称: Sequencer

意味: MIDIイベントやオーディオを時間順に記録・編集・再生する機能または装置である。現在はDAWの一部として実装されることが多い。

### <a id="term-73"></a>73. ピアノロール

正式名称: Piano Roll Editor

意味: 縦軸を音高、横軸を時間としてノートを矩形で編集する画面である。長さ・開始位置・ベロシティなどを視覚的に変更できる。

### <a id="term-74"></a>74. イベントリスト

正式名称: Event List

意味: ノートやCCなどのイベントを時刻、種類、値の一覧で表示・編集する画面である。ピアノロールでは見落としやすい細かな値や順序の確認に向く。

### <a id="term-75"></a>75. クオンタイズ

正式名称: Quantize

意味: 演奏やノートの開始・長さを指定したグリッドへ近づける編集処理である。強く適用すると人間的な揺れまで失うため、適用量や対象を調整する。

### <a id="term-76"></a>76. スウィング

正式名称: Swing

意味: 等分の細かい拍を長短の比率でずらし、跳ねたリズム感を作る処理または演奏概念である。グリッド、対象音符、比率によって効果が異なる。

### <a id="term-77"></a>77. トランスポート

正式名称: Transport Control

意味: 再生、停止、録音、早送りなど時間軸の走行を操作する機能である。MIDIのStart/StopやMMCを使う同期制御とは、同じ操作概念でも伝送仕様が別である。

### <a id="term-78"></a>78. オーディオ

正式名称: Audio

意味: マイクや音源から得た連続的な音声信号を、サンプリングしてデジタルデータとして記録・処理したものである。サンプルレートと量子化ビット数などが品質やデータ量に関係する。

### <a id="term-79"></a>79. MIDIデータ

正式名称: MIDI Data

意味: ノート、CC、テンポ、SysExなどのイベントと時間情報を表すデータである。演奏情報であって完成した音声ではないため、再生には音源やレンダリング工程が必要になる。

### <a id="term-80"></a>80. 録音

正式名称: Recording

意味: 演奏や音声をマイク・ライン入力などから記録する行為である。MIDI録音は操作イベントを記録し、オーディオ録音は実際の音声波形を記録する。

### <a id="term-81"></a>81. 打ち込み

正式名称: MIDI Programming

意味: マウスやキーボード等でMIDIノートや制御イベントを入力・編集する制作方法である。正確な入力ができても、ベロシティや発音長を調整しなければ自然な演奏になるとは限らない。

### <a id="term-82"></a>82. アレンジ

正式名称: Arrangement

意味: 曲の構成、楽器編成、伴奏、展開、音域などを設計する作業である。作曲された旋律を変えずに編成を変える場合もあれば、構成自体を再設計する場合もある。

### <a id="term-83"></a>83. ミックス

正式名称: Mixing

意味: 複数のオーディオトラックを音量、定位、音色、ダイナミクスなどで整え、二次元以上の出力へまとめる工程である。マスタリングや作曲・アレンジとは目的が異なる。

### <a id="term-84"></a>84. 著作権

正式名称: Copyright

意味: 創作した音楽作品や録音などに関して、利用を許諾・制限する権利の制度である。MIDIデータも創作性を含む場合や既存曲の表現を含む場合があり、単なる数値列だから常に自由とはいえない。

### <a id="term-85"></a>85. 同期

正式名称: Synchronization

意味: 複数の機器やソフトの再生位置・テンポ・時間を一致させることをいう。MIDIクロック、MTC、ワードクロックなどは対象と精度が異なるので目的に応じて選ぶ。

### <a id="term-86"></a>86. MIDIタイムコード

正式名称: MIDI Time Code (MTC)

意味: 時間コードをMIDIメッセージで伝え、映像や録音機器の時刻を同期させる方式である。テンポを刻むMIDIクロックとは用途が異なり、フレーム単位の時間情報を扱う。

### <a id="term-87"></a>87. MIDIマシンコントロール

正式名称: MIDI Machine Control (MMC)

意味: レコーダーやDAWの再生、停止、録音などのトランスポート操作をMIDIで制御する仕様である。音符のタイミングを同期するMIDIクロックそのものではない。

### <a id="term-88"></a>88. SysEx ID

正式名称: System Exclusive Identification

意味: SysEx内でメーカーや機器、用途を識別するためのID情報である。IDが一致しない機器に設定データを送っても無視される、または望ましくない動作をする可能性がある。

### <a id="term-89"></a>89. ノート番号

正式名称: MIDI Note Number

意味: MIDI 1.0のノートオン等で音高を指定する7ビット値で、0から127を取る。値60を中央Cとする慣習はあるが、オクターブ名C3/C4などの表示はソフトや規約によって異なる。

### <a id="term-90"></a>90. ポリフォニック・アフタータッチ

正式名称: Polyphonic Key Pressure

意味: 鍵盤ごとに、押した後の圧力変化を送るチャンネルボイスメッセージである。各ノートの独立表現に使えるが、対応する鍵盤・音源は限られる。

### <a id="term-91"></a>91. チャンネル・アフタータッチ

正式名称: Channel Pressure

意味: チャンネル内の押鍵後の圧力を1つの値で表すメッセージである。MIDI 1.0では7ビット値で、チャンネル内の複数音に共通の変化として扱われる。

## 難所の自作例

1. 480 ticks/四分音符のSMFで120 BPMなら、四分音符は0.5秒なので1 tickは約1.0417 msである。MIDIクロックは同じ曲でも24 PPQNで送られ、480というファイル分解能をそのまま送るわけではない。
2. ノートオン(チャンネル1, note 60, velocity 100)の直後に同じ音のノートオン(note 60, velocity 0)を送ると、後者はノートオフ相当になる。note 60の表示がC3かC4かはソフトのオクターブ規約を確認する。
3. ピッチベンド値8192は中央であり、値16383が最大上方向、0が最大下方向である。これは7ビットCCを2つ送る操作と同じではなく、14ビットの専用メッセージである。
4. 6/8を「四分音符6拍」と読むのは不適切で、通常は付点四分音符2拍、または八分音符3つのまとまり2つとして感じる。BPMの基準拍が何かをDAW設定で確認する。
5. GM対応SMFのチャンネル10にドラムノートを置いても、非GM音源が同じノート配置や音色を採用する保証はない。GMの互換性目標を、全MIDI機器の共通動作と取り違えない。
6. ADSRでSustainを0.5秒と指定するのは概念上の誤りで、Sustainは押鍵を保持している間のレベルである。0.5秒はDecayまたはReleaseなど時間パラメーターの値として指定する。
7. SMF format 0は全イベントを1トラックにまとめ、format 1は複数トラックを同時進行で保存する。format 2は独立した複数シーケンスを扱うため、format 1の単なる別名ではない。
8. MIDIデータを送っても、受信側にピアノ音源がなければピアノの波形は発生しない。オーディオ録音は波形を保存するため、再生時に元音源がなくても録音音を再現できる。
9. CからC#は12平均律では半音で周波数比2^(1/12)だが、純正律など別の音律にも同じ比率を広げてはいけない。音律の前提を文中に書く。
10. バンクセレクトはCC#0とCC#32、続くプログラムチェンジの順で送る実装が多い。音源によってバンク番号の解釈や1始まり表示が異なるため、仕様表を照合する。
11. MTCは「00:12:03:10」のような時間位置を同期し、MIDIクロックはテンポに沿った拍の進行を同期する。映像との時刻合わせにMIDIクロックだけを使う、とは限らない。
12. MIDIデータのノート列を自作しても、既存曲の旋律や配布サンプルを含めれば著作権・利用許諾の確認が必要になり得る。データが音声でないことだけを理由に無許諾利用しない。
