# 映像資格 用語集

## 対象と限界

正式資格名：映像音響処理技術者資格認定試験（一般社団法人日本ポストプロダクション協会）

本稿は映像・音響・ポストプロダクションを学ぶための基礎用語集であり、試験範囲の完全再現、合格保証、公式解答ではない。規格の版や納品先指定がある場合はそれを優先する。

## 独立定義

### <a id="term-1"></a>1. フレームレート

正式名称・英語表記：Frame rate

意味：1秒間に表示・記録する映像フレーム数で、単位はfps。動きの滑らかさと時間基準を左右する。

### <a id="term-2"></a>2. fps

正式名称・英語表記：frames per second

意味：frames per secondの略で、1秒あたりのフレーム数。59.94 fpsは約16.68 msごとに1フレームを扱う。

### <a id="term-3"></a>3. プログレッシブ走査

正式名称・英語表記：Progressive scanning

意味：1枚のフレームを上から下まで一度に走査する方式。フィールド間の櫛形歪みを生じにくい。

### <a id="term-4"></a>4. インターレース走査

正式名称・英語表記：Interlaced scanning

意味：奇数線と偶数線を別々のフィールドとして送る方式。59.94iは59.94フィールド/秒で、通常29.97フレーム/秒である。

### <a id="term-5"></a>5. 解像度

正式名称・英語表記：Spatial resolution

意味：画像の横と縦の画素数。1920×1080と3840×2160は同じ16:9でも細部の記録量が異なる。

### <a id="term-6"></a>6. 走査線

正式名称・英語表記：Scan line

意味：映像を横方向に読み出す1本の線。インターレースでは奇数線と偶数線を別フィールドに割り当てる。

### <a id="term-7"></a>7. アスペクト比

正式名称・英語表記：Aspect ratio

意味：画面の横と縦の比で、16:9や4:3で表す。画素アスペクト比が非正方形なら保存画素数の比と表示比は一致しない。

### <a id="term-8"></a>8. 画素

正式名称・英語表記：Pixel

意味：デジタル画像を構成する最小のサンプルで、色や明るさの値を持つ。画素数を増やしても撮影情報が自動的に増えるわけではない。

### <a id="term-9"></a>9. RGB

正式名称・英語表記：Red, Green, Blue

意味：赤・緑・青の加法三原色で色を表す形式。ディスプレイやコンピューター画像で使うが、映像伝送形式そのものではない。

### <a id="term-10"></a>10. YCbCr

正式名称・英語表記：Y' (nonlinear luma), Cb and Cr chroma-difference components

意味：YCbCrはY'（非線形luma）とCb・Cr（色差成分）で表す信号形式で、頭字語を根拠なく展開しない。色差を間引くことで伝送量を抑えられる。

### <a id="term-11"></a>11. 色差

正式名称・英語表記：Chroma difference

意味：基準色成分との差を表す成分で、CbとCrが代表例。Y'（非線形luma）と混同すると色やレベルの判定を誤る。

### <a id="term-12"></a>12. クロマサブサンプリング

正式名称・英語表記：Chroma subsampling

意味：輝度より色差のサンプル数を減らす方法。4:4:4は間引かず、4:2:2は横方向を半分、4:2:0は横と縦を概ね半分にする。

### <a id="term-13"></a>13. 量子化ビット深度

正式名称・英語表記：Quantization bit depth

意味：各サンプルを何ビットの段階で表すか。10ビットなら理論上1024段階だが、機器や元信号が対応しなければ情報は増えない。

### <a id="term-14"></a>14. SDR

正式名称・英語表記：Standard Dynamic Range

意味：Standard Dynamic Rangeの略で、従来型の標準的な明暗範囲。HDRから変換するには明るさと色域の変換が必要である。

### <a id="term-15"></a>15. HDR

正式名称・英語表記：High Dynamic Range

意味：High Dynamic Rangeの略で、SDRより広い明暗範囲を扱う総称。PQやHLG、色域、最大輝度を合わせて管理する必要がある。

### <a id="term-16"></a>16. Rec.709

正式名称・英語表記：ITU-R Recommendation BT.709

意味：HDTVの制作・国際交換に関するITU-R勧告BT.709。HDのSDRで広く使われ、Rec.2020やHDRと同義ではない。

### <a id="term-17"></a>17. Rec.2020

正式名称・英語表記：ITU-R Recommendation BT.2020

意味：UHDTVの制作・国際交換に関するITU-R勧告BT.2020。広い原色範囲などを定める色域・信号基準で、コーデック名ではない。

### <a id="term-18"></a>18. ガンマ

正式名称・英語表記：Gamma transfer characteristic

意味：入力値と表示輝度の関係を表す伝達特性の呼び方。撮影、符号化、表示のどの段階かを指定しないと設定は確定しない。

### <a id="term-19"></a>19. PQ

正式名称・英語表記：Perceptual Quantizer

意味：Perceptual Quantizerの略で、BT.2100のHDR方式の一つ。コード値を基準となる絶対輝度範囲に対応させる。

### <a id="term-20"></a>20. HLG

正式名称・英語表記：Hybrid Log-Gamma

意味：Hybrid Log-Gammaの略で、BT.2100のHDR方式の一つ。暗部のガンマ特性と高輝度側の対数特性を組み合わせる。

### <a id="term-21"></a>21. 色域

正式名称・英語表記：Color gamut

意味：再現できる色の範囲。Rec.709とRec.2020は原色位置が異なるため、変換なしに数値を移すと色が変わる。

### <a id="term-22"></a>22. ホワイトポイント

正式名称・英語表記：White point

意味：白として扱う色度の基準点。D65などが異なる素材を混ぜると、同じRGB値でも白の色味が変わる。

### <a id="term-23"></a>23. 輝度

正式名称・英語表記：Luminance

意味：画面の明るさに関係する物理量で、通常cd/m²で表す。コード値や主観的な明るさとは区別する。

### <a id="term-24"></a>24. コントラスト

正式名称・英語表記：Contrast

意味：明るい部分と暗い部分の差または比率。黒つぶれや白飛びには信号範囲と表示特性も関係する。

### <a id="term-25"></a>25. 色温度

正式名称・英語表記：Color temperature

意味：光の色を黒体温度に対応させる尺度でKを使う。一般に高いほど青白く、低いほど赤みを帯びる。

### <a id="term-26"></a>26. クロマキー

正式名称・英語表記：Chroma key

意味：特定色を選択して透明化し、別映像を合成する手法。スピル、被写体の縁、背景の照明むらを確認する。

### <a id="term-27"></a>27. コーデック

正式名称・英語表記：Codec

意味：映像や音声を符号化・復号する方式で、H.264やProResが例。コンテナとは別の概念である。

### <a id="term-28"></a>28. コンテナ

正式名称・英語表記：Container format

意味：映像・音声ストリーム、字幕、タイムコードなどを一つのファイルに格納する形式。MOVやMXFは内部コーデックを一意に決めない。

### <a id="term-29"></a>29. ビットレート

正式名称・英語表記：Bit rate

意味：単位時間あたりのデータ量でbit/sで表す。必要量は解像度、フレームレート、内容、コーデックで変わる。

### <a id="term-30"></a>30. 圧縮

正式名称・英語表記：Compression

意味：冗長性を減らして保存・伝送量を小さくする処理。復元可能性により可逆と非可逆に分かれる。

### <a id="term-31"></a>31. 可逆圧縮

正式名称・英語表記：Lossless compression

意味：圧縮前のデータを完全に復元できる方式。品質を失わない一方、非可逆方式ほど小さくならないことが多い。

### <a id="term-32"></a>32. 非可逆圧縮

正式名称・英語表記：Lossy compression

意味：知覚されにくい情報などを捨ててデータ量を減らす方式。再圧縮でノイズや輪郭劣化が蓄積し得る。

### <a id="term-33"></a>33. GOP

正式名称・英語表記：Group of Pictures

意味：Iフレームを基点にP/Bフレームを並べた符号化単位。長いGOPは効率向上の反面、編集やランダムアクセスに不利な場合がある。

### <a id="term-34"></a>34. Iフレーム

正式名称・英語表記：Intra-coded frame

意味：他フレームを参照せずフレーム内で符号化した画像。GOPの基点になりやすいが、無圧縮を意味しない。

### <a id="term-35"></a>35. Pフレーム

正式名称・英語表記：Predictive-coded frame

意味：前方の参照フレームとの差分や動き情報で符号化するフレーム。参照先がないと単独復号できない。

### <a id="term-36"></a>36. Bフレーム

正式名称・英語表記：Bi-predictive-coded frame

意味：前後の参照フレームから予測するフレーム。圧縮効率は高めやすいが、表示順と符号化順が異なることがある。

### <a id="term-37"></a>37. キーフレーム

正式名称・英語表記：Keyframe

意味：再生や編集の基準としてアクセスしやすいフレームを指す実務語。ソフトによってIフレームとの定義を確認する。

### <a id="term-38"></a>38. イントラフレーム

正式名称・英語表記：Intra frame

意味：フレーム内予測だけで符号化されたフレーム。Iフレームに近いが、コーデックごとの細部まで同一とは限らない。

### <a id="term-39"></a>39. タイムコード

正式名称・英語表記：Timecode

意味：映像・音声の位置を時分秒フレームで示す番号。時間軸のラベルであり、実フレーム数そのものではない。

### <a id="term-40"></a>40. ドロップフレーム

正式名称・英語表記：Drop-frame timecode

意味：29.97系の実時間に合わせるためタイムコード番号を一定規則で飛ばす方式。実フレームは削除しない。

### <a id="term-41"></a>41. ノンドロップフレーム

正式名称・英語表記：Non-drop-frame timecode

意味：タイムコード番号を飛ばさず連番で付ける方式。29.97系では長時間に実時間とのずれが生じる。

### <a id="term-42"></a>42. 実フレーム

正式名称・英語表記：Actual picture frame

意味：実際に記録・表示される画像フレーム。ドロップフレームの欠番は実フレームの廃棄ではない。

### <a id="term-43"></a>43. HDMI

正式名称・英語表記：High-Definition Multimedia Interface

意味：映像と音声をデジタル伝送するインターフェース。帯域、端子、HDCP、機器間認証などの互換性を確認する。

### <a id="term-44"></a>44. SDI

正式名称・英語表記：Serial Digital Interface

意味：業務用映像をシリアルデジタル伝送するインターフェース群。信号規格、データレート、音声補助データの対応を合わせる。

### <a id="term-45"></a>45. 同期信号

正式名称・英語表記：Synchronization signal

意味：複数機器が映像・音声の時間基準を共有する信号。ずれるとフレーム飛びや音声クリックが起こる。

### <a id="term-46"></a>46. Genlock

正式名称・英語表記：Generator locking

意味：外部基準同期に各機器の映像発生タイミングをロックする仕組み。同じタイムコード設定だけではフレーム同期にならない。

### <a id="term-47"></a>47. SMPTE

正式名称・英語表記：Society of Motion Picture and Television Engineers

意味：Society of Motion Picture and Television Engineersの略で、映画・テレビ技術の標準化を行う専門団体。個別規格の適用範囲は規格番号で確認する。

### <a id="term-48"></a>48. EBU

正式名称・英語表記：European Broadcasting Union

意味：European Broadcasting Unionの略で、欧州放送連合および技術文書を指す。EBU R 128は番組ラウドネス運用の勧告である。

### <a id="term-49"></a>49. ITU-R

正式名称・英語表記：ITU Radiocommunication Sector

意味：International Telecommunication Union Radiocommunication Sectorの略で、無線通信・放送の勧告を扱う部門。BT.709、BT.2020、BT.2100はBTシリーズである。

### <a id="term-50"></a>50. 音声同期

正式名称・英語表記：Audio-video synchronization

意味：映像の出来事と対応音声の時間位置を一致させること。タイムコードや遅延補正を確認し、音量調整とは区別する。

### <a id="term-51"></a>51. リップシンク

正式名称・英語表記：Lip sync

意味：唇の動きと発話音声が一致して見える状態。映像・音声の遅延を測り、フレームまたはサンプル単位で補正する。

### <a id="term-52"></a>52. サンプリング周波数

正式名称・英語表記：Sampling frequency

意味：音声波形を1秒に何回測定するかを示す値。48 kHzなら1秒に48000サンプルを記録する。

### <a id="term-53"></a>53. 量子化

正式名称・英語表記：Quantization

意味：サンプリングした振幅を有限の数値段階へ丸める処理。段階数が少ないと量子化雑音が増える。

### <a id="term-54"></a>54. PCM

正式名称・英語表記：Pulse-Code Modulation

意味：Pulse-Code Modulationの略で、音声をサンプリングと量子化による数値列にする方式。非圧縮PCMのデータ量は周波数、ビット深度、チャンネル数で決まる。

### <a id="term-55"></a>55. チャンネル

正式名称・英語表記：Audio channel

意味：独立した音声信号の経路で、L/Rやセンターなどを表す。チャンネル数とトラック数、スピーカー本数は必ずしも同じではない。

### <a id="term-56"></a>56. ステレオ

正式名称・英語表記：Stereo

意味：左右二つのチャンネルで方向感や広がりを再現する方式。L/Rの取り違えや位相差はモノラル化で確認できる。

### <a id="term-57"></a>57. サラウンド

正式名称・英語表記：Surround sound

意味：複数方向のチャンネルで包囲感を作る方式。5.1は5つのフルレンジ系とLFE 1系統だが、チャンネル順は仕様確認が必要である。

### <a id="term-58"></a>58. ラウドネス

正式名称・英語表記：Loudness

意味：周波数特性や時間変化を考慮した、人が感じる音の大きさの指標。瞬間ピークだけでは番組の聞こえ方を評価できない。

### <a id="term-59"></a>59. LUFS

正式名称・英語表記：Loudness Units relative to Full Scale

意味：Loudness Units relative to Full Scaleの略で、標準化ラウドネスの単位。EBU R 128は平均番組ラウドネス-23 LUFSを示すが納品先指定を優先する。

### <a id="term-60"></a>60. ピークメーター

正式名称・英語表記：Peak meter

意味：音声の瞬間的またはサンプル上のピークを表示するメーター。クリッピング検出用で、平均の大きさはLUFSで別に測る。

### <a id="term-61"></a>61. 波形モニター

正式名称・英語表記：Waveform monitor

意味：映像信号の輝度・電圧レベルをスケール表示する測定器。黒白レベルを画面の見た目だけで判断しないために使う。

### <a id="term-62"></a>62. ベクトルスコープ

正式名称・英語表記：Vectorscope

意味：色差成分を色相の方向と彩度の距離で表示する測定器。肌色線やカラーバーで色ずれを確認できる。

### <a id="term-63"></a>63. カラーバー

正式名称・英語表記：Color bars

意味：色、輝度、レベルを点検する標準的試験パターン。送出側と受像側で同じパターンを測り経路異常を切り分ける。

### <a id="term-64"></a>64. テスト信号

正式名称・英語表記：Test signal

意味：機器や伝送の性能、レベル、同期を確認するための信号。カラーバーや1 kHz音などは目的と規格を明示する。

### <a id="term-65"></a>65. マスターモニター

正式名称・英語表記：Mastering monitor

意味：色・輝度・階調を基準に近い状態で再現し最終判断に使う表示装置。校正、色域、HDR方式、周囲光を管理する。

### <a id="term-66"></a>66. 編集

正式名称・英語表記：Editing

意味：素材を選び順序・長さ・音声・効果を組み合わせ、作品の時間構造を作る工程。内容決定と規格処理は目的を分ける。

### <a id="term-67"></a>67. オフライン編集

正式名称・英語表記：Offline editing

意味：低負荷のプロキシ等で構成や演出を決める工程。終了後は決定情報を高品質原素材へ正しくリンクする。

### <a id="term-68"></a>68. オンライン編集

正式名称・英語表記：Online editing

意味：高品質原素材で色調整、合成、最終出力まで仕上げる工程。オフラインのタイムコードと素材の一致が前提となる。

### <a id="term-69"></a>69. ノンリニア編集

正式名称・英語表記：Non-linear editing

意味：ファイル上の任意位置へアクセスして編集する方式。テープを順に扱うリニア編集より修正や案比較が容易である。

### <a id="term-70"></a>70. トランスコード

正式名称・英語表記：Transcoding

意味：コーデック、解像度、フレームレート等を別形式へ変換する処理。色域、音声、タイムコードを変換前後で検証する。

### <a id="term-71"></a>71. 書き出し

正式名称・英語表記：Export

意味：編集結果を指定ファイル形式と場所へ出力する処理。コーデック、コンテナ、色空間、音声チャンネルを納品仕様に合わせる。

### <a id="term-72"></a>72. レンダリング

正式名称・英語表記：Rendering

意味：合成やエフェクトの計算結果を再生可能なデータに生成する処理。一時レンダーと納品書き出しは品質確認を分ける。

### <a id="term-73"></a>73. インジェスト

正式名称・英語表記：Ingest

意味：媒体から素材を取り込み、保存・検査・登録する工程。コピー後にチェックサム、ファイル数、容量、メタデータを確認する。

### <a id="term-74"></a>74. メタデータ

正式名称・英語表記：Metadata

意味：撮影日時、設定、権利、タイムコードなどを説明する付加情報。変換時に保持される項目はコンテナやソフトに依存する。

### <a id="term-75"></a>75. プロキシ

正式名称・英語表記：Proxy media

意味：原素材の代わりに編集を軽くする代理メディア。タイムコード、フレームレート、音声を原素材と照合して戻す。

### <a id="term-76"></a>76. アーカイブ

正式名称・英語表記：Archive

意味：将来の再利用のため完成素材、プロジェクト、必要な関連ファイルを長期保存すること。媒体劣化を想定し復元テストも行う。

### <a id="term-77"></a>77. バックアップ

正式名称・英語表記：Backup

意味：障害や誤削除に備え復元可能な複製を別媒体・別場所に保持すること。RAID内の複製だけではバックアップにならない。

### <a id="term-78"></a>78. RAID

正式名称・英語表記：Redundant Array of Independent Disks

意味：複数ディスクで速度向上や一部故障耐性を得る仕組み。可用性の構成であり、別場所のバックアップを代替しない。

### <a id="term-79"></a>79. ファイルベース

正式名称・英語表記：File-based workflow

意味：映像音声をファイルとして収録、転送、編集、納品する運用。命名、フォルダー、チェックサム、メタデータ管理が重要である。

### <a id="term-80"></a>80. 放送規格

正式名称・英語表記：Broadcast standard

意味：放送で要求される映像、音声、信号レベル、搬入等の技術条件。国・局・媒体で異なるため最新版を確認する。

### <a id="term-81"></a>81. 納品仕様

正式名称・英語表記：Delivery specification

意味：コンテナ、コーデック、解像度、音声、字幕、ファイル名等の納品条件。制作開始時に確認し検査表にする。

### <a id="term-82"></a>82. CM

正式名称・英語表記：Commercial message

意味：Commercial messageの略で商品やサービスを告知する短い広告映像。尺、権利、字幕、音声レベル、搬入仕様を管理する。

### <a id="term-83"></a>83. MA

正式名称・英語表記：MA (usage varies; often Multi Audio or dubbing/mixing workflow)

意味：MAは会社や案件により展開と範囲が一定しない。ここでは収録、整音、効果、ナレーション、ミックスを含む音声仕上げ工程を指し、Multi Audioと断定せず仕様書で確認する。

### <a id="term-84"></a>84. ダビング

正式名称・英語表記：Dubbing

意味：別言語の台詞や音声を収録・置換する作業、または複製を指す実務語。翻訳、尺、権利、完成ミックスとの同期を確認する。

### <a id="term-85"></a>85. フォーリー

正式名称・英語表記：Foley

意味：足音や衣擦れ等を画面の動きに合わせてスタジオで作る効果音。同期、反響、台詞との重なりを整える。

### <a id="term-86"></a>86. ナレーション

正式名称・英語表記：Narration

意味：説明や語りを担う音声。原稿、発音、尺、権利を管理し、音楽や効果音との明瞭度を調整する。

### <a id="term-87"></a>87. 効果音

正式名称・英語表記：Sound effect

意味：動作や環境、演出を伝える音。収録音、ライブラリー、フォーリーを使い分け、許諾と同期を確認する。

### <a id="term-88"></a>88. ミックス

正式名称・英語表記：Mixing

意味：複数音声の音量、定位、周波数、ダイナミクスを統合しバランスを作る工程。チャンネル構成とラウドネスも確認する。

### <a id="term-89"></a>89. ステム

正式名称・英語表記：Stem

意味：台詞、音楽、効果音などをまとめたサブミックス。言語差替えに便利だが、再合成時の過大レベルを防ぐ設計が必要である。

### <a id="term-90"></a>90. ミュート

正式名称・英語表記：Mute

意味：指定トラックやクリップの音を出力しない状態。書き出し前に意図しないミュートが残っていないか確認する。

### <a id="term-91"></a>91. フェード

正式名称・英語表記：Fade

意味：音量や明るさを時間に沿って徐々に変える処理。音声ではクリック防止、映像ではテンポとの整合を確認する。

### <a id="term-92"></a>92. クロスフェード

正式名称・英語表記：Crossfade

意味：一方を下げながら別素材を上げて連続的につなぐ処理。音声の位相や低域の重なりも確認する。

### <a id="term-93"></a>93. ディゾルブ

正式名称・英語表記：Dissolve

意味：前映像を薄くし次映像を現して重ねるトランジション。二つのショットが重なるため、カットとは必要な尺が異なる。

### <a id="term-94"></a>94. カット

正式名称・英語表記：Cut

意味：ショットを瞬時に別ショットへ切り替える編集点。フレーム位置、動作連続性、音の切断を確認する。

### <a id="term-95"></a>95. コンフォーム

正式名称・英語表記：Conform

意味：オフライン決定情報を高品質原素材や音声工程へ再構成する作業。EDL/XML、リール、タイムコード、速度変更を照合する。

### <a id="term-96"></a>96. EDL

正式名称・英語表記：Edit Decision List

意味：Edit Decision Listの略で、素材入出点や編集点を記すリスト。単純なカットに有効だが複雑な合成の表現範囲を確認する。

### <a id="term-97"></a>97. XML

正式名称・英語表記：Extensible Markup Language

意味：Extensible Markup Languageの略でタグ付き構造化テキスト形式。編集情報を交換できるが、対応範囲はソフトや版で異なる。

### <a id="term-98"></a>98. 字幕

正式名称・英語表記：Subtitles

意味：台詞や情報を文字で表示するもの。表示時間、文字量、セーフエリア、翻訳、焼き付けか別ファイルかを定める。

### <a id="term-99"></a>99. セーフエリア

正式名称・英語表記：Safe area

意味：表示端で欠ける可能性を考え重要映像や文字を内側に置く範囲。放送・配信先のトリミング条件を確認する。

### <a id="term-100"></a>100. タイトルセーフ

正式名称・英語表記：Title safe area

意味：タイトルや字幕など重要文字を置く安全範囲。一般にアクションセーフより内側だが、現在の納品仕様を優先する。

## 難所を確認する自作例

1. 59.94iは59.94フィールド/秒だが通常29.97フレーム/秒で、フィールドとフレームを同一視しない。
2. ドロップフレームはタイムコード番号を飛ばすだけで、実フレームを捨てない。
3. YCbCrのY'は非線形luma、Cb/Crは色差であり、頭字語を勝手に英単語展開しない。
4. 4:2:2は色差の横サンプルを減らす形式で、4:4:4と同じ色解像度ではない。
5. H.264はコーデック、MP4はコンテナであり、MP4だからH.264とは限らない。
6. RAID 1は故障耐性で、誤削除や火災に備える別場所バックアップではない。
7. 5.1はチャンネル数だけでなくL/R/C/LFE/Ls/Rsの順序を仕様と照合する。
8. -23 LUFSは平均ラウドネスの基準で、ピークメーターの値とは別に測る。
9. プロキシのタイムコードが原素材から1フレームずれると、コンフォーム後にカット点もずれる。
10. PQは絶対輝度型、HLGは放送運用を考慮した方式で、HDRという総称だけで同じ変換をしない。
11. Rec.709 SDRをRec.2020 HDRとして数値だけ書き出さず、色域・伝達特性・輝度を変換する。
12. MAは会社や案件で意味が揺れるので、Multi Audioと決め打ちせず作業範囲を仕様書で確認する。
