## 独立定義

### <a id="term-1"></a>1. 音圧

正式名称
音圧

意味
音波によって媒質中に生じる、静圧からの瞬時の圧力変動で、単位はPa（パスカル）です。マイクロホンはこの変動を電気信号へ変換し、音圧そのものは距離や室内反射の影響を受けます。

### <a id="term-2"></a>2. 音圧レベル

正式名称
Sound Pressure Level (SPL)

意味
音圧の実効値pを基準音圧20 µPaで比べ、SPL = 20 log10(p/20 µPa) [dB]で表します。周波数重み付け（A特性など）や測定時間を併記しない数値は、比較条件が不足します。

### <a id="term-3"></a>3. 音響パワー

正式名称
Sound Power

意味
音源が単位時間に放射する音のエネルギーで、単位はW（ワット）です。部屋の位置や距離に直接依存する音圧とは異なり、音源の出力を評価する量です。

### <a id="term-4"></a>4. デシベル

正式名称
decibel (dB)

意味
二つの量の比を対数で表す単位で、電圧・音圧の振幅比は20 log10、電力比は10 log10を使います。基準値が異なるdBu、dBV、dB SPL、dBFSは同じdBでも意味が違います。

### <a id="term-5"></a>5. dBu

正式名称
decibel referenced to 0.775 volts

意味
0.775 Vrmsを0 dBuとする電圧レベルで、dBu = 20 log10(Vrms/0.775)です。たとえば+4 dBuは約1.228 Vrmsで、機器の公称ラインレベルを示す用途があります。

### <a id="term-6"></a>6. dBV

正式名称
decibel referenced to 1 volt

意味
1 Vrmsを0 dBVとする電圧レベルで、dBV = 20 log10(Vrms/1)です。-10 dBVは約0.316 Vrmsで、機器仕様の基準をdBuと混同しないようにします。

### <a id="term-7"></a>7. dBFS

正式名称
decibels relative to full scale

意味
デジタル系の許容最大値（フルスケール）を0 dBFSとする相対レベルで、通常は0 dBFSを超えるとサンプル値がクリップします。サンプルピークのdBFSと、再生時の補間ピークを示すdBTP（true peak）は別物です。

### <a id="term-8"></a>8. 実効値

正式名称
Root Mean Square (RMS) value

意味
交流波形が同じ抵抗で生む電力に対応する値で、波形を二乗し平均して平方根を取ります。正弦波ならVrms = Vpeak/√2であり、ピーク値や平均値とは異なります。

### <a id="term-9"></a>9. 周波数

正式名称
Frequency

意味
周期的な現象が1秒間に繰り返す回数で、単位はHzです。音では周波数が高いほど一般に高い音程として知覚されますが、音色は倍音や時間変化にも左右されます。

### <a id="term-10"></a>10. 波長

正式名称
Wavelength

意味
波が同じ位相になる点どうしの距離で、単位はmです。平面波では波長λ = 音速c/周波数fなので、周波数が高いほど短くなります。

### <a id="term-11"></a>11. 音速

正式名称
Speed of Sound

意味
空気中を音の波面が伝わる速度で、温度などで変化し、20℃付近では約343 m/sです。距離による遅延を見積もるときは、実際の温度・経路・反射を考慮します。

### <a id="term-12"></a>12. 位相

正式名称
Phase

意味
周期波形の基準時点に対する進み遅れを角度（360°で1周期）またはラジアンで表します。位相は時間位置の概念で、信号を反転する極性とは別の用語です。

### <a id="term-13"></a>13. 極性

正式名称
Polarity

意味
信号の正負や機械的な向きが基準に対して同じか反転しているかを表します。片方のスピーカーやマイクだけ極性が反転すると、低域を中心に相殺が起こることがあります。

### <a id="term-14"></a>14. 干渉

正式名称
Interference

意味
複数の波が重なって振幅が加算または減算される現象です。同相なら強め合い、周波数ごとの位相差がずれると特定帯域が弱くなるコムフィルターになります。

### <a id="term-15"></a>15. 反射

正式名称
Reflection

意味
音波が壁や床などの境界で跳ね返り、入射角と反射角が関係する現象です。直接音との時間差が短い反射は音色を変え、長い反射はエコーとして聞こえます。

### <a id="term-16"></a>16. 吸音

正式名称
Sound Absorption

意味
材料が入射音の一部を熱などへ変換し、反射音を減らす作用です。吸音率は周波数で変わるため、厚さ・空気層・材料だけでなく対象帯域を選びます。

### <a id="term-17"></a>17. 拡散

正式名称
Sound Diffusion

意味
音を特定方向へ強く反射せず、空間に時間的・空間的に分散させることです。拡散体は残響を保ちながらフラッターエコーや局所的な反射集中を抑えます。

### <a id="term-18"></a>18. 残響

正式名称
Reverberation

意味
音源停止後も室内の多数の反射音が重なって続く現象です。適度な残響は自然さを与えますが、長すぎると音声明瞭度を下げます。

### <a id="term-19"></a>19. 残響時間

正式名称
Reverberation Time (RT60)

意味
音源を止めてから音圧レベルが60 dB低下するまでの時間です。測定できない場合に推測せず、室容積・吸音面積・周波数帯を分けて評価します。

### <a id="term-20"></a>20. フラッターエコー

正式名称
Flutter Echo

意味
平行な硬い面の間で短い反射が規則的に往復し、パタパタした反復音になる現象です。壁面の角度変更、吸音、拡散で反射の規則性を崩します。

### <a id="term-21"></a>21. 定在波

正式名称
Standing Wave

意味
反射波と進行波が同じ周波数で重なり、節と腹が固定されたように生じる波です。室内寸法に対応する低域モードで、位置によって音圧が大きく変わります。

### <a id="term-22"></a>22. 近接効果

正式名称
Proximity Effect

意味
指向性マイクを音源へ近づけたとき、低域が相対的に増える現象です。距離やマイクの指向特性で量が変わるため、声の厚み付けにも低域過多の補正にも使えます。

### <a id="term-23"></a>23. 指向性

正式名称
Directivity

意味
音源またはマイクの方向による感度・放射レベルの違いです。指向性パターンは周波数で変わるので、正面の仕様だけで配置を決めません。

### <a id="term-24"></a>24. 無指向性

正式名称
Omnidirectional

意味
理想上、全方向からほぼ同じ感度で音を受ける、または全方向へ放射する特性です。近接効果が小さい一方、室内音やハウリング対策では配置が重要です。

### <a id="term-25"></a>25. 単一指向性

正式名称
Unidirectional

意味
主に一方向からの音を強く受け、側面・背面を減衰させる特性です。カーディオイドなどが代表例で、背面の反射やモニター位置も確認します。

### <a id="term-26"></a>26. 双指向性

正式名称
Bidirectional

意味
正面と背面を受け、側面を大きく減衰させる8の字型の特性です。リボンマイクなどに多く、背面音と近接効果の扱いが必要です。

### <a id="term-27"></a>27. ダイナミックマイク

正式名称
Dynamic Microphone

意味
振動板に接続したコイルを磁界中で動かし、電磁誘導で信号を発生させます。比較的頑丈で大音圧に強い機種が多い一方、感度や高域特性は機種ごとに確認します。

### <a id="term-28"></a>28. コンデンサーマイク

正式名称
Condenser Microphone

意味
振動板と固定電極の静電容量変化を電気信号に変換し、内部回路を動作させる電源を必要とすることが多い方式です。ファンタム電源の電圧や入力保護を確認して接続します。

### <a id="term-29"></a>29. リボンマイク

正式名称
Ribbon Microphone

意味
磁界中に置いた薄い金属リボンの速度を電磁誘導で取り出すマイクです。双指向性が多く、強い風圧や誤ったファンタム供給からリボンを保護します。

### <a id="term-30"></a>30. ファンタム電源

正式名称
Phantom Power

意味
マイクケーブルの信号線へ、通常は+48 Vの直流を両線同じ電位で供給する方式です。平衡接続のコンデンサーマイク等に使い、接続変更時はミュートして機器仕様とケーブル状態を確認します。

### <a id="term-31"></a>31. バランス伝送

正式名称
Balanced Transmission

意味
信号線を基準線に対して同じインピーダンスで扱い、受信側の同相成分除去で外来ノイズを抑える伝送です。逆相信号が必須条件ではなく、二本の信号線に差があることと受信回路の同相除去が要点です。

### <a id="term-32"></a>32. アンバランス伝送

正式名称
Unbalanced Transmission

意味
信号線1本と共通のシールド・グラウンドで電圧を伝える方式です。短距離では便利ですが、グラウンド電位差や誘導ノイズの影響を受けやすいので配線長と電源系統に注意します。

### <a id="term-33"></a>33. インピーダンス

正式名称
Impedance

意味
交流に対する電圧と電流の比で、抵抗だけでなく周波数依存のリアクタンスを含む量です。入力インピーダンスは出力より十分高くし、スピーカー出力では許容負荷を下回らないようにします。

### <a id="term-34"></a>34. ゲイン

正式名称
Gain

意味
回路や処理段が信号を増幅または減衰する比率で、dBで表すことが多い量です。入力段のゲインはノイズとクリップ余裕を左右し、フェーダー位置とは役割が異なります。

### <a id="term-35"></a>35. ヘッドルーム

正式名称
Headroom

意味
公称動作レベルからクリップなどの非線形限界まで残っている余裕です。ピークが予測できない生演奏では、平均レベルを無理に上げず十分な余裕を確保します。

### <a id="term-36"></a>36. クリッピング

正式名称
Clipping

意味
増幅器や変換器の限界を超え、波形の頂点が切り取られる歪みです。アナログでは過大入力、デジタルではサンプルピークが0 dBFSに達することが主因です。

### <a id="term-37"></a>37. ノイズフロア

正式名称
Noise Floor

意味
信号がないときにも存在する機器・環境の雑音レベルです。ゲインを上げすぎると雑音も増幅されるため、必要信号を早い段階で適正レベルにします。

### <a id="term-38"></a>38. 信号対雑音比

正式名称
Signal-to-Noise Ratio (SNR)

意味
基準信号の電力または実効値と雑音の比をdBで示した値です。定義する信号レベル、帯域、重み付けが違えば値も変わるため、仕様の測定条件を確認します。

### <a id="term-39"></a>39. 全高調波歪率

正式名称
Total Harmonic Distortion (THD)

意味
入力周波数の整数倍である高調波成分の大きさを、基本波に対する比として表す歪率です。測定周波数・出力レベル・帯域を併記しないTHD値だけでは比較できません。

### <a id="term-40"></a>40. 周波数特性

正式名称
Frequency Response

意味
周波数ごとの出力レベルや位相が、入力に対してどう変わるかを示します。マイク・スピーカー・部屋の特性を分けて測定し、指定帯域と許容差を確認します。

### <a id="term-41"></a>41. イコライザー

正式名称
Equalizer (EQ)

意味
周波数帯ごとのゲインを増減して音色や明瞭度を調整する処理です。大きなブーストはヘッドルームを消費するため、不要帯域をカットしてから全体レベルを整える場合があります。

### <a id="term-42"></a>42. ハイパスフィルター

正式名称
High-Pass Filter (HPF)

意味
設定したカットオフ周波数より低い成分を減衰させ、高い成分を通すフィルターです。振動や空調などの不要低域を抑えますが、傾斜と位相変化も確認します。

### <a id="term-43"></a>43. ローパスフィルター

正式名称
Low-Pass Filter (LPF)

意味
カットオフ周波数より高い成分を減衰させ、低い成分を通すフィルターです。高域ノイズ抑制や帯域分割に使い、ナイキスト周波数近傍ではアンチエイリアスの考慮が必要です。

### <a id="term-44"></a>44. ノッチフィルター

正式名称
Notch Filter

意味
狭い周波数帯だけを深く減衰させる帯域阻止フィルターです。ハウリング周波数を狙うのに有効ですが、周波数を外すと効果がなく、広すぎる設定は音色を損ないます。

### <a id="term-45"></a>45. コンプレッサー

正式名称
Compressor

意味
設定したしきい値を超える信号のレベル差を小さくするダイナミクス処理です。比率、しきい値、アタック、リリース、ニー、メイクアップゲインを組み合わせ、過圧縮によるポンピングに注意します。

### <a id="term-46"></a>46. リミッター

正式名称
Limiter

意味
高い信号ピークを設定値以上にほぼ通さないようにする、非常に高比率のダイナミクス処理です。スピーカー保護に使えますが、平均音量を無制限に上げる装置ではありません。

### <a id="term-47"></a>47. アタック

正式名称
Attack Time

意味
コンプレッサーなどが検出したしきい値超過へ反応し始め、所定の減衰量へ到達するまでの時間です。短くするとピークを抑えやすく、長くするとアタック感を残しやすくなります。

### <a id="term-48"></a>48. リリース

正式名称
Release Time

意味
信号がしきい値を下回った後、処理による減衰が解除されるまでの時間です。短すぎるとレベルが揺れ、長すぎると次の音まで圧縮が残ります。

### <a id="term-49"></a>49. ゲート

正式名称
Noise Gate

意味
信号がしきい値未満になったとき、出力を減衰または閉じる処理です。ドラムの漏れ音を抑えられますが、リリースやホールドが不適切だと語尾や残響を切ります。

### <a id="term-50"></a>50. エキスパンダー

正式名称
Expander

意味
しきい値未満のレベル差をさらに広げ、静かな部分をより小さくする処理です。ゲートより滑らかなノイズ低減に使えますが、背景音の変化やポンピングを聴いて調整します。

### <a id="term-51"></a>51. ディレイ

正式名称
Delay

意味
信号を時間的に遅らせて出力する処理または装置です。反射の再現やスピーカーの到達時間補正に使え、遅延信号を原音へ混ぜると干渉が生じます。

### <a id="term-52"></a>52. フィードバック

正式名称
Feedback

意味
出力の一部が入力へ戻る経路またはその現象です。正帰還は発振を起こし得るため、マイクとスピーカーの距離・向き・ゲインを管理します。

### <a id="term-53"></a>53. ハウリング

正式名称
Acoustic Feedback

意味
拡声器の音がマイクへ戻り、特定周波数のループゲインが1以上になって発振する現象です。音量を下げ、配置を変え、必要なら狭いノッチで抑えます。

### <a id="term-54"></a>54. ミキサー

正式名称
Audio Mixer / Mixing Console

意味
複数入力のレベル、ルーティング、音色、ダイナミクスをまとめて扱う機器またはソフトウェアです。入力ゲイン、チャンネル処理、バス、マスターの順に信号経路を確認します。

### <a id="term-55"></a>55. フェーダー

正式名称
Fader

意味
チャンネルやバスの信号レベルを連続的に調整する操作子です。フェーダーは主にミックス内の送り量を決め、入力ゲインは前段の信号対雑音比とヘッドルームを決めます。

### <a id="term-56"></a>56. パンニング

正式名称
Panning

意味
信号を左右など複数の再生チャンネルへ配分する操作です。中央定位のレベル規則（センター減衰）やモノ互換性を確認して配置します。

### <a id="term-57"></a>57. AUXセンド

正式名称
Auxiliary Send (AUX Send)

意味
チャンネル信号の一部を補助バスへ送る出力経路です。プリフェーダーなら主フェーダーに影響されにくいモニター送り、ポストフェーダーなら効果音量と連動するリターン送りに使えます。

### <a id="term-58"></a>58. バス

正式名称
Bus

意味
複数の信号をまとめ、共通の処理や出力へ送る内部信号経路です。グループ、AUX、メインなど種類ごとに送り元・送り先とレベル構造を確認します。

### <a id="term-59"></a>59. ダイレクトアウト

正式名称
Direct Out

意味
特定チャンネルの信号をミックスやバスを経由せず個別に取り出す出力です。プリ・ポストゲインやプリ・ポストフェーダーの分岐位置は機器ごとに異なります。

### <a id="term-60"></a>60. インサート

正式名称
Insert

意味
チャンネル信号経路を一度外部機器へ出し、処理後に戻す接続点です。送出と返送の端子規格、レベル、アンバランス化によるノイズ、接続不良を確認します。

### <a id="term-61"></a>61. デジタル信号処理

正式名称
Digital Signal Processing (DSP)

意味
サンプリングした数値信号へ、加算・乗算・フィルターなどの演算を行う処理です。設定値だけでなく処理遅延、内部ビット深度、入出力レベルも音質と安全性に関係します。

### <a id="term-62"></a>62. アナログデジタル変換

正式名称
Analog-to-Digital Conversion (ADC)

意味
連続したアナログ信号をサンプリングし、各標本を量子化してデジタル値にする変換です。入力レベル、サンプリング周波数、ビット深度、アンチエイリアスフィルターを適切に設定します。

### <a id="term-63"></a>63. デジタルアナログ変換

正式名称
Digital-to-Analog Conversion (DAC)

意味
デジタル標本列から連続的なアナログ電圧・電流を再構成する変換です。再構成フィルターでサンプリングイメージを抑え、出力レベルと負荷条件を守ります。

### <a id="term-64"></a>64. サンプリング周波数

正式名称
Sampling Frequency / Sample Rate

意味
アナログ信号を1秒間に何回標本化するかを示し、単位はHzです。再現したい帯域の2倍を超える必要があり、48 kHzなら理論上のナイキスト周波数は24 kHzです。

### <a id="term-65"></a>65. ナイキスト周波数

正式名称
Nyquist Frequency

意味
サンプリング周波数fsの半分（fs/2）で、理想化したサンプリングで表現できる上限帯域です。48 kHzでは24 kHzですが、入力帯域をこの上限未満に制限しないとエイリアシングが起こります。

### <a id="term-66"></a>66. エイリアシング

正式名称
Aliasing

意味
標本化前に上限帯域を超えた成分が、低い別の周波数として折り返される歪みです。一度発生すると後段で元の成分と区別できないため、ADC前のローパスフィルターが必要です。

### <a id="term-67"></a>67. 量子化ビット数

正式名称
Bit Depth

意味
1標本の振幅を何ビットの段階で表すかを示す値です。理想的な量子化雑音の目安はビットあたり約6.02 dB改善しますが、実機のアナログ雑音や処理条件も効きます。

### <a id="term-68"></a>68. ディザ

正式名称
Dither

意味
量子化前に小さな雑音を加え、量子化誤差の周期的な歪みを平均化する技術です。ビット深度を下げる工程で有効ですが、最終段以外で重ねて加えないよう管理します。

### <a id="term-69"></a>69. ロッシー圧縮

正式名称
Lossy Compression

意味
知覚上影響が小さいと仮定した情報を捨て、データ量を減らす圧縮方式です。MP3などはビットレートや素材によりプリエコー・高域変化が生じるため、編集用マスターには適さない場合があります。

### <a id="term-70"></a>70. ロスレス圧縮

正式名称
Lossless Compression

意味
復号すると元のデジタルデータを完全に同一へ戻せる圧縮方式です。FLACなどは音質データを捨てませんが、圧縮率は内容によって変わります。

### <a id="term-71"></a>71. PCM

正式名称
Pulse Code Modulation

意味
音声振幅を一定間隔で標本化し、各値を量子化して数値列として表す方式です。サンプリング周波数とビット深度が帯域・量子化雑音・データ量を決めます。

### <a id="term-72"></a>72. ビットレート

正式名称
Bit Rate

意味
1秒あたりに扱うデジタルデータ量で、bit/sで表します。非圧縮PCMの概算はサンプリング周波数×ビット深度×チャンネル数で、48 kHz・24 bit・2chなら2.304 Mbit/sです。

### <a id="term-73"></a>73. PA

正式名称
Public Address (PA) system

意味
演者や再生機器の音を客席へ届ける拡声システムです。入力、ミキサー、信号処理、パワーアンプ、スピーカーを安全なレベルと配置で運用します。

### <a id="term-74"></a>74. モニター

正式名称
Monitor System

意味
演者や技術者が音を確認するためのスピーカー、イヤホン、ヘッドホンまたはその系統です。客席用PAと目的・送り・音量が異なるため、ハウリングと聴覚保護を別に管理します。

### <a id="term-75"></a>75. スピーカーアレイ

正式名称
Loudspeaker Array

意味
複数のスピーカーを配置・駆動して、必要な指向性・音圧分布・帯域を作る構成です。間隔や遅延が不適切だと干渉によるムラが増えるため、設計値と実測を照合します。

### <a id="term-76"></a>76. タイムアライメント

正式名称
Time Alignment

意味
複数経路の信号が同じ聴取点へほぼ同時に届くよう、遅延や配置を調整することです。測定マイクで到達時間を確認し、極性・周波数帯・基準位置を変えずに設定します。

### <a id="term-77"></a>77. 音響測定

正式名称
Acoustic Measurement

意味
音圧、周波数特性、残響、インパルス応答などを、校正した測定系で定量化する作業です。測定位置、信号、時間窓、重み付け、環境を記録しない結果は再現性がありません。

### <a id="term-78"></a>78. ラウドネス

正式名称
Loudness

意味
人が感じる音の大きさで、音圧だけでなく周波数、時間、マスキングに依存する知覚量です。LUFSなどの測定値は特定の規格・重み付けに基づくため、SPLと同一視しません。

### <a id="term-79"></a>79. 聴覚安全

正式名称
Hearing Safety

意味
過大な音圧や長時間曝露による聴力損傷を避けるため、音量・時間・距離・休憩を管理する考え方です。測定可能なSPLを監視し、保護具を使い、突然の大音量を出さない手順を設けます。

### <a id="term-80"></a>80. 信号フロー

正式名称
Signal Flow

意味
音声信号が入力から処理、分岐、出力へ進む経路を示します。各段のゲイン、ミュート、パッチ、レベルメーターを順に追うと、音が出ない・歪む原因を切り分けられます。

### <a id="term-81"></a>81. 録音

正式名称
Recording

意味
音をマイクやライン入力から取り込み、記録媒体へ保存する工程です。入力ゲインでピークの余裕を確保し、サンプルレート、ビット深度、ファイル形式、バックアップを事前に決めます。

### <a id="term-82"></a>82. ミックス

正式名称
Mixing

意味
複数トラックの音量、定位、音色、ダイナミクス、空間系を整え、ステレオなどのまとまった出力を作る工程です。各処理の前後を聴き、ピークとラウドネスを管理します。

### <a id="term-83"></a>83. マスター

正式名称
Mastering

意味
完成ミックスを配布媒体や再生環境に合わせて最終確認・調整し、納品データを作る工程です。音量だけでなく、サンプルレート、ビット深度、ピーク、メタデータ、曲間を検証します。

### <a id="term-84"></a>84. 同期

正式名称
Synchronization

意味
複数機器の時間基準や動作タイミングを一致させることです。デジタル音声ではサンプルクロックの不一致によるドロップやクリックを防ぐため、基準クロックとロック状態を確認します。

### <a id="term-85"></a>85. タイムコード

正式名称
Time Code

意味
映像・音声・照明などの位置を時刻形式の数値で表す情報です。SMPTE/時間・分・秒・フレーム等の規格とフレームレートを一致させ、音声サンプルクロックそのものと混同しません。

### <a id="term-86"></a>86. SPLメーター

正式名称
Sound Pressure Level Meter

意味
マイクで測った音圧を、基準20 µPaに対するdB SPLとして表示する測定器です。A/C/Z特性、Fast/Slow応答、校正状態、マイク位置を記録して比較します。

### <a id="term-87"></a>87. 校正

正式名称
Calibration

意味
測定器や信号経路の表示を既知の基準へ合わせ、測定結果の信頼性を確保する作業です。音響では音圧校正器の周波数・レベルと測定マイクの組合せを確認し、実施日を記録します。

### <a id="term-88"></a>88. DIボックス

正式名称
Direct Injection (DI) Box

意味
楽器などのアンバランス・高インピーダンス信号を受け、低インピーダンスのバランス信号へ変換して卓へ送る装置です。パッシブ／アクティブ、パッド、グラウンドリフト、ファンタム可否を接続先と照合します。

### <a id="term-89"></a>89. ラインレベル

正式名称
Line Level

意味
機器間で音声を受け渡すための公称電圧範囲で、業務用+4 dBuや民生用-10 dBVなど基準が異なります。マイクレベルより高いので、入力感度を間違えると過大入力になります。

### <a id="term-90"></a>90. マイクプリアンプ

正式名称
Microphone Preamplifier

意味
マイクの微小な出力を、ミキサーやADCが扱えるライン付近まで低雑音で増幅する回路です。必要ゲイン、入力インピーダンス、ファンタム、パッド、位相反転を確認します。

### <a id="term-91"></a>91. 音響機構調整作業

正式名称
Stage Equipment Adjustment Work (Audio Equipment Adjustment)

意味
舞台上の音響機器を安全に設置・接続・調整し、リハーサル、ミキシング、原状復帰まで行う作業です。技能検定の3級案内では、音源によるセッティング・リハーサル・本番ミキシング・復帰と、音の判別が実技に含まれます。

### <a id="term-92"></a>92. 残響室

正式名称
Reverberation Room

意味
反射性の高い室内で音を拡散させ、吸音率や音響パワーなどを測るための試験室です。拡散条件や測定規格を満たす必要があり、通常の演奏会場とは目的が異なります。

### <a id="term-93"></a>93. 無響室

正式名称
Anechoic Room

意味
壁・床・天井に吸音くさび等を設け、反射音を極力抑えて音源の直接音を測る室です。自由音場に近い条件を作りますが、低域限界や測定対象の大きさに制約があります。

### <a id="term-94"></a>94. 音声明瞭度

正式名称
Speech Intelligibility

意味
話し言葉の内容を正しく聞き取れる度合いです。直接音と残響・雑音の比、帯域、音量、話者、測定指標（STIなど）に左右され、単なる大音量化では改善しません。

### <a id="term-95"></a>95. オクターブバンド

正式名称
Octave Band

意味
上限周波数が下限周波数の2倍となる帯域で、中心周波数ごとに音響量を整理します。1/3オクターブは隣接帯域の比が2^(1/3)で、測定やイコライザー調整に使います。

### <a id="term-96"></a>96. 位相差

正式名称
Phase Difference

意味
二つの同一周波数成分の位相のずれを角度または時間差で表します。時間差Δtの位相差は360°×f×Δtなので、周波数が変わると同じ時間差でも角度が変わります。

### <a id="term-97"></a>97. 遅延

正式名称
Latency / Delay

意味
信号がある点から別の点へ到達・処理されるまでの時間です。音速による空間遅延とADC・DSP・ネットワークなどの機器遅延を分け、複数経路の相対差を補正します。

### <a id="term-98"></a>98. サイドチェイン

正式名称
Sidechain

意味
コンプレッサーやゲートなどの検出回路へ、処理対象とは別の制御信号を入力する経路です。たとえばキックを検出信号にしてベースを一時的に下げるダッキングができます。

### <a id="term-99"></a>99. ステレオ

正式名称
Stereophonic Sound (Stereo)

意味
左右など二つ以上のチャンネルへ異なるレベル・時間・位相情報を配分し、方向感や広がりを作る方式です。左右の極性・遅延・モノ合成時の相殺を確認します。

### <a id="term-100"></a>100. モノラル

正式名称
Monaural Sound (Mono)

意味
一つの音声チャンネルとして信号を扱う方式です。複数マイクをモノへまとめるときは位相差・極性・レベル差による低域減衰を確認します。

## 技術上の注意

電圧・音圧の比は20 log10、電力の比は10 log10です。dBFSのサンプルピークとdBTPのtrue peakは別指標で、SPLの基準音圧は20 µPa、dBuは0.775 Vrms、dBVは1 Vrmsです。
