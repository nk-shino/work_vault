# 音響 発展用語（設計・測定・規格）

書式は `_用語集の書き方と回し方.md` のとおり。**正式名称・直訳・意味の3点。**

**`Audio_Certification_Glossary.md` の先。**あちらは共通基礎（音圧・dB・位相・残響・定在波）で、
**こちらは「数値で設計し、測って確かめる」側を扱う。**基礎にある語は繰り返さない。

**この分野は略語の壁が高い。**`NAG` `STI` `CMRR` `HRTF` は、
展開しないと何の話か分からない。**直訳を入れると筋が通る。**

関連: `Vocal_Synthesis_Glossary.md`（LUFS・RT60・トゥルーピークはそちらに重複を置かず、
測り方の文脈でこちらに書いた）

## 1. 電気的に繋ぐ

### インピーダンス

- **正式名称**: impedance（impedire = 妨げる から）
- **直訳**: 妨げるもの
- **意味**: **交流に対する電気の通りにくさ。**直流の抵抗と違い、周波数で値が変わる
- **混同**: **「妨げる」が直訳なので、低いほうが良いと思いやすいが違う。**送る側は低く、受ける側は高いのが基本

### ロー出しハイ受け

- **正式名称**: low output impedance / high input impedance
- **直訳**: 低い・出力の妨げ ／ 高い・入力の妨げ
- **意味**: **送る側の内部抵抗を低く、受ける側を高くする繋ぎ方。**こうすると信号がほぼそのまま渡る
- **混同**: **逆にすると音が痩せて高域が落ちる。**壊れないので気づきにくい。「なんとなく元気がない」の原因

### バランス伝送

- **正式名称**: balanced transmission
- **直訳**: 釣り合った・伝送
- **意味**: **同じ信号を正負ひと組で送り、受け側で引き算する。**途中で乗ったノイズは両方に同じだけ乗るので、引き算で消える
- **混同**: **ケーブルが3芯だから強いのではなく、引き算をしているから強い。**受け側が引き算しなければ意味がない

### CMRR

- **正式名称**: Common Mode Rejection Ratio
- **直訳**: 共通の・様式を・はねのける・比
- **意味**: **両方に同じだけ乗った成分を、どれだけ消せるかの比。**バランス伝送の実力そのもの
- **混同**: 数字が大きいほど強い。**仕様に書いてある値は特定の周波数での値**で、高域では落ちる

### グランドループ

- **正式名称**: ground loop
- **直訳**: 接地の・輪
- **意味**: **機器を繋いだ結果、接地が輪になってそこに電流が流れる。**電源周波数のうなりが出る
- **混同**: **ケーブルを良いものに替えても直らない。**輪を切る（接地を1点にする）以外に解決しない

### ファンタム電源

- **正式名称**: phantom power
- **直訳**: 幽霊の・電源
- **意味**: **信号線と同じ線で、マイクへ電源を送る仕組み。**専用の電源線が無いのに電気が来るので「幽霊」
- **混同**: **リボンマイクや一部の機器に入れると壊れる。**繋いでから入れる、切ってから抜く

## 2. 拡声を設計する

### 指向係数

- **正式名称**: directivity factor（Q）
- **直訳**: 向きを持つ・度合い
- **意味**: **音を前へどれだけ集められるかの数値。**全方向に等しく出るなら1、狭く絞るほど大きくなる
- **混同**: **音を増やしているのではなく、向きを変えているだけ。**絞れば前は大きくなるが横は小さくなる

### 指向指数

- **正式名称**: Directivity Index（DI）
- **直訳**: 向きを持つことの・指数
- **意味**: 指向係数をデシベルで表したもの。**`DI = 10 log Q`**
- **混同**: Q と DI は同じことを別の目盛りで言っている。**足し算で扱いたいときに DI を使う**

### 感度

- **正式名称**: sensitivity
- **直訳**: 感じやすさ
- **意味**: スピーカーに**決めた電力を入れたとき、決めた距離で出る音圧。**例: 1W / 1m
- **混同**: **感度が高いほうが少ない電力で鳴る。**最大音量とは別の話

### NAG / PAG

- **正式名称**: Needed Acoustic Gain / Potential Acoustic Gain
- **直訳**: 必要な・音の・増し分 ／ 可能な・音の・増し分
- **意味**: **どれだけ増幅が要るか（NAG）と、ハウリングせずにどれだけ増幅できるか（PAG）。**設計は `PAG > NAG` を満たすかの確認
- **混同**: **「音量が足りない」は機器の力の問題ではなく、この不等式が成り立っていない問題。**アンプを大きくしても解決しない

### ハウリングマージン

- **正式名称**: feedback margin / gain before feedback
- **直訳**: （音が）戻ってくるまでの・余裕
- **意味**: **ハウリングが始まる手前まで、あとどれだけ上げられるか**
- **混同**: **余裕が小さいと、人が動くだけでハウる。**本番は余裕を6dB程度残す、という目安はここから来る

### 臨界距離

- **正式名称**: critical distance
- **直訳**: 分かれ目の・距離
- **意味**: **直接届く音と、部屋の反射音が同じ大きさになる距離。**ここより遠いと、近づいても聞き取りやすさが上がらない
- **混同**: **音量は距離で下がり続けるが、聞き取りやすさは臨界距離から先はほぼ変わらない。**別の性質

### D/R比

- **正式名称**: Direct-to-Reverberant ratio
- **直訳**: 直接の音と・響いた音の・比
- **意味**: 直接音と残響音の比。**聞き取りやすさを決める本体**
- **混同**: 残響を減らすのと、直接音を増やすのは**どちらも同じ方向に効く。**吸音材か、スピーカーを近づけるか

## 3. 聞き取りやすさを測る

### STI

- **正式名称**: Speech Transmission Index
- **直訳**: 話し言葉の・伝わり方の・指数
- **意味**: **言葉がどれだけ正確に伝わるかを0〜1で表す。**残響・雑音・反射をまとめて1つの数値にする
- **混同**: **音量とは無関係。**大きくても伝わらない部屋はある。非常放送の設計で使われる

### %ALcons

- **正式名称**: percentage Articulation Loss of consonants
- **直訳**: 百分率で表した・子音の・明瞭さの・損失
- **意味**: **子音が何パーセント聞き取れないかを表す。**小さいほど良い
- **混同**: **STI とは逆向き。**STIは大きいほど良く、%ALconsは小さいほど良い。混ぜると判断が逆になる
- **なぜ子音か**: **母音は大きく長いので、よほど悪くても残る。**言葉が崩れるときは子音から崩れる

### インパルス応答

- **正式名称**: impulse response
- **直訳**: 衝撃に対する・応え
- **意味**: **一瞬の音を出して、部屋がどう返してくるかを記録したもの。**ここから残響時間も明瞭度も計算できる
- **混同**: **測るのは部屋ではなく「その場所とその場所の間」。**マイクを動かせば結果は変わる

### 1/3オクターブ分析

- **正式名称**: one-third octave band analysis
- **直訳**: オクターブの3分の1の・帯域の・分析
- **意味**: **周波数を人の聞こえ方に近い幅で区切って測る。**1オクターブでは粗く、FFTの細かさでは読めない、その間
- **混同**: **FFTと目的が違う。**FFTは細かく見るため、1/3オクターブは判断するため

### ピンクノイズ

- **正式名称**: pink noise
- **直訳**: 桃色の・雑音
- **意味**: **オクターブごとのエネルギーが等しい雑音。**人の聞こえ方に近いので測定の基準に使う
- **混同**: ホワイトノイズは**周波数ごとに等しい**ので、聞くと高域に偏って聞こえる。**色の名前は光のスペクトルの比喩**

### コヒーレンス

- **正式名称**: coherence
- **直訳**: 一貫していること
- **意味**: **測った結果のうち、入力と因果関係がある割合。**低いと、測定値そのものが信用できない
- **混同**: **周波数特性のグラフだけ見て判断してはいけない理由。**コヒーレンスが低い帯域の山谷は雑音

## 4. デジタルで繋ぐ

### AES3

- **正式名称**: AES3（Audio Engineering Society standard 3。民生側は S/PDIF）
- **直訳**: （規格番号）
- **意味**: 2chのデジタル音声を1本で送る規格。**業務用はXLR、民生はRCAや光**
- **混同**: **同じ信号でも端子と電圧が違う。**変換は単純な結線ではできない

### ワードクロック

- **正式名称**: word clock
- **直訳**: 語の・時計
- **意味**: **標本1つ（= 1 word）の刻みを機器間で揃えるための信号。**揃っていないと、繋いだ機器がそれぞれの時計で動く
- **混同**: **音声信号とは別の線。**音が出ていても同期は取れていないことがある

### ジッタ

- **正式名称**: jitter
- **直訳**: 小刻みな震え
- **意味**: **刻みのタイミングの揺らぎ。**本来等間隔のはずの標本が、わずかにずれる
- **混同**: **データは正しいのに音が悪くなる。**値が合っていても、取り出す時刻がずれると波形が崩れる

### Dante / AVB

- **正式名称**: Dante（Digital Audio Network Through Ethernet）／ AVB（Audio Video Bridging）
- **直訳**: イーサネットを通した・デジタル音声の・網 ／ 音声と映像の・橋渡し
- **意味**: **LANケーブルで多チャンネルの音声を送る方式。**配線が劇的に減る
- **混同**: **普通のネットワークと同じ線を使うが、同じ扱いはできない。**遅延の上限を守るため、機器や設定に条件がつく

### レイテンシ

- **正式名称**: latency
- **直訳**: 潜んでいること・遅れ
- **意味**: 入ってから出るまでの遅れ
- **混同**: **演奏者が気づくのは数ミリ秒から。**聞き取りには影響しない遅れでも、演奏はできなくなる

## 5. 規格と運用

### ITU-R BS.1770

- **正式名称**: ITU-R Recommendation BS.1770
- **直訳**: （勧告番号）
- **意味**: **ラウドネス（LUFS）の測り方を定めた国際勧告。**周波数ごとの補正と平均の取り方が書かれている
- **混同**: **LUFS という単位の定義はここ。**各国の放送規格はこれを引用して、目標値だけ自分で決めている

### EBU R128

- **正式名称**: EBU Recommendation R128
- **直訳**: （勧告番号）
- **意味**: 欧州放送連合の運用規格。**目標 -23 LUFS**
- **混同**: 測り方は BS.1770 と同じ。**違うのは目標値と、短時間の見方**

### ARIB TR-B32

- **正式名称**: ARIB Technical Report B32
- **直訳**: （技術資料番号）
- **意味**: 日本の放送のラウドネス運用規格。**目標 -24 LKFS**
- **混同**: **LKFS と LUFS は同じもの。**呼び方が違うだけ。規格の系統で用語が分かれた

### 許容曝露

- **正式名称**: permissible exposure limit
- **直訳**: 許される・さらされ方の・限界
- **意味**: **ある音圧レベルに、1日あたりどれだけさらされてよいかの上限。**レベルが3dB上がると、許される時間は半分になる
- **混同**: **「うるさい」と感じるかどうかとは無関係。**慣れても損傷は進む。**聴力は戻らない**

## 6. 立体で鳴らす

### チャンネルベース / オブジェクトベース

- **正式名称**: channel-based / object-based audio
- **直訳**: 回路を基にした ／ 物を基にした
- **意味**: **前者は「どのスピーカーから出すか」を決めて録る。後者は「どこで鳴っているか」を記録し、再生側が持っているスピーカーに合わせて割り振る**
- **混同**: **オブジェクトベースは、再生環境が分からなくても作れる。**その代わり、どう鳴るかを作り手が決めきれない

### HRTF

- **正式名称**: Head-Related Transfer Function
- **直訳**: 頭に・関係する・伝達の・関数
- **意味**: **頭と耳の形で音がどう変わるかを表した関数。**これを掛けると、ヘッドホンでも方向が感じられる
- **混同**: **人によって頭の形が違うので、他人の関数では合わない。**「人によってバイノーラルの効きが違う」のはこれ

### アンビソニックス

- **正式名称**: Ambisonics（ambi = 周囲 + sonics = 音）
- **直訳**: 周囲の・音
- **意味**: **スピーカーの位置を前提にせず、音の場そのものを球面の成分で記録する方式**
- **混同**: **次数を上げると精度が上がるが、必要なチャンネル数が二乗で増える**（n次で (n+1)²）

### バイノーラル

- **正式名称**: binaural
- **直訳**: 両の・耳の
- **意味**: **左右の耳の位置で録る、または計算する。**ヘッドホン前提
- **混同**: **スピーカーで再生すると崩れる。**両耳に別々に届くことが前提

## 7. 覚える順番

1. **インピーダンスとバランス伝送。**繋がらない・ノイズが出るの大半がここ
2. **NAG / PAG と臨界距離。**「音量が足りない」を機器の話にしないための足場
3. **STI と %ALcons。**向きが逆なので、必ず一緒に覚える
4. **インパルス応答とコヒーレンス。**測った数字を信じてよいかの判断
5. **BS.1770 → R128 / TR-B32 の順。**測り方が1つ、目標値が国ごと
6. 立体（§6）は最後。**上が通っていないと、何が効いているか分からない**

**§5 の許容曝露だけは先に読む。**ここだけは取り返しがつかない。
