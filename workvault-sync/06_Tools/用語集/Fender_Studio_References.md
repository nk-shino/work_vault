# Fender Studio参照

## 最新対象と確認履歴

対象は製品版を特定していないFender Studio無料版。以下の確認日は公開資料を読んだ日であり、アプリの版番号や製品版を意味しない。

- [Fender公式「How To Use Fender Studio With Compatible Interfaces」](https://www.fender.com/articles/parts-and-accessories/how-to-use-fender-studio-with-compatible-interfaces)（確認日: 2026-10-02）: 録音、停止、再生、Preferences > Audio Setup、Record Device、Playback Device、対応インターフェース、端子、USB-Cを確認。
- [Fender公式「Audio Monitoring & Signal Routing in Fender Studio」](https://www.fender.com/articles/fender-studio/audio-monitoring-and-signal-routing-in-fender-studio)（確認日: 2026-10-02）: audio monitoring、signal routing、Audio Setupの説明を確認。
- [Fender公式「Import & Export Audio in Fender Studio」](https://www.fender.com/articles/fender-studio/import-and-export-audio-in-fender-studio)（確認日: 2026-10-02）: 音声ファイルのインポートとエクスポートを扱う記事を確認。拡張子、保存先、詳細UIは未取得。
- [Fender Support「Fender Studio Release Notes」](https://support.fender.com/en-us/knowledgebase/article/KA-02275)（確認日: 2026-10-02）: iOS、macOS、Windows、Android、Linux向けの案内を確認。個別版の要件は未取得。
- [Fender Support「Fender Studio Installation Guide」](https://support.fender.com/en-us/knowledgebase/article/KA-02274)（確認日: 2026-10-02）: 登録後にtracks、amps、effects、Jam Tracksが解除される案内を確認。個別モデルや数量は未取得。
- [Fender公式「Fender Studio Pro」](https://www.fender.com/products/fender-studio-pro)（確認日: 2026-10-02）: 別製品としてのFender Studio Proを確認。無料Fender Studioの機能根拠には使用しない。

## 未取得・未確認

対応OSの版ごとの必要条件、登録の必須性、トラック上限、MIDI録音、音声ファイルの拡張子・保存先、アンプシミュレーターとエフェクトの個別モデル・操作、Jam Tracksの種類と数、実際の編集機能は今回の対象資料から未取得または未確認である。未確認は非搭載を意味せず、対象版の公式ヘルプまたはアプリ画面を別途確認する事項として残す。

## 復習手順

まず「録音デバイス→Audio Setup→録音開始→停止→再生」の順に声に出して確認し、録音デバイスと再生デバイスの向きを区別する。次に音声とMIDI、録音とモニター、インポートとエクスポートをそれぞれ一文で説明し、Refsの未取得欄と照合する。

実機・実OSでの操作検証は未実施であり、本文は公式Web資料の確認記録に基づく。
