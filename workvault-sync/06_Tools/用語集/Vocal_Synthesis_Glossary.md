# 音声合成・歌唱合成の制作用語

書式は `_用語集の書き方と回し方.md` のとおり。**正式名称・直訳・意味の3点。**

**この分野は略語と造語が多い。**`LUFS` も `VEL` も `NSF` も、
展開しないと記号のままになる。**直訳を入れると、名前が機能の説明になる。**

関連: `Music_Theory_Glossary.md`（楽典）・`Audio_Certification_Glossary.md`（音響）・
`Xsynth_Glossary.md`（合成器）・`Fender_Studio_Glossary.md`（編集環境）

## 1. 合成の方式

### 素片接続合成

- **正式名称**: concatenative synthesis
- **直訳**: 鎖のように繋ぐ・合成
- **意味**: **実際の人の声を細かく切って録り、それを繋いで歌わせる方式。**初期の歌唱合成はこれ。「鎖で繋ぐ」が直訳そのままで、素片の境目をどう滑らかにするかが品質を決める
- **混同**: **音の高さを変えると声の質も変わってしまう**のが原理的な弱点。録った高さから離れるほど無理が出る

### 統計的パラメトリック合成

- **正式名称**: Statistical Parametric Speech Synthesis（SPSS）
- **直訳**: 統計にもとづく・媒介変数による・音声合成
- **意味**: 声を直接繋ぐのではなく、**声の特徴を数値（媒介変数）に落として、その数値を統計モデルで作る方式。**滑らかだが、こもった音になりやすい
- **混同**: 素片接続より自然に繋がるが、**平均に寄るので輪郭がぼやける。**統計の性質そのもの

### ニューラル音声合成

- **正式名称**: neural speech synthesis
- **直訳**: 神経網による・音声合成
- **意味**: 波形そのもの、または波形に近い表現を学習して作る方式。**現在の主流**
- **混同**: **学習データに無い歌い方は出せない。**「何でもできる」のではなく、学習の範囲が上限

### ボコーダ

- **正式名称**: vocoder（**vo**ice + **coder**）
- **直訳**: 声を・符号化するもの
- **意味**: **声を「基本周波数」「音色」「かすれ具合」などの成分に分解し、必要なら組み直す仕組み。**もともとは通信の帯域を節約するための技術で、音楽用途は転用
- **混同**: 音楽で言う「ボコーダー（声をシンセで鳴らすエフェクト）」と、**合成の内部で使う分析・再合成のボコーダは別の話。**同じ語が指す対象が違う

### WORLD

- **正式名称**: WORLD（vocoder の実装名。頭字語ではない）
- **直訳**: （固有名詞）
- **意味**: 声を **F0（基本周波数）・スペクトル包絡・非周期性指標** の3つに分けて分析し、組み直せるボコーダ。**歌唱合成でよく使われる**
- **混同**: **3成分に分けるのが要点。**高さ・音色・かすれを別々に触れるので、「高さだけ変えて声質は保つ」ができる

### NSF

- **正式名称**: Neural Source-Filter model
- **直訳**: 神経網による・音源と濾過器の・模型
- **意味**: **声を「音源（声帯の振動）」と「濾過器（口や鼻の形）」に分けて考える古典的な考え方を、神経網で実装したもの**
- **混同**: **ソースフィルタ理論そのものは1960年代の話。**新しいのは実装のほうだけ

## 2. 声道と音色

### フォルマント

- **正式名称**: formant（formare = 形づくる から）
- **直訳**: 形づくるもの
- **意味**: **口や喉の形で強められる周波数の山。**この山の位置で母音が決まる。「あ」と「い」の違いは、声の高さではなくフォルマントの位置の違い
- **混同**: **音の高さを変えてもフォルマントは動かないのが自然な声。**両方一緒に動くと、早回し再生のような声になる

### ソースフィルタ理論

- **正式名称**: source-filter theory
- **直訳**: 音源と・濾過器の・理論
- **意味**: **声は「音源（声帯の振動）」が「濾過器（声道の形）」を通って出てくる、と分けて考えるモデル。**音源が高さを決め、濾過器が母音を決める
- **混同**: **この分離があるから、高さと母音を別々に操作できる。**歌唱合成の根っこの考え方

### スペクトル包絡

- **正式名称**: spectral envelope
- **直訳**: 周波数分布の・外袋
- **意味**: 周波数ごとの強さの、**山谷を均した外側の輪郭。**声質はほぼここで決まる
- **混同**: 倍音1本1本の高さ（細かい櫛の歯）とは別。**包絡は櫛を包む袋のほう**

### 非周期性指標

- **正式名称**: aperiodicity
- **直訳**: 周期を持たないこと・の度合い
- **意味**: **声に混ざる、規則的でない成分の割合。**息の音、かすれ、ざらつき
- **混同**: ノイズと呼ぶと「邪魔なもの」に聞こえるが、**これが無いと機械的な声になる。**必要な成分

### ジェンダーファクター

- **正式名称**: gender factor
- **直訳**: 性別の・因子
- **意味**: **フォルマントの位置をまとめて上下させる操作。**下げると太く、上げると細く聞こえる
- **混同**: **高さは変わらない。**変わるのは声道の大きさの印象だけ

## 3. 歌わせるときの媒介変数

**製品によって名前が違うが、指しているものは共通。**

### F0

- **正式名称**: fundamental frequency（基本周波数）
- **直訳**: 基礎となる・振動数
- **意味**: **声の高さそのもの。**倍音の一番下
- **混同**: 楽譜上の音高は「狙い」で、**F0 は実際に出ている値。**この差が歌の表情になる

### ベロシティ

- **正式名称**: velocity（VEL）
- **直訳**: 速さ
- **意味**: 歌唱合成では**主に子音の長さと勢いに効く。**上げると子音が短く鋭くなる
- **混同**: **鍵盤楽器の「強く弾く」とは効き方が違う。**音量のパラメータではない

### ダイナミクス

- **正式名称**: dynamics（DYN）
- **直訳**: 力の働き
- **意味**: **声の張り。**音量だけでなく、張ったときの倍音の増え方まで一緒に変わる
- **混同**: フェーダーで音量を上げるのとは別。**音量を上げても張ったようには聞こえない**

### ブレシネス

- **正式名称**: breathiness（BRE）
- **直訳**: 息っぽさ
- **意味**: 息の成分（非周期性）の量
- **混同**: 上げると柔らかく聞こえるが、**上げすぎると子音が埋もれて歌詞が聞き取れなくなる**

### ブライトネス / クリアネス

- **正式名称**: brightness（BRI）／ clearness（CLE）
- **直訳**: 明るさ ／ 澄み具合
- **意味**: 高い側の倍音の量と、その輪郭のはっきりさ
- **混同**: **EQで高域を上げるのとは別。**合成の段で倍音を作る量が変わるので、歪まずに明るくなる

### オープニング

- **正式名称**: opening（OPE）
- **直訳**: 開き具合
- **意味**: **口の開きに相当する操作。**閉じ気味にすると籠る
- **混同**: 音量ではない。**同じ音量のまま、音色だけが変わる**

### ポルタメント

- **正式名称**: portamento（portare = 運ぶ から）
- **直訳**: 運ぶこと
- **意味**: **音から音へ高さを滑らせて移ること。**「運ぶ」が直訳そのまま
- **混同**: ピッチベンドは**任意の形に曲げる**操作、ポルタメントは**次の音へ向かう移り方**。目的が違う

### 調声

- **正式名称**: （日本語の制作用語。定訳なし。英語では vocal tuning / vocal editing）
- **直訳**: （和製の語。声を調える）
- **意味**: **打ち込んだままの状態から、高さ・長さ・媒介変数を人が調整していく作業全体**
- **混同**: ピッチ補正だけを指すのではない。**子音のタイミングと息の量のほうが、自然さには効く**

### ベタ打ち

- **正式名称**: （制作用語。英語では flat input / no expression）
- **直訳**: （和製の語。平らに打ち込む）
- **意味**: **音符と歌詞を入れただけで、調整を一切していない状態**
- **混同**: 出発点であって失敗ではない。**ベタ打ちで既に通じるメロディかどうかが、曲の良さの試金石になる**

## 4. 発音の指定

### 音素

- **正式名称**: phoneme
- **直訳**: 音の・素
- **意味**: **意味を区別する最小の音の単位。**「か」は `k` と `a` の2つに分かれる
- **混同**: 仮名1文字 = 音素1つではない。**この取り違えが、子音のタイミングを合わせられない原因になる**

### 発音記号

- **正式名称**: phonetic symbol
- **直訳**: 音声の・記号
- **意味**: 音素を書き表す記号。**仮名で書くより細かく指定できる**
- **混同**: 製品ごとに記号の体系が違う。**他の製品の記号をそのまま持ち込むと鳴らない**

### 子音の先行

- **正式名称**: consonant pre-utterance
- **直訳**: 子音の・先に発する分
- **意味**: **子音は拍の前から始まっている。**拍の頭に子音を置くと、聞こえ上は遅れて聞こえる
- **混同**: **ここが歌唱合成で最も「機械っぽさ」として現れる箇所。**音符どおりに置くと合わない

## 5. 混ぜる

### コンプレッサー

- **正式名称**: compressor
- **直訳**: 圧し縮めるもの
- **意味**: **決めた音量を超えた分だけ圧し縮める。**大小の差を詰めて、聞き取りやすくする
- **混同**: **音量を上げる道具ではない。**縮めてから全体を持ち上げるので、結果として大きく聞こえる

### アタック / リリース

- **正式名称**: attack / release
- **直訳**: 襲いかかる ／ 放す
- **意味**: 圧し始めるまでの時間と、圧すのをやめるまでの時間
- **混同**: **アタックを速くすると子音が潰れる。**歯切れが欲しいときは、むしろ遅くして子音を通す

### サイドチェイン

- **正式名称**: side-chain
- **直訳**: 脇の・鎖
- **意味**: **別の音を引き金にして効果をかける。**キックが鳴る瞬間だけベースを下げる、など
- **混同**: 「脇」が直訳の要点。**引き金になる音は出力されない。**判断材料としてだけ通る

### ディエッサー

- **正式名称**: de-esser
- **直訳**: s の音を・取り除くもの
- **意味**: **「サ」「シ」の耳に刺さる帯域だけを狙って抑える。**名前そのままで、`s` の音が対象
- **混同**: EQで高域を下げると**歌全体がこもる。**ディエッサーは刺さる瞬間だけ働く

### マルチバンドコンプレッサー

- **正式名称**: multiband compressor
- **直訳**: 複数の・帯域の・圧し縮めるもの
- **意味**: **周波数帯ごとに別々に圧し縮める。**低音が鳴った瞬間に全体が下がるのを防げる
- **混同**: **帯域を分けると位相がずれる。**分けすぎると輪郭が鈍る

### サチュレーション

- **正式名称**: saturation
- **直訳**: 飽和
- **意味**: **わざと軽く歪ませて倍音を足す。**同じ音量でも前に出て聞こえる
- **混同**: **音量は上がっていない。**倍音が増えて目立っているだけ。測ると上がっていないのに大きく聞こえる

### トランジェントシェイパー

- **正式名称**: transient shaper
- **直訳**: 過渡の・形を変えるもの
- **意味**: **音の出だしの一瞬だけを強めたり弱めたりする。**音量の大小とは別に、立ち上がりを操作する
- **混同**: コンプレッサーは**音量に反応**するが、これは**時間的な位置に反応**する

## 6. 空間

### リバーブ

- **正式名称**: reverberation
- **直訳**: 繰り返し響くこと
- **意味**: 部屋の反射。**音がどこで鳴っているかの印象を作る**
- **混同**: **掛けるほど遠ざかる。**前に出したいなら減らす

### プリディレイ

- **正式名称**: pre-delay
- **直訳**: 前の・遅れ
- **意味**: **直接音が届いてから、反射が来るまでの時間。**長くすると、歌が前に残ったまま空間が広がる
- **混同**: **これを0にすると、歌が壁に貼り付いたように聞こえる。**リバーブを薄くしても解決しない

### RT60

- **正式名称**: reverberation time 60 dB
- **直訳**: 残響が・60デシベル・減るまでの時間
- **意味**: 音が止まってから **60dB 下がるまでにかかる秒数。**部屋の響きの長さを表す物差し
- **混同**: **数字が大きいほど広いのではなく、長く響く。**小さくて硬い部屋でも長くなる

### ハース効果

- **正式名称**: Haas effect（precedence effect）
- **直訳**: （人名）ハース効果／先行の効果
- **意味**: **左右で30ミリ秒くらいまでのずれは、「2つの音」ではなく「1つの音が広がった」と聞こえる**
- **混同**: **それを超えると山彦になる。**広げるための遅延に上限があるのはこの理由

### M/S処理

- **正式名称**: Mid/Side processing
- **直訳**: 中央と・両脇の・処理
- **意味**: 左右2本を「真ん中の成分」と「広がりの成分」に組み替えて、別々に触る
- **混同**: **真ん中だけ下げると、歌とキックが同時に下がる。**どちらも中央にいるため

## 7. 測る

### LUFS

- **正式名称**: Loudness Units relative to Full Scale
- **直訳**: 音の大きさの単位・満杯目盛りを基準にした
- **意味**: **人の耳の感じ方に合わせて測った音量。**周波数ごとの聞こえ方の差を補正してから平均する
- **混同**: **ピーク（瞬間の最大値）とは全く別。**ピークが同じでも LUFS は大きく違う。配信側が揃えているのはこちら

### トゥルーピーク

- **正式名称**: True Peak（dBTP）
- **直訳**: 本当の・頂点
- **意味**: **標本と標本の「間」に隠れている最大値まで含めた頂点。**デジタルの点の列を実際の波形に戻したときの本当の山
- **混同**: 画面上のピークメーターが 0 を超えていなくても、**変換後に超えることがある。**「本当の」が付いているのはそのため

### ISP

- **正式名称**: Inter-Sample Peak
- **直訳**: 標本と標本の・間の・頂点
- **意味**: トゥルーピークが指している、その隠れた山そのもの
- **混同**: **mp3 や AAC に変換した後に歪むのは、ほぼこれ。**変換前は問題なく見える

### ラウドネスノーマライゼーション

- **正式名称**: loudness normalization
- **直訳**: 音の大きさの・標準化
- **意味**: **配信側が、曲ごとの音量を揃えて再生する仕組み**
- **混同**: **大きく作っても意味がない。**揃えるために下げられる。下げられた分、圧し縮めた代償だけが残る

### ダイナミックレンジ

- **正式名称**: dynamic range
- **直訳**: 力の働きの・幅
- **意味**: 一番小さい音から一番大きい音までの幅
- **混同**: **狭いほうが迫力が出るわけではない。**狭めると、最初は大きく聞こえて、すぐ疲れる

## 8. 書き出し

### 標本化周波数

- **正式名称**: sampling rate / sampling frequency
- **直訳**: 標本を取る・振動数
- **意味**: 1秒間に何回、波形の高さを測るか。**44,100回 なら 44.1kHz**
- **混同**: **再現できる最高の音は、この半分まで**（標本化定理）。44.1kHz で 22.05kHz まで

### 量子化ビット数

- **正式名称**: bit depth
- **直訳**: 二進桁の・深さ
- **意味**: 1回の測定を何段階で表すか。**16ビットなら65,536段階**
- **混同**: 音の大きさの上限ではなく、**小さい音をどこまで細かく表せるかに効く。**静かな部分のざらつきの量

### ディザ

- **正式名称**: dither
- **直訳**: 震え・ためらい
- **意味**: **ビット数を落とすときに、わざと微かな雑音を足す。**段差が規則的な歪みになるのを、無害なざらつきに置き換える
- **混同**: **雑音を足すほうが良い音になる、という逆に見える話。**規則的な歪みのほうが耳に付く

### オーバーサンプリング

- **正式名称**: oversampling
- **直訳**: 過剰に・標本を取る
- **意味**: **処理の間だけ標本化周波数を上げる。**歪み系で発生する折り返しを避ける
- **混同**: **音質が良くなるのではなく、折り返しの汚れが減る。**歪ませない処理では意味が薄い

### 折り返し雑音

- **正式名称**: aliasing
- **直訳**: 別名を与えること
- **意味**: **表現できる上限を超えた高い音が、低い側に「別の音として」現れる。**「別名」が直訳そのまま
- **混同**: **元の音と無関係な高さで鳴るので、音楽的に馴染まない。**歪みのざらつきと区別が付く

## 9. 覚える順番

1. **ソースフィルタ理論とフォルマント。**ここが分かると§2と§3が一度に通る
2. **F0・DYN・BRE の3つ。**この3つで表情の8割が動く
3. **子音の先行。**機械っぽさの最大の原因
4. **コンプレッサーのアタックとリリース。**数値の意味が分かるまで触らない
5. **LUFS とトゥルーピークの違い。**ここを混ぜると書き出しで失敗する
6. 空間（§6）と書き出し（§8）

**§7 を先に読む手もある。**測り方が分かると、
**感覚の話を数値で確かめられるようになる。**独学で一番効くのはそこ。
