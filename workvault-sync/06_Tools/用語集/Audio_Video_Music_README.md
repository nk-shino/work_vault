# 音響・映像・音楽の資格学習ノート

基準日：2026年10月1日

## 対象と位置づけ

音響版は、舞台機構調整技能士の音響機構調整作業に関連する共通基礎を扱う。特定級の完全対策ではない。3級の学科・実技の概要を参照しているが、舞台一般、電気、関係法規、安全衛生の全範囲と実技訓練は別途必要。「音響技術士」という呼称をこの資格の正式名称としては扱わない。

映像版は、日本ポストプロダクション協会が実施する映像音響処理技術者資格認定試験の共通基礎に加え、公式確認できたAdobe Certified Professional（ACP）Premiereの学習範囲を分けて扱う。Adobe Certified Expert（ACE）は呼称だけで現行Premiere資格と断定せず、Experience Cloud系Expertとも区別する。

音楽版は、音楽電子事業協会が実施するMIDI検定3級を想定した基礎学習用。MIDIはMusical Instrument Digital Interfaceの略で、電子楽器などの間で演奏情報を交換する規格。演奏実技の検定ではなく、音楽制作と電子楽器の扱いに関する学習を選んだ。MIDI 2.0関連は補足であり、3級の出題対象とは断定しない。

## 内容

音響100項目、映像158項目（JPPA旧100＋Adobe補足58）、音楽91項目。各用語は正式名称と意味を分け、難しい内容に例を添えた。各分野に自作演習15問と解答・解説を収録。公式問題の転載や再現ではない。
