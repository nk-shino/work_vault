# 舞台機構調整技能士（音響機構調整作業） 自作演習

本書は公式問題の転載・再現ではない、級未指定の共通基礎ノートに対応する自作問題です。3級案内の学科・実技分野を意識していますが、試験対策完全版や合格保証ではありません。実機操作・大音量実験は行わないでください。

## 問題

1. 0 dBuと0 dBVの基準電圧をそれぞれ答えよ。
2. 48 kHzでサンプリングしたときのナイキスト周波数を求めよ。また、入力に25 kHz成分を入れる場合の注意を述べよ。
3. 2 Vrmsの正弦波は何 dBuか。式と概算値を示せ。
4. 2 Wが0.5 Wになったときの電力比をdBで求めよ。
5. 94 dB SPLの基準音圧はいくらか。20 µPaからの音圧比も求めよ。
6. バランス伝送のノイズ耐性の理由を説明せよ。「逆相信号が必須」とだけ答えるのが不十分な理由も述べよ。
7. dBFSのサンプルピークとtrue peak（dBTP）の違いを説明せよ。
8. 入力ゲインとフェーダーの役割の違いを、ノイズフロアとヘッドルームに触れて説明せよ。
9. マイクとスピーカーの距離が2 m増えたとき、音速343 m/sとして音の到達遅延は何 ms増えるか。
10. コンプレッサーのしきい値-12 dBFS、入力-2 dBFS、比率4:1のとき、ニー等を無視した出力レベルを求めよ。
11. 量子化ビット数を16 bitから24 bitへ増やしたとき、理想化した量子化雑音の目安は何 dB改善するか。
12. 3本の同一信号を同相で加算すると、電圧（振幅）比は何 dB増えるか。電力比では何 dBか。
13. ファンタム電源を使うときの安全手順を二つ以上挙げよ。リボンマイクを含む場合の注意も述べよ。
14. PAの基本的な信号フローを、入力から客席まで順に書け。各段のクリップ確認点を一つ示せ。
15. 残響が長すぎる会場で音声明瞭度を改善する方法を三つ挙げよ。音量を上げるだけでは不十分な理由も述べよ。

## 正答・計算・解説

1. 0 dBu = 0.775 Vrms、0 dBV = 1 Vrms。基準が違うため同じ電圧でも表示値は一致しない。

2. ナイキスト周波数 = 48,000/2 = **24 kHz**。25 kHzは上限を超えるため、ADC前で制限しないと可聴帯域側へ折り返すエイリアシングが生じ得る。

3. dBu = 20 log10(2/0.775) = **約8.23 dBu**。電圧比なので20 log10を使う。

4. 10 log10(0.5/2) = 10 log10(0.25) = **-6.02 dB**。電力比なので10 log10を使う。

5. 基準音圧は**20 µPa**。94 dB SPLなので音圧比 = 10^(94/20) ≈ **50,119倍**、音圧実効値は約1 Paとなる。

6. 平衡伝送は、二本の信号線を受信側で差動的に扱い、両線に同じように乗った同相ノイズを除去しやすくする。インピーダンスの対称性と受信回路の同相除去が要点で、装置方式によっては二本が完全な逆相信号であることを必須条件とはしない。

7. dBFSはデジタルの各サンプル値をフルスケールに対して表す。DACや再生系の補間で、隣接サンプル間の波形がサンプルピークを超えることがあり、その推定ピークがtrue peak（dBTP）である。したがってサンプルピーク0 dBFS未満でもtrue peakが0 dBTPを超え得る。

8. 入力ゲインはマイク等の微小信号を前段で適正化し、低すぎれば後段でノイズを持ち上げ、高すぎれば前段でクリップする。フェーダーは主にミックス内の送り量を決める。まず入力で十分なS/Nとヘッドルームを作り、その後フェーダーでバランスを取る。

9. Δt = 2/343 s = 0.00583 s = **約5.83 ms**。同じ信号を別スピーカーから出す場合、この差が干渉やエコーの原因になり得る。

10. しきい値超過は10 dB。圧縮後の超過 = 10/4 = 2.5 dB。出力 = -12 + 2.5 = **-9.5 dBFS**（メイクアップゲインなし）。

11. 8 bit分増えるので、理想的な目安は8×6.02 = **約48.16 dB**。実機のアナログ雑音、変換器性能、ディザ、処理経路で実効値は変わる。

12. 振幅比は3なので20 log10(3) = **約9.54 dB**。同一抵抗へ供給する電力比は9なので10 log10(9) = **約9.54 dB**。信号を電圧として加算する前提であり、別々の負荷電力を単純に足す意味ではない。

13. 接続・抜去や設定変更時はモニターをミュートまたはフェーダーを下げる、必要なマイクだけファンタムを有効にする、ケーブルと端子の損傷を確認する。リボンマイクは機種の説明書でファンタム可否を確認し、危険な直流や誤配線から保護する。

14. 例: マイク/再生機器 → マイクプリアンプ・入力 → ミキサーチャンネル → AUX/グループ/メインバス → システムプロセッサー → パワーアンプ → スピーカー → 客席。各段で入力メーター、出力メーター、クリップ表示を確認し、定格負荷と安全な音圧を守る。

15. スピーカーを客席へ近づけて直接音を増やす、指向性と配置を整えて壁・天井への不要反射を減らす、不要低域や残響を抑えつつスピーチ帯域を整える、吸音・反射対策を行う、など。音量だけを上げると反射音と雑音も増え、直接音対残響音の比が改善しないため、聴覚安全上も不適切である。
