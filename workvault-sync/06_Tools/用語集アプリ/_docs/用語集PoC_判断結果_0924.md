## USB に入れたもの（E:\glossary-poc、310MB）

- ソース一式（130ファイル）。開発PCの元ファイルと1バイトずつ照合して一致を確認済み
- `wheels\3.11`・`wheels\3.12`・`wheels\3.13`：依存パッケージ一式（各41ファイル・約100MB）。社用PCの Python の版が分からないので3つとも入れた。pip が社外に出られなくても、これだけで入る

**`wheels` は Work_Vault の USBミラー（11_USBミラー_E）には入れなくてよい。** 開発PCから取り直せるインストーラ類と同じ扱い。

## 社用PCでの手順

USB の `glossary-poc` フォルダを社用PCのローカル（例: `C:\work\glossary-poc`）へコピーしてから実行する。USB 上で直接動かすと、仮想環境（数百MB）が USB に作られるため。

1. `python envcheck.py`：Python の版を確認する（3.11 以上であること）
2. `python tasks.py setup --wheelhouse wheels\3.11`：`3.11` の部分は手順1で分かった版に合わせる
3. `python tasks.py check`：テスト105件がすべて通るか
4. `python tasks.py demo`
5. `python tasks.py serve --db data\demo\glossary-demo.db` → ブラウザで http://127.0.0.1:8000

どこかで止まったら、その画面のメッセージを控える。
