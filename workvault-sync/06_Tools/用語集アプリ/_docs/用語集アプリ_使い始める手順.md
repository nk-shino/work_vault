# 用語集アプリ：使い始める手順（2026-09-24）

用語集アプリを、実際に使える段階まで仕上げた。置き場所は2か所ある。

- **Work_Vault：** `06_Tools\用語集アプリ`（ソース一式・約300KB。説明は同じフォルダの README）
- **業務USB：** `E:\glossary-poc`（ソース一式と、Python 3.11 / 3.12 / 3.13 用の依存パッケージ `wheels`。約310MB）

`wheels` は Work_Vault には入れていない。開発PCで取り直せるので、Vault の容量を使わないため。

## できること

- **用語を手で登録する：** 見出し・定義・用例（その語が実際に使われている文）・出典・読み・英語・略語。同じ見出しで登録すると、2つ目の語義になる
- **資料やメールから候補を拾う：** フォルダを指定すると、その下の `.md` / `.txt`（引継ぎ資料・手順書）と `.eml` / `.csv` / `.jsonl`（メールのエクスポート）をサブフォルダまでたどって読み、よく出る語を提案キューに並べる。定義を書いて「修正して採用」する
- **検索する：** 見出し・読み・英語・略語から検索できる。文脈タグと状態で絞り込める
- **直す・つなぐ：** 定義、読み・英語・略語の編集。関連語（混同注意・同義・略語の元など）の追加。誰でも直せるが、理由の入力が必須で、履歴にすべて残る
- **CSV に書き出す：** Excel でそのまま開ける形で出る
- **消す代わりにアーカイブ：** 削除の機能はない。誤って消した用語を取り戻せなくなるのを防ぐため

今は LLM を使えないので、提案に付く定義文は仮の文（モック）になる。そのまま採用はできないようにしてある。LiteLLM が使えるようになったら、ここを差し替える。

## 社用PCで使い始める手順

1. `06_Tools\用語集アプリ`（または USB の `E:\glossary-poc`）を、社用PCのローカルの作業フォルダへコピーする。Google Drive や USB の上で直接動かさない。仮想環境（数百MB）がそこに作られてしまうため
2. コピー先のフォルダで `python envcheck.py` を実行し、Python の版を確かめる（3.11 以上が必要）
3. `python tasks.py setup` を実行する
   - pip が社外に出られない場合は、USBの`wheels` フォルダもコピーし、`python tasks.py setup --wheelhouse wheels\3.11` を実行する。`3.11` の部分は手順2で確かめた版に合わせる
4. `start.bat` をダブルクリックすると、ブラウザで用語集が開く
5. 引継ぎ資料から候補を拾うときは `python tasks.py import "資料のフォルダ"` を実行する

止まったら、画面のメッセージを控える。

## 用語集の中身

`data\glossary.db` の1ファイルに入っている。バックアップはこのファイルをコピーするだけでよい。Work_Vault の `用語集アプリ` フォルダには、この DB は入っていない（まだ社用PCで作っていないため）。

## まだ決まっていないこと

- 出典キーにメールの Message-ID を使ってよいか（実物には送信サーバー名や社内ドメインが入る）
- 用例の上限400字
- 文脈タグの分類（今は仮に 業務/設備/物流/品質/その他）
  - これ以外に最適なものがあればそちらを採用すること。現状はこの分類で後から必要に応じて追加する。
- git のコミット作者名とリモート
