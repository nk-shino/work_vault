# 検証サマリー — 用語集アプリ再設計プロトタイプ（2026-11-04）

対象: `20261104_用語集アプリ再設計/prototype/` の 6 画面（index / detail / queue / review / new / history）

## 1. 独立検証（オーケストレーター実施）

方法: `python -m http.server`（127.0.0.1:8761）で配信し、Playwright で各画面を 1280×900 で読み込み、要求・コンソール・ページ例外を記録。サーバーは PID を確認（python.exe）したうえで PID 指定で停止し、ポートの閉鎖を確認した。

| 画面 | 要求数 | 127.0.0.1 以外への要求 | コンソールのエラー・警告 | ページ例外 |
|---|---|---|---|---|
| index.html | 5 | 0 | 0 | 0 |
| detail.html | 5 | 0 | 0 | 0 |
| queue.html | 5 | 0 | 0 | 0 |
| review.html | 5 | 0 | 0 | 0 |
| new.html | 5 | 0 | 0 | 0 |
| history.html | 5 | 0 | 0 | 0 |

| 項目 | 結果 |
|---|---|
| キーボード（queue）: `j` | 先頭の提案カードへ移動（確認済み） |
| キーボード（queue）: `?` → `Esc` | ヘルプのダイアログが開き、`Esc` で閉じる（確認済み） |
| キーボード（index）: `Ctrl+K` | コマンドパレットのダイアログが開く（確認済み） |
| reduced-motion（index） | `prefers-reduced-motion: reduce` をエミュレートし、main 配下 185 要素でアニメーションの実行 0 件（確認済み） |
| プロトタイプのソース | 外部 URL の参照は SVG の名前空間宣言 1 件のみ（要求は発生しない）（確認済み） |

## 2. designer による検証（designer の報告に基づく）

- 撮影: PNG 14 枚（6 画面 @1280、3 画面 @375、reduced-motion 2 枚、ゼロ件 1 枚、stagger 動作中 1 枚、自己点検 1 枚）。375px は headless の最小ウィンドウ幅の制約により 375px の iframe 経由で撮影（右端の灰色帯は撮影方法による枠外）
- キーボード自己点検（`prototype/selftest.html`・合成イベント）: 19/19 PASS。実機のキー入力による最終確認は未実施
- 容量予算: CSS 36.4KB（予算 45KB 以内）、JS 23.0KB（予算 25KB 以内）

## 3. 生ログの扱い

designer が検証に使った Edge の netlog（`netlog.json`）と内部ログ（`console-*.log` 3 件）は、ページと無関係なブラウザ全体の通信（企業管理通信など）と認証関連の項目を含み得るため、内容を参照せずに削除した。外部要求なし・コンソールエラーなしの根拠は §1 の独立検証で置き換えている。
