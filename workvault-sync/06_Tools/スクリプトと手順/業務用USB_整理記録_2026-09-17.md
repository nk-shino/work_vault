# 業務用USB（ピンクUSB）の整理記録

対象は業務用USB。容量が逼迫していたため、重複を洗い出して整理した。
**私用PCのドライブ整理とは別管理**。こちらは業務データのみを扱う。

## 状態

| 項目 | 値 |
|---|---:|
| 総ファイル数 | 1,885 |
| 使用量 | 12.28 GB |
| 整理前の空き | 2.18 GB |
| 整理後の空き | 2.43 GB |

## 実行したこと（2026-09-17）

### 入れ子コピーの削除

`wip` フォルダが自分自身の中にコピーされていた。

```
01\0911\wip\              ← ① 9/11時点のスナップショット
01\0911\wip\篠原\         ← ② ①の中に①のコピーが入っていた（削除）
篠原\wip\                 ← ③ 現役の作業用
```

②を削除して **243MB** を回収した。

削除前の確認手順:
1. ②にあって①に無いファイルを洗い出した → 5件（`0確認マクロ.xlsm`、`棚卸しメモ.xlsx`、`[WIP]在庫修正フローチャート.drawio` ほか）
2. その5件が③に同一サイズで存在することを確認
3. 重要な3件はSHA256ハッシュまで照合して同一と確定
4. その上で②を削除

### 残した重複（334MB）

①と③の差分。①は `0911` という日付入りのフォルダ名で、9/11時点のスナップショットと判断した。
意図的なバックアップであれば消すべきでないため、そのままにしてある。

**判断が要る**: このスナップショットをいつまで残すか。不要なら次回削除する。

### 同一ファイルが複数箇所にあるもの

`固定テーブル　棚卸し方法.pptx`（12.8MB）が5か所にある。内容は同一。

| 場所 |
|---|
| `01\在庫管理システム関連データ\棚卸セット\手順\` |
| `01\0911\wip\` |
| `01\0911\wip\棚卸しセット\手順\` |
| `篠原\wip\` |
| `篠原\wip\棚卸しセット\手順\` |

手順の正本は保管庫側の [[固定テーブル棚卸し方法_手順書]] と決まっている。
このpptxは図解の元データなので、**1か所（`固定テーブル　棚卸し方法\`）へ集約してよい**が、
どれが最新かをファイル名から判断できないため、開いて確認してから統合する。
