# ショートカット一括作成.bat の使い方

ファイルやフォルダを複数選んで bat にドラッグアンドドロップすると、それぞれのショートカット(.lnk)を元の場所に作る。

## 使い方

1. ショートカットを作りたいファイル/フォルダをエクスプローラーで選ぶ
2. 選んだまま `ショートカット一括作成.bat` へドラッグアンドドロップする
3. 黒い画面に作成結果が出る(作成/スキップ/失敗の件数付き)。何かキーを押すと閉じる

## 仕様

| 項目 | 内容 |
|---|---|
| 作成場所 | ドロップしたファイルと同じフォルダ |
| 名前 | 元の名前 + .lnk |
| 既に同名の .lnk がある | 上書きしないでスキップ。ドロップしたショートカット自身も壊れない |
| 対象 | ファイル・フォルダ両方。WorkingDirectory は対象のあるフォルダ |
| 内部 | 1件ずつ PowerShell(WScript.Shell COM)を呼び出して .lnk を生成 |

## 動作確認(2026-10-23)

- 日本語+空白入りファイル名(資料 A.txt)/アポストロフィ入り(it's.txt)/フォルダ(サブ)の3種で作成を確認。指し先と WorkingDirectory を WScript.Shell で読み戻し、全て一致した。
- 2回連続実行で3件ともスキップになり、.lnk の更新日時が変わらない(上書きなし)ことを確認した。

## 注意

- bat は文字コード **CP932(ANSI)+CRLF** で保存している。UTF-8 で再保存すると日本語表示が崩れ、LF のままだと goto のラベル解釈が壊れて全く別の行を実行する(2026-10-23 実測)。編集するときはこの2点を守る。
- パスに % を含む名前は想定外の動作になる可能性がある。
- 実行には PowerShell が使える環境が必要(標準の Windows であれば可)。
