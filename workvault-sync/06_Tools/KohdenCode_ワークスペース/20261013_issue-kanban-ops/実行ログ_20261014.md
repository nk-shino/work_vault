### 結論：`GH_CONFIG_DIR` を区分ごとに分ける

```
GH_CONFIG_DIR=<隔離先> gh auth status
  → You are not logged into any GitHub hosts.
既定のまま
```

**設定ディレクトリを分けるとアカウント状態も完全に分かれることを実測した。**

| 方式 | 問題 |
