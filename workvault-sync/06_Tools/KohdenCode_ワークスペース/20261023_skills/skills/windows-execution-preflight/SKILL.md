# windows-execution-preflight

## 起動条件

- PowerShellスクリプトが動かない・エラーになる
- 収集結果がすべて0件で終了する
- タスクスケジューラへの定期実行登録前

## 手順

1. **存在確認**: 対象スクリプト・パスを `Test-Path` で確認する。「スクリプトが存在しない」を最初に排除する。
2. **実行環境の確認**:
   - 実行ユーザー(手動実行とタスク実行で違うことに注意)
   - 共有フォルダへのアクセス(`Get-Item`, `Get-ChildItem` で列挙できるか)
   - 実行ポリシーと署名のエラー(`Get-ExecutionPolicy -List`, エラーメッセージの確認)
3. **0件と失敗の切り分け**: 取得0件は「成功して該当なし」と「取得失敗の握り潰し」を区別する。`-ErrorAction`、try/catch、`$Error[0]` を確認する。
4. **出力の確認**: 出力先フォルダ、上書き条件、再実行時の挙動(上書き/追記/日時別シート)を確認する。リダイレクトや cp で生成したファイルは**直後に同一コマンド内で `ls -la` 等で実在・サイズを確認する**(exit=0でも後ラウンドで消失する事故あり: ERR-20261020-001/20261022-001)。生成と依存する読み取りは同一コマンドで完結させる。
5. **実行方法の分離**: 手動実行とタスクスケジューラ実行を別々に検証する。タスク実行は作業ディレクトリ・ユーザーコンテキストが異なることを前提にする。

## 出力

- 診断結果(どこまで確認できたか)
- 修正案(原因ごとに分ける)
- 再実行手順
- 実行記録(日時・結果)

## 禁止事項

- 組織の実行制限(実行ポリシー等)を勝手に緩めない
- 0件を成功として報告しない
- サーバー・共有・フォルダごとに出力を分けずに一括判定しない
