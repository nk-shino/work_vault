# サーバー関係用語

**この保管庫に実際に出てくる語に絞った。**一般的な入門用語集ではない。
`nksv523` `nksv569` `nksv1359` を触るときに読む前提で書いてある。

書式は `06_Tools/用語集/_用語集の書き方と回し方.md` のとおり。
**正式名称・直訳・意味の3点を置く。**直訳があると、名前そのものが機能の説明になる。

**認証情報は書かない。** ユーザー名・パスワード・トークンは別紙管理。
この方針は `_system/rules.md` で決めたもの。

## 1. ファイル共有

### UNCパス

- **正式名称**: Universal Naming Convention path
- **直訳**: 万国共通の・名前付けの・取り決め
- **意味**: `\\nksv569.ad.nkc.co.jp\Share\mnt\DGS-SV\...` の形。**ドライブ文字を当てずにサーバー上の場所を直接指す書き方。**「取り決め」という名前なのは、どのPCから見ても同じ文字列で同じ場所を指せるようにするための約束だから。ドライブ文字（`Z:`）は割り当てた人のPCでしか通じないが、UNCは誰のPCでも通じる
- **混同**: ネットワークドライブの割り当ては、UNCへの別名にすぎない。**手順書にドライブ文字で書くと、割り当てていない人には届かない。**手順書は必ずUNCで書く

### SMB

- **正式名称**: Server Message Block
- **直訳**: サーバーへの・言づて・ひとかたまり
- **意味**: Windows のファイル共有の通信規約。**フォルダを開く・ファイルを読むという操作を、そのままネットワーク越しの「言づて」に変換して運ぶ。**「ひとかたまり」なのは、要求を決まった形の塊にして送り合うから
- **混同**: **CIFS は SMB の古い呼び名**（下記）。同じものを指していることが多い

### CIFS

- **正式名称**: Common Internet File System
- **直訳**: 共通の・インターネット・ファイルの・仕組み
- **意味**: SMB をインターネットでも使えるものとして売り出すときに付け直された名前。**実質 SMB 1.0 系の別称。**Linux 側で共有をマウントするときのオプションが `cifs` なのは、この時代の名前が残っているため
- **混同**: 名前に Internet が入っているが、**インターネットへ出してよいという意味ではない**

### SMB 1.0

- **正式名称**: Server Message Block version 1.0
- **直訳**: （上記の第1版）
- **意味**: 1980年代の設計。**暗号化が無く、通信の改ざんを検知できず、マルウェアの横移動に使われた実績がある。**Microsoft は新しい Windows で既定で無効にしている
- **注意**: **引き継ぎ資料に「`nksv523` は SMB 1.0 でマウント」との記載がある。**点検対象。ただし止めると繋がらなくなる業務があるので、**切る前にどこから叩かれているかを数える**

### Samba

- **正式名称**: Samba（SMB をもじった造語）
- **直訳**: （固有名詞。訳は無い）
- **意味**: **Linux や UNIX の上で、Windows のファイル共有の役を演じるソフト。**`nksv569` と `nksv1359` がこれ。中身は Linux なのに、Windows からは普通の共有フォルダに見える
- **混同**: **見た目が同じでも権限の持ち方が違う。**Windows アカウントと Linux 側の利用者の対応がずれると、所有者が SID の生文字列や意図しない値で出る。`Get-Acl` の結果をそのまま信じられないのはこれが理由

### マウント

- **正式名称**: mount
- **直訳**: 載せる・取り付ける
- **意味**: 別の場所にある記憶領域を、**自分のフォルダの木のどこかに生やして、そこから下を普通のフォルダとして扱えるようにすること。**`\Share\mnt\DGS-SV` の `mnt` はこの mount の慣習的な置き場
- **混同**: マウントが外れると、**パスは残っているのに中身が空に見える。**「ファイルが消えた」の多くはこれ

## 2. 権限と識別

### ACL

- **正式名称**: Access Control List
- **直訳**: 近づくことを・制御する・一覧
- **意味**: 誰が何をできるかを並べた表。**ファイル1つごとに持っている。**PowerShell の `Get-Acl` で読める
- **混同**: **所有者は「作った人」とは限らない。**共有へコピーした時点で変わることがある。**所有者を根拠に担当者を特定すると外れる**

### SID

- **正式名称**: Security Identifier
- **直訳**: 安全を守るための・識別子
- **意味**: `S-1-5-21-...` の形をした、利用者やグループの本当の名前。**画面に出る表示名は飾りで、システムが見ているのはこの番号。**名前を変えても SID は変わらないので権限が追従する
- **混同**: **SID のまま表示されるのは「名前を引けなかった」という意味。**Samba 側の利用者や、消えたアカウントで起きる。異常ではないが、放置すると誰の権限か分からなくなる

### 最小権限

- **正式名称**: Principle of Least Privilege（PoLP）
- **直訳**: 最も少ない・特権・の原則
- **意味**: **業務が回る最小限しか与えない。**理由は、事故の範囲が権限の範囲で止まるから。管理者権限で動かしているスクリプトが暴走すると、全部消せる
- **混同**: 動かないときに権限を足して解決するのは、**原因を調べていないだけ。**足した権限は誰も外さない

### サービスアカウント

- **正式名称**: service account
- **直訳**: 役務の・口座
- **意味**: 人ではなくプログラムが使う利用者。**夜間バッチや定期実行は誰もログインしていない時間に動くので、人のアカウントでは動かせない**
- **混同**: **人のアカウントで登録された定期実行は、その人の退職やパスワード変更の瞬間に止まる。**止まっても画面には何も出ないので、気づくのは成果物が無いと言われたとき

## 3. 名前解決とネットワーク

### FQDN

- **正式名称**: Fully Qualified Domain Name
- **直訳**: 完全に・資格を満たした・領域の・名前
- **意味**: `nksv569.ad.nkc.co.jp` のように、**どこから見ても1か所に決まる形まで書いた名前。**「完全に資格を満たした」とは、省略された部分が無いという意味
- **混同**: `nksv569` だけだと、**PCに設定された検索領域で補完される。**補完の設定が違うPCでは解決できない。**手順書は FQDN で書く**

### DNS

- **正式名称**: Domain Name System
- **直訳**: 領域の・名前の・仕組み
- **意味**: 名前を住所（IPアドレス）に変換する仕組み。**人は名前で呼び、機械は番号で届ける。**その間の通訳
- **混同**: **「サーバーが落ちた」の正体がDNSであることは多い。**サーバーは生きていて名前が引けていないだけ。IPアドレスで直接叩けば切り分けられる

### Active Directory

- **正式名称**: Active Directory（AD）
- **直訳**: 能動的な・名簿
- **意味**: **社内の利用者・PC・共有をまとめて管理する名簿。**`ad.nkc.co.jp` の `ad` がこれ。1回のログインで複数のサーバーへ通れるのはADが保証しているから
- **混同**: ADが止まると**ログイン自体ができなくなる。**ファイルサーバーが生きていても届かない

### ポート

- **正式名称**: port（番号）
- **直訳**: 港
- **意味**: 1台のサーバーの中で「どの窓口に用があるか」を表す番号。**住所がIPアドレス、部屋番号がポート。**SMBは445番、HTTPは80番
- **混同**: **ファイアウォールで塞がれているとき、サーバーは何も受け取っていないので、サーバー側のログに何も残らない。**「ログに無い」は「来ていない」の証拠にならない

## 4. 定期実行とログ

### cron / crontab

- **正式名称**: cron（chronos = 時間 から）／cron table
- **直訳**: 時の神・の・表
- **意味**: Linux 側の定期実行の仕組みと、その予定表。**`nksv1359` の Perl スクリプトがこれで動いている**（EGPro のビューから実装計画と実績を取る処理）
- **混同**: **Windows のタスクスケジューラと役は同じだが別物。**この環境には両方あるので、「定期実行が止まった」はどちらの話かを先に確定させる

### バッチ

- **正式名称**: batch（処理）
- **直訳**: ひとまとめ・一束
- **意味**: 人が見ていない時間にまとめて走らせる処理。**「一束」なのは、1件ずつ対話的にやる代わりに溜めて一気に流すから**
- **混同**: **成功したかどうかは、誰かが見ない限り分からない。**引き継ぎ資料のバックアップ障害2件は、どちらも**成否を確認する担当が決まっていなかったことで長期化している**（EGProのサブサーバー同期は1年以上、`nksv523` は6月から暫定運用のまま）。**手順書を作るだけでは同じことが起きる**

### syslog

- **正式名称**: system log
- **直訳**: 仕組みの・航海日誌
- **意味**: UNIX系の記録を1か所へ集める仕組み。**log が「航海日誌」なのは、船が丸太（log）を流して速度を測り、その数値を帳面に書いた慣習から**
- **混同**: 集約先が落ちていると**記録が無いだけで、障害が無かったことにはならない**

### ログローテーション

- **正式名称**: log rotation
- **直訳**: 日誌の・輪番
- **意味**: 古い記録を押し出しながら、決めた世代だけ残す仕組み。**入れないとディスクが記録で埋まってサーバーが止まる**
- **混同**: **世代数を越えた分は消える。**「過去の記録を見たい」と言われた時点でもう無いことがある

## 5. データベースと連携

### ODBC

- **正式名称**: Open Database Connectivity
- **直訳**: 開かれた・データ置き場への・つながり
- **意味**: **どのデータベースにも同じ書き方で繋げるようにする中間層。**Excel や Perl から EGPro を叩けているのは、これが挟まっているから。「開かれた」は、特定の製品に縛られないという意味
- **混同**: **32ビットと64ビットで設定が別々に存在する。**Excelが32ビットなら32ビット側の設定が要る。繋がらない原因のかなりの割合がこれ

### DSN

- **正式名称**: Data Source Name
- **直訳**: データの・源の・名前
- **意味**: ODBC の接続先に付けた別名。**プログラム側はこの名前だけ知っていればよい**ので、接続先が変わっても設定を1か所直せば済む
- **混同**: **DSN には認証情報が含まれることがある。**手順書に転記しない。別紙管理

### ビュー

- **正式名称**: view
- **直訳**: 眺め・見え方
- **意味**: 実体を持たない表。**いくつかの表を組み合わせた結果に名前を付けておいたもの。**`T_計画データLog` がこれ。**「眺め」なのは、同じデータを目的に合わせた見え方で切り出すから**
- **混同**: **ビューは軽くない。**呼ぶたびに裏の問い合わせが走るので、重いビューを繰り返し叩くとサーバーに効く

### MES

- **正式名称**: Manufacturing Execution System
- **直訳**: ものを作ることを・実行する・仕組み
- **意味**: 製造現場の実行を管理する仕組み。**計画（上流）と設備（下流）の間に立って、何をどれだけ作ったかを押さえる**
- **混同**: ERP（全社の資源計画）とは層が違う。**MESは現場の時間単位、ERPは経営の月単位**

## 6. この環境の固有名

**用語ではないが、略語のまま出てくるので展開を置く。**

| 名前 | 何か | 覚えておくこと |
|---|---|---|
| EGPro | 生産管理の基幹。部品マスタと生産実績を持つ | **止まるとQCD可視化システムが道連れになる。**依存の向きが一方通行 |
| PanaCIM | パナソニック製の実装機の管理 | 引き継ぎ資料の点検項目は EGPro / `nksv1359` 系が中心で、**PanaCIM 単体の点検項目としてそのまま転記できる行が無い** |
| Asprova | 生産スケジューラ | `nksv1359` の cron が EGPro 部品マスタと一緒に取得している |
| QCD可視化システム | 品質・原価・納期を見るための仕組み | `nksv1359` の cron（`qcd_DB`）が作っている |
| SMT_result | 実装の実績を入れる表（`nksv560`） | **在庫CSVを作る処理とは別プロセス。**混同すると調査先を間違える |
| DGS-SV | `nksv569` の共有配下の領域 | 棚卸し・固定マスタ・リール消費マクロの置き場 |
| SMT | Surface Mount Technology（表面実装技術） | 基板の表面に直接部品を載せる方式 |
| THT | Through-Hole Technology（貫通穴技術） | 穴に足を通して裏で留める方式。**SMTより古いが、力が掛かる部品では今も要る** |

## 7. サーバーの一覧

**名前だけでは何のサーバーか分からないので、分かっている範囲を置く。**

| ホスト | 分かっていること |
|---|---|
| `nksv523` | `Backup` / `LOG`、`第二工場実装課用`、`システム関係`。**SMB 1.0 でマウント。6月から暫定運用のまま** |
| `nksv569` | `Share` / `WWW`。Samba。配下に `DGS-SV`（棚卸し・固定マスタ・個人フォルダ） |
| `nksv1359` | `share` / `WWW`。Samba。cron で Perl が動く（`qcd_DB`）。CGI あり |
| `nksv250` | **共有が数百件あるため丸ごとは対象外。**棚卸しに関わる共有だけに絞る |
| `nksv560` | `SMT_result` テーブルの置き場 |
| `nksv135` | 記録に頻出するが、**役割が未確認** |

**`nksv135` と `nksv1359` が別物か同一かを確認する。**記録上は別々の出現数になっている。
