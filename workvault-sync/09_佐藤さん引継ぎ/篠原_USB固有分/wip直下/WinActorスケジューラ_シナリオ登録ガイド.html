🎯 目的

Accessデータベース シナリオ登録.accdb の T_Schedule テーブル を直接編集して、WinActorスケジューラにシナリオを登録・変更するための入力ルール。

✍️ ユーザが入力するフィールドの詳細

📌 Order（実行順序）

項目 内容
何を入力するか 実行される順番の番号
入力形式 1以上の整数
注意点 重複させない。小さい番号から順に実行判定される

📌 IsEnabled（有効/無効）

項目 内容
何を入力するか このシナリオを有効にするかどうか
入力形式 チェックボックス（Yes/No）
注意点 チェックを外すと実行対象から完全に除外される

📌 ManualRunRequested（手動実行要求）

項目 内容
何を入力するか 今すぐ実行してほしいかどうか
入力形式 チェックボックス（Yes/No）
注意点 チェックを入れると次のチェックサイクルで即実行される。実行後は自動でOFFに戻る。休日でも実行される

📌 ScenarioName（シナリオ名）

項目 内容
何を入力するか シナリオの表示名
入力形式 自由テキスト
注意点 ログ出力やUI表示に使われるため分かりやすい名前にする

📌 ScenarioPath（シナリオファイルパス）

項目 内容
何を入力するか WinActorシナリオファイル（.ums6等）のフルパス
入力形式 UNCパス
注意点 必ず \\nksv523.ad.nkc.co.jp\ から始まるパスを入力する。ローカルパスは不可

📌 ScheduleType（スケジュール種別）

項目 内容
何を入力するか 実行方式
入力形式 以下の5つのいずれかを正確に入力
選択肢 Daily / Weekly / Monthly / FileWatch / Manual
注意点 大文字小文字を正確に入力すること。スペルミスがあると動作しない

📌 ExecuteTime（実行時刻）

項目 内容
何を入力するか シナリオを実行する時刻
入力形式 HH:MM 形式（24時間表記）例：07:30
注意点 Daily / Weekly / Monthly で必須。FileWatch / Manual では不要

📌 DayOfWeek（曜日指定）

項目 内容
何を入力するか 実行する曜日を番号で指定
入力形式 1〜7 の整数
対応表 1=日, 2=月, 3=火, 4=水, 5=木, 6=金, 7=土
注意点 Weeklyのみ必須。他の種別では空欄でよい

📌 DayOfMonth（日付指定）

項目 内容
何を入力するか 毎月何日に実行するか
入力形式 1〜31 の整数
注意点 Monthlyのみ必須。31を指定した場合、2月等では月末日に自動補正される

📌 WatchFilePath（監視ファイルパス）

項目 内容
何を入力するか 更新を監視するファイルのフルパス
入力形式 UNCパス
注意点 FileWatchのみ必須。このファイルが更新されるとシナリオが実行される

🚫 触らないフィールド（システム自動更新）

フィールド 説明
ID オートナンバー。自動採番
LastFileModified 監視ファイルの最終更新日時を自動記録
LastExecuted シナリオ実行完了時に自動記録
LastResult Success または Error が自動記録
ErrorMessage エラー発生時にエラー内容が自動記録

⚠️ よくある間違い

# 間違い 正しい対応
1 ScenarioPathにローカルパスを入れる \\nksv523.ad.nkc.co.jp\ から始まるUNCパスを使用
2 DailyなのにExecuteTimeを空欄にする Daily / Weekly / Monthly は時刻必須
3 ScheduleTypeのスペルミス Daily Weekly Monthly FileWatch Manual を正確に
4 DayOfWeekに曜日文字を入れる 数値 1〜7 で入力する
5 FileWatchなのにWatchFilePathが空 監視対象がないと実行されない
6 LastExecuted等を手動で変更する システム自動更新のフィールドは触らない
7 T_Holidayの更新を忘れる 年1回のメンテナンスが必要
