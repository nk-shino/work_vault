# 効果測定記録

導入前後で、規模と環境が近い作業を比較する。速度だけでなく正確性と追跡可能性で判断する。

## 安全・品質の基準(毎回記録)

- 意図しない本番データ変更: 目標 0件
- 無許可の削除・公開・外部送信: 目標 0件
- 未実施テストの実施済み報告: 目標 0件

## 記録方法

- Skills 使用時に該当する数値をこの表に追記する
- 削減率や目標時間は、導入前の実績が取れるまで設定しない
