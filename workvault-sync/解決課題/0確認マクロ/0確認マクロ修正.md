改修の具体項目（必須）
1) 宣言部（Module1）
   - Type coordinate と API 宣言を Private 化し、#If VBA7 で PtrSafe を付与すること（#If Win64 ではなく #If VBA7）[4][8][2].
   - 例: Private Type coordinate / #If VBA7 Then Private Declare PtrSafe Function GetCursorPos ... #Else ... #End If [8]

2) Module2
   - Module2 を Module2_修正版.bas と差し替える（重複宣言の解消と PtrSafe 対応）[8].

3) CSV取り込み（Sheet1: Input0_Click）
   - 取り込み前に Columns(1).ClearContents を実行する（前回データ残存対策）[4][8].
   - シリアルは Cells(...).Value = Trim(cols(0)) として両端空白を除去する（先頭空白が多発）[4][8][3].
   - ファイル読み込みは ADODB.Stream を用い UTF-8 (BOM含む) を想定して読み込む（改行正規化を含む）[5][8].
   - 取り込みは A列 のみを書き、B列は空に保つ（B列は再開判定に使用）[3][5].

実装上の制約（絶対順守）
- ゼロ確認（ラベル消去）ルーチンは変更しない。消し込みは不可逆のため自動実行禁止（取り込み後は必ず人の目視で確認）[3][4].
- VBAはプロジェクト全体をコンパイルしてから実行されるため、まずVBEでコンパイルエラーが無いことを確認すること（作業必須）[8].

- VBE の [デバッグ] → [VBAProject のコンパイル] がエラー無し（必須）[8].
- テストCSV（上記）を取り込み実行し、MsgBox 表示が "5848 件を取り込みました。" であること（期待値：5,848 件）[4][8].
- A列 1行目が "160096C100792"、A列 最終行(5848) が "T9000031021100011" であること[4].
- 取り込み直後 B列が空であること（値が入っていると次回再開位置がズレる）[3].

- 動作ログ: 変更適用者・適用日時・テスト結果を README/変更ログに記載すること（誰がいつ何をしたか必須）[4][8].
