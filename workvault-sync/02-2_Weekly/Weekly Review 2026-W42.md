## 7. 気づき

- **回帰テストが実機投入前の重大欠陥を捉えた。**CRLF 行末の USB マーカーで必ず停止する不具合（V-1）は、自己テストでは出ない形だった。ハーネス（AST 関数抽出＋subst 疑似USB）の形は次の改修でも使える。
- **控えの世代は数時間で落ちる。**`98_Pass` の復元は最古4世代ギリギリだった。削除が起きたら早めに控えを確認する。
- **git リポジトリを Drive 同期下に置かない。**loose object が壊れる。作業ツリーは `git bundle` で退避。
- **md ファイル1文字の化けは NUL バイトになる。**decision-log.md が file コマンドで data 判定され、原因は「0」が NUL 化した1バイトだった。破損は utf-8 復旧で直せた。pdftotext 等で生成した断片を貼るときは制御文字を確認する。
- **0バイトの新規ファイルは同期で無音に混入する。**vault-sync に 0バイト新規の除外条件を追加した（意図的に追跡する場合は手動 `git add -f`）。実行ログの上書き事故（追記のつもりが上書き）も同日発生し、git 履歴から復旧。追記形式と同期前の差分確認を徹底する。
