# ESXi 更新手順の管理書反映(2026-11-11)

管理書 `01_成果物/管理書.md` に ESXi の更新手順を追加した。版は 0.13 から 0.14。
反映先は第4章の §4-3-8。チェックシートは §13-7、要確認事項は No.31〜36。

## 反映した内容

- §4-3-8-1 事前準備(P1〜P8): 実機スペックの記録、HCL、ファームウェア、Upgrade Path、ゲスト OS、パッチ入手、データストア配置、方針決定。
- §4-3-8-2 作業当日(Step 1〜19): 承認、事前記録、サポートバンドル、NTP、ゲスト OS シャットダウン、構成バックアップ、メンテナンスモード、SSH、プロファイル確認、dry-run、適用、再起動、事後確認、VM 起動、SSH 停止、記録。
- §4-3-8-3 切り戻し: 適用失敗、起動失敗(Shift+R)、VM 不動作、構成バックアップの復元制約。
- §4-3-8-4 バージョンアップ(7.0／8.0): ISO 対話式、追加確認4点、作業後の Host Client キャッシュ。

## 事実の根拠

- ホスト: 172.25.253.45、ESXi 6.7、CIMC-SV 1台(RHEL 6)、自動起動 無効、NTP 172.25.253.42、TSM-SSH 停止、vpxa 停止。
- ハードウェア: Dell 製(PERC H730P、MAC OUI `b8:cb:29`、DELL Disk)。型番は未確認。
- ストレージ: datastore1、4.36 TB、空き 2.35 TB(2020-12-23 時点)。
- 公式: KB 343840、313510、372545、390293、316595、326984。6.7 は EOGS 2022-10-15、EOTG 2023-11-15、最終パッチ P08(2022-10-06、ビルド 20497097)。

出典は `02_参照元/VMwareキャプチャ/`(2026-11-09 取得、45枚)と `2026-11-10_VMware公式情報_ESXi6.7.md`。

## 記録の食い違い(未解決)

2026-11-09 のキャプチャは、パッケージタブの VIB が `670.0.8169922`(6.7 GA)、導入日 2020-12-23 21:22 と表示する。2026-11-10 の記録はビルド 17167734(P04)とする。**実機の `vmware -vl` と `esxcli software profile get` で確定するまで、どちらかを正としない。**§4-3-1 に追記し、§14 No.31 に残した。

## 提示された草案から直した点

- 物理サーバーを Cisco UCS とする前提を削除。Dell 製の根拠3点を明記した。
- CIMC ファームウェアの確認を削除。CIMC-SV は Cisco の管理控制器ではなく、ESXi 上の仮想マシン。確認対象を iDRAC・BIOS・PERC に置き換えた。
- 「6.7 GA」と「ビルド 17167734」の混在を解消せず、実機確定の手順を先頭に置いた。
- 構成バックアップが更新後の切り戻しに使えないこと(KB 313510 の同一ビルド前提)を明記した。
- ログが再起動で消えることを受け、停止前の `vm-support` 取得を手順に入れた。
- 単独ホスト(vpxa 停止)のため、vCenter と Update Manager を前提にしない構成にした。
