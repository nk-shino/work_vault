# チェックシート改訂設計（週次・月次・年次）2026-11-11

## 1. 目的と範囲

既存のチェックシートは、Pana-CIM が「月次・異常時」、LNB が「日次」「月次・異常時」であり、週次・年次と、5原則（4大原則＋3H）に対応する点検が不足している。本書は、実機で確認できた内容を正として、週次・月次・年次の点検項目を追加するための設計を記録する。

- 対象ブック：`Pana-CIM管理手順書案_未承認.xlsx`、`LNB管理手順書案_未承認.xlsx`
- 既存シート：変更しない。Pana の `チェックシート(月次・異常時)`、LNB の `チェックシート(日次)`・`チェックシート(月次・異常時)` はそのまま残す。
- 追加シート：両ブックに `チェックシート(週次)`・`チェックシート(月次)`・`チェックシート(年次)` を追加する。

## 4. 一般例の採否

| 一般例 | 採否 | 理由・読み替え |
| --- | --- | --- |
| バックアップ成否の週次確認 | 採用 | 両システムとも手動バックアップ。成否と最終実行日時を確認する |
| トランザクションログの肥大化 | 条件付き | DB 種別が未確認。DB 保守の項目に統合し、ベンダー推奨がある場合に実施する |
| データストア空き容量 20% 以上 | 案として採用 | 20% は仮の閾値。実機の増加傾向で確定する |
| スナップショットの有無 | 採用 | Pana-CIM は ESXi 上のため該当。不要なスナップショットの残留を確認する |
| 物理 LED・ランプ | 採用 | 両システムとも目視可能。UPS は設置時のみ |
| DB インデックス再構築 | 条件付き | DB 種別が未確認。ベンダー推奨がある場合のみ |
| vCenter／ESXi アラート | 読み替え | vCenter は該当なし。ESXi のアラートとハードウェアセンサーに限定する |
| UPS バッテリーテスト | 条件付き | 設置有無が未確認。「UPS 設置時」と明記し、該当なしはその旨を記録する |
| アーカイブ・保持期間 | 採用 | Pana-CIM は保持期間が未確定。LNB は稼働率フォルダ等の外部保存がある |
| ライセンス・保守契約 | 採用 | 両システムとも対象製品の一覧と期限が未確定 |
| パッチ・ファームウェア | 採用 | ESXi 6.7 の最終パッチ、RHEL 6、Windows、LWS、サーバー・ストレージのファームウェア |
| 計画停止・復電テスト | 採用 | Pana-CIM は §10-4 の異常時手順を流用できるか確認。LNB は Pana-CIM との順序を確認 |
| リストア試験 | 条件付き | 両システムとも手順未確定。実施できない場合は理由を記録する |
| 清掃 | 採用 | 実施主体と頻度が未確定。Pana-CIM は IT か施設かの切り分けが必要 |

## 5. シート構成

| 項目 | 内容 |
| --- | --- |
| 用紙 | A4 横、1ページ幅にfit、高さは可変 |
| 列 | A:No.／B:点検項目／C:原則／D:確認方法／E:判定基準／F:結果／G:証跡・記録No.／H:実施者／I:確認者／J:備考 |
| 列幅 | A=5、B=34、C=6、D=27、E=24、F=10、G=14、H=9、I=9、J=16 |
| ヘッダー | 公式様式（手順書／管理番号／頁／型名／工程番号／作業内容）を A〜J 上に再構成 |
| 印刷タイトル | 1〜9行を繰り返す |
| フッター | `NR4030`／`様式 NR4030-0300-A3`／`日本光電` |
| 行高 | 点検項目・確認方法・判定基準・備考の折り返し行数から算出。固定の AutoFit は使わない |

項目数は、Pana-CIM が週次10・月次12・年次12、LNB が週次8・月次10・年次10 である。

## 6. 項目の考え方

- 週次：日次記録の集約、バックアップ、容量・スナップショット、アラート、物理ランプ、監視の稼働、変更の3H。
- 月次：月次再起動、リソース・容量の推移、パッチとサポート、アカウント、ログ監査、変更の3H。
- 年次：リストア試験、計画停止、パッチ適用、ファームウェア、ライセンス、アカウント総点検、保持期間、キャパシティ計画、清掃、3H。
- 判定基準は、実機で確定するまで「案」と明記する。特にデータストア 20%、バックアップの遅り閾値、復旧時間は確定値ではない。
- 未確定の項目は「未確定」、該当しない項目は「該当なし」と記録する。空欄は「記入忘れ」と区別できないため許容しない。

## 7. 未確定事項

- Pana-CIM の DB 種別、バックアップ保存先の正式表記、成否確認者、世代数、復旧手順と復旧時間。
- Pana-CIM の監視仕様、UPS の設置有無、サーバー室の清掃主体、データ保持期間、ライセンス一覧、ファームウェア版。
- LNB のサーバー名・台数、L2/L3 の構成情報、生産設備番号と IP の対応、予備品の必要数、Windows Update 後の再起動方針、資産台帳の照合方法。
- LNB の認証IDと URL 埋め込みパスワードの是正、設定情報の自動バックアップを有効化するか。
- 両システムの計画停止手順、Pana-CIM と LNB を同日に停止する場合の順序。
