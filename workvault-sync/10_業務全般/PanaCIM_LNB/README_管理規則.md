# PanaCIM_LNB フォルダ 管理規則

**このフォルダの目的**: Pana-CIM と LNB の管理文書作成に関わる成果物・参照元・記録を一元管理する。

## 階層の定義

| フォルダ | 置くもの | 例 |
| --- | --- | --- |
| `01_成果物/` | **現行の正本**。運用に入る文書・図・Excel・生成スクリプト | `管理書.md`、`LNB管理書.md`、`*_確実構成図.drawio`、`*_管理手順書_草案.xlsx`、`tools/` |
| `02_参照元/` | **参照のみの一次資料**。改変しない | 会議記録、会議jpg、`LNBキャプチャ/`、`再起動手順_画像/`、`様式_操作手順書0494-912039/`、持ち寄り案 |
| `03_記録/` | **時系列の報告・ログ**。追記はするが過去分を書き換えない | `経過報告_YYYY-MM-DD.md`、`定期報告_YYYY-MM-DD.md` |
| `99_archive/` | **旧版・統合前・参照頻度の低いもの**。消さない | `*_草案.xlsx`の旧版、`*_Integrated_Initial.docx`、`PanaCIM_LNB_関係図.drawio`、`*_横書き版_v0.2_2026-10-14退避.xlsx`、`定期報告_原稿_2026-10-14_重複_2026-10-14退避.md` |
| `LNB_Collector/` | 収集ツール一式（独自の回帰テストを持つプロダクト） | 既存のまま維持 |

## 命名規則

- **成果物**　システム名を接頭にする: `管理書.md`（Pana-CIM 側）・`LNB管理書.md`。構成図は `PanaCIM_LNB_確実構成図.drawio` / `LNB_確実構成図.drawio`
- **記録**　`種類_YYYY-MM-DD.md`（`経過報告_2026-10-13.md`）。**日付は作成日**
- **キャプチャ等の証跡**　取得日時が分かる元のファイル名を維持する（`スクリーンショット 2026-10-14 102305.png`）。リネームして日時を消さない
- **旧版の取り扱い**　版を重ねたら旧ファイルを `99_archive/` へ移す。**上書きして版の履歴を消さない**

## 運用のきまり

- **`01_成果物` の正本を直接編集する。**編集のたびに front matter の `版` と改訂履歴を更新する
- 相対リンクは `01_成果物` から見た経路で書く（`../02_参照元/…`、`../../点検文書の設計/…`）。**移動時は参照元のリンク更新までを一連の作業とする**
- `02_参照元` は読み取り専用として扱い、訂正が必要な場合は `01_成果物` 側で版を上げる
- このフォルダ配下にはネスト git リポジトリ（`.git/`）を新たに作らない。**追跡は親 `work_vault` リポジトリで行う**（ミラー同期の障害になるため）
- `tools/__pycache__/` 等の生成物はコミットしない（`.gitignore` 済み）
- 認証情報を含むファイル（`*.url` 等）は `.gitignore` 済み。**値を文書へ転記しない**（LNB管理書 §15）
- **旧作業フォルダ `PanaCim・LNB管理書作成/` は 2026-10-14 に廃止した**（内容は `01_成果物/`・`03_記録/`・`99_archive/` へ移行済み。旧経路の記載は過去記録としてそのまま残す）

## 増えたときの判断

1. **運用で使う文書か** → `01_成果物`
2. **根拠として参照するだけか** → `02_参照元`（種別ごとにサブフォルダを作ってよい: `02_参照元/会議_<日付>/` 等）
3. **いつ・誰が行ったかの記録か** → `03_記録`
4. **置き換わった旧版か** → `99_archive`（日付サフィックスを付けて重複を避ける）
