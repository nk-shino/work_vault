## 表示シート

### 1. メンテナンスメモ (Sheet2, A1:C17)
修正履歴のメモ欄。「シート／メモ／マクロ修正シュウセイ」の3列。

### 2. 過去データ (Sheet6コード名はトレイと隣接注意→実コード名 Sheet6, A:V 1,020行)
過去の計算結果を値で保管。期間 2023-11-24～2026-09-30（日付重複0、4つの欠け）。
- 列: 日付/DBにBOM無し/DBにサイクルタイム無し/フリー容量/フリー部品種類数/フリー/L1試作/NKV/L1停止時間/L2試作/TEC-5600/TEC-1000/**送信機L2**/L2停止時間/L3試作/AED/L3停止時間/送信機/EMS-1000/有鉛品目数/…
- **注意: 「送信機L2」は計算シートの「送信機_L2」と列名不一致**（R-02）。
- 数式4件のみ（残りは値）。最終行 2026-09-30 以降は未追記。

### 4. 準備工数 (Sheet_Junbi, A:AO 1,556行)
- A列: 日付 2023-02-01～2027-09-26（r2=702は1901-12-02のゴミセル）
- B:E列 = 計算シートからの XLOOKUP（r978以前は値化済み、r1211以降2026-10-16～が数式、**r1378–1556=2027-04-01以降は計算シート範囲外で#N/A 6,802セル**）
- r3 パラメータ行: F3=2400, G3=2820, H3=1800, I3=1200, J3=804, K3=20, L3=5000, N3=45, O3=15600, Q3=20, R3=15600（秒換算の準備工数定数）
- W列 = IF(OR(COUNTA(B:E)<>4, SUM(B:E)=0), 0, SUM(M,P,S,V))、X列 = W×24
- 共有数式は r978 以降。XLOOKUP 1,388件・IF 1,052件
- `Reflection_Junbi`（VBA）が XLOOKUP を値化し、当日行を選択

### 5. 容量計算 (Sheet_Cal2, A:Q 56行)
- A:C = 品目/分類/生産時間（getBOSS_btn が BOSSから1日分を取得・ソート順 `AED,L3試作,TEC-5600,TEC-1000,L2試作,送信機,L1試作,フリー`）
- G2 = 対象日（`一週間ちょい分のフリーとる` がここを書き換えてループ）
- I4 = 63.5（3ノズル空き）→ L4 = 90-I4、I6 = 74.5 → L6 = 300-I6、O4 = 360
- I21 注意書き「フリー品目連日生産はNG」
- ボタン: getBOSS_btn / Cal_Capa_btn / Cal_Capa2_btn / Cal_Dup_btn
- N:O列は Cal_Fee の出力残骸先（14/15列）

### 6. 計算 (Sheet_Cal, A:U 183行・全て値)
Main の出力先。A列日付 2026-10-01～2027-03-31（182日・欠落0・土日含む）。
- 固定列: 日付/DBにBOM無し/DBにサイクルタイム無し/フリー容量/フリー部品種類数/フリー
- グループ列: L1試作/NKV/L2試作/TEC-5600/TEC-1000/送信機_L2/L3試作/AED（表示形式 0.00"h"）
- 停止時間列: L1/L2/L3停止時間（平日+1.75h）
- **D_Day結合キーは A列の表示文字列 yyyy/mm/dd**（R-07）
- グラフ1–6（L1/L2/L3）は `$A$2:$A$92` の**92行固定参照**（R-10）
- 図形テキストに指図取得用の資格情報（マスク済・R-09）

### 7. 設備停止予定 (Sheet_tenken, A:L 261行)
日付/ライン/分類/設備/内容/F:H = L1/L2/L3停止時間。Mainは列6以降のヘッダを列名として収集。

### 8. カスタム設定 (Sheet_Custom, A:S 225行)
- A:D = 日程変更（品目/変更前/変更後）44行分
- L:O = 日程追加（品目/台数/追加日/頻度）1行
- R:S = 指図指定日程変更 1行（指図212131570、BOSS存在確認済み）
- A1:D44 に「鹿島品目日程変更」ラベルが同居（R-11）
- Mainの日程修正は A|B（品目|日付）をキーに C（変更後）へ。R:S は指図NO完全一致で S へ

### 9. 試作 (Sheet_Sisaku, A:J 20行)
品目/グループ/固定生産時間/組取り数/実装予定…/備考。C列に数式・値の混在。
- Main: A列品目→(B,C,D)を D_Sisaku へ。B列のグループ名を計算シート列として追加
- chkTime: 試作品は CTあり=数量×CT+600、CTなし&組取りあり=数量/組取り×75+600、CTなし&組取りなし=数量×75+600＋固定時間加算
- 量産グループ名を試作に使うと999を書き込むガードあり

### 10. ←の使い方 (Sheet4)
試作シートの説明書。

### 13. job作成 (Sheet_Job)
`一週間ちょい分のフリーとる`: P列14行目以降へ 日付+2から14日分のフリー/L1試作時間を追記。ボタン: openMacro（TOOL.xlamをReadOnlyで開く）。

### 14. BOSS (Sheet_BOSS, A:O 10,171行)
- 列: 指図(A,一意0重複)/品目(B)/…/数量(L)/…/基準開始日(M)/基準終了日(N=Field14)/タイプ(O相当はD列=タイプ分類)
  ※ タイプは列D。基準開始 2024-10-16～2028-04-11、N列表示形式 yyyy/mm/dd（numFmtId=176）
- タイプ内訳: ZP21=7,212 / LA=2,638 / ZP12=128 / ZP13=99 / ZP11=94。全行 B020/PC
- **基準終了日<基準開始日が16行**（R-01）。曜日は月～金のみ
- ImportBOSS: BOSS_Formatの全セルコピー（書式リセット）→ 指図情報全データ.xlsx のUsedRangeを貼付 → Param!A2 にファイル更新日時

### 15. 祝日 (Sheet_Holiday, 71件)
最終 2026-12-31。**今日以降は5件のみ**。2027年分未登録（R-04）。mailプロシージャは「未来日が無ければ警告」するだけ。

### 16. メール (Sheet_Mail)
日報の組版。グラフ7–21（13枚）が B4:N6 等の小セル範囲参照。`mail` プロシージャ: 祝日チェック→Outlook MailItem生成→A10:N75をCopyPicture→WordEditorへ貼付→Send。

### 20. 列設定 (Sheet_CalumSetting, A:D 44行)
計算シートの強制列順。Mainが先頭から列名を読み D_ColNumber を構築。

## 非表示シート

### 3. トレイ (Sheet_Tray)
Main がクリア→計算シートの骨組みをコピー→グループ毎のトレイ部品数を記録。hidden。

### 11. Param (Sheet_Param)
A1=取得日時, A2=指図ファイルの更新日時（46310.31…=2026-10-15 07:31）。

### 12. BOSS_Format (Sheet_BOSS_Format)
書式のみの空テンプレート。ImportBOSSが「BOSS_Format.Copy→BOSS.Cells」で書式リセットに使用。

### 17/18/19. グループ/サイクルタイム/組取り数
PQの取り込み先（3テーブル）。詳細は design/system_design.md §2。

## 計算シート列名の生成順序（Main実行時）

1. 固定6列（日付〜フリー）
2. 列設定シートのA列（先頭行から）
3. 試作シートのB列グループ名
4. グループシートのA列品目→ChkGroup(品目→グループ)と同時に列追加
5. 設備停止予定の列6以降ヘッダ

→ 計算シートの列順は実行のたびに変わり得る。外部参照（グラフ92行固定等）は書き換わらないため列ずれに注意。
