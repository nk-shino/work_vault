項目名は会議資料の協議案を仮置きしたものであり、現在実施している点検とは限らない。聞き取りで確認し、実施していない項目は行ごと削除する。

会議では、サーバーの内部まで見ることはできなくても、バックアップデータが取得できている事実を確認できれば当面は足りるという発言があった。F-2とF-3を先に定義する根拠になる。

各欄の書き方

| 欄 | 書き方 |
| --- | --- |
| 頻度 | 日次、月次、年次、随時のいずれかを記入。「協議」は未確定を示す仮置き |
| 手段 | 画面の目視、コマンド実行、ログ確認のいずれかを記入。複数なら行を分ける |
| 操作の種別 | 読み取りのみ、状態を変える、のどちらかを記入 |
| 取り消し可否 | 「状態を変える」の場合のみ記入。戻せるなら戻す方法も書く |
| 正常の基準 | 数値または画面の状態で書く。「問題なければ」とは書かない |
| 異常とみなす状態 | 何がどう見えたら異常かを書く |
| 記録する内容 | 残す値、画面、出力を書く。残さないなら「記録なし」と書く |
