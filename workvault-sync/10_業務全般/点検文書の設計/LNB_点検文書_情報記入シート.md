各欄の書き方

| 欄 | 書き方 |
| --- | --- |

| 取り消し可否 | 「状態を変える」の場合のみ記入。戻せるなら戻す方法も書く |
| 正常の基準 | 数値または画面の状態で書く。「問題なければ」とは書かない |
| 異常とみなす状態 | 何がどう見えたら異常かを書く |
| 記録する内容 | 残す値、画面、出力を書く。残さないなら「記録なし」と書く |

## L. 充足判定

- [ ] F の全行で、正常の基準と異常とみなす状態の両方が埋まっている
- [ ] F の「状態を変える」行すべてに、取り消し可否が書かれている
- [ ] E-2 から E-5 が埋まっており、新人が自力で接続先へ到達できる
- [ ] G-1 と G-5 が埋まっており、異常時に止まる判断ができる

現時点で埋まったのは、製品名称、作成体制、期限、文書方針にとどまる。点検の実態に関する欄はすべて空欄のため、点検手順書の本体は着手できない。管理書のうち対象の定義と作成計画については、記入済みの範囲で下書きに入れる。
