# KohdenGPTのモデル一覧と使い分け

## 前提

- この一覧は、提示いただいたモデル選択メニューの内容を基に、重複と付随表示を除いて整理したものです。
- 実行可否、内部のモデル設定、入力上限、利用制限は確認していません。
- 使い分けは公開情報で確認できた特性を参考にした目安であり、KohdenGPT上での性能比較結果ではありません。
- 詳細を確認できていないモデルについては、名称や世代番号だけで性能を推測していません。
- 「Claude Opus 47」「Grok 4.3」は、貼り付け文字列に曖昧さがあるため要確認です。

## 6. 実務での使い分け早見表

以下は性能順位ではなく、最初に試すモデルの候補です。
特性を確認できたモデルを基準に、同じ課題で他モデルを比較することを推奨します。

| やりたいこと | 最初に試す候補 | 指示・確認のポイント |
|---|---|---|
| メール、言い換え、簡単な要約 | GPT-5.4 Mini／Claude Haiku 4.5 | 読み手、文字数、文体を指定 |
| 報告書、企画書、説明文 | Claude Sonnet 4.6／GPT-5.4 | テンプレート、構成、完成例を渡す |
| 複雑な仕様検討、原因分析 | Claude Opus 4.6／GPT-5.4 | 前提、制約、判断基準を明示 |
| 大量PDF・仕様書の突合 | Gemini 3.1 Pro Preview | 原文引用、文書ID、版、ページを必須にする |
| 重要な差分・矛盾の再確認 | Claude Opus 4.6／GPT-5.4 | 差分表だけでなく、該当する原文も渡す |
| 短い文章の分類・項目抽出 | GPT-5.4 Nano／Gemini 3.1 Flash Lite | 出力列・分類ラベルを固定 |
| コード作成・レビュー | Claude Sonnet 4.6／GPT-5.4 | 実行環境、関連コード、テスト条件を指定 |
| 外部情報の概要調査 | Quick Research | 出典、更新日、検索範囲を確認 |
| 外部情報の詳細調査 | Deep Research | 調査目的、対象期間、比較軸、出典要件を指定 |
| Officeファイル関連の作業 | Officeエージェント | 非機密のサンプルで対応機能を確認 |

## 7. PDF・仕様書突合での利用案

1. Gemini 3.1 Pro Previewで、文書ごとの要求事項を抽出する。
2. 文書ID、版、要求ID、ページ、短い原文引用を付けた差分表を作る。
3. 重要な差分や矛盾の疑いを、Claude Opus 4.6またはGPT-5.4で再確認する。
4. 数値、単位、適用条件、例外、安全に関わる要求は人が元文書で確認する。
5. 検証済みの差分表を基に、報告用の要約を作る。

注意：
- 複数モデルが同じ結論でも、正しさの保証にはなりません。
- 「確認範囲で見つからない」と「文書に存在しない」を区別します。
- 重要な判断では、モデルの説明ではなく元文書の根拠を確認します。
- 社内機密やソースコードは、承認済みの利用範囲・環境で扱います。

## 8. 選び方のまとめ

- 普段使い：Claude Sonnet 4.6／GPT-5.4 Mini
- 複雑な検討：GPT-5.4／Claude Opus 4.6
- 大量PDFの突合：Gemini 3.1 Pro Previewを候補として検証
- 短文の分類・抽出：GPT-5.4 Nano／Gemini 3.1 Flash Lite
- 調査：Quick Research／Deep Researchの検索範囲を確認して利用
- 詳細未確認のモデル：名称や世代番号ではなく、同じ課題で比較して判断

比較する指標：
- 要求事項の見落とし
- 差分・矛盾の誤判定
- 原文引用と出典の正確さ
- 指定形式への忠実さ
- 応答時間
- 人による修正・確認の手間
