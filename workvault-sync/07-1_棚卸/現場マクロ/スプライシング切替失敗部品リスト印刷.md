## 目的
- 計算機TEC56.xlsm の `FaildSplice` マクロを実行し、  
  計算結果_整形シートの19列目が「◯」である行（スプライシング切替失敗部品）を一覧化。  
- 現場で優先的に確認・是正作業を行うための印刷リストを出力する。

## 前提条件（確定）
- ブック：セットアップレポート計算機TEC56.xlsm  
- マクロ：`FaildSplice`（切替失敗リスト印刷用）  
- 判定基準：計算結果_整形シートの19列目が「◯」  
- 前処理：  
  - 最新のセットアップレポート（Pana-CIM出力）を `SETUPREPORT_Import` で取込済み  
  - EG-Pro在庫CSV を `EG_Import` で取込済み  
  - 配列データを `HAIRETSU_Import` で取込済み

## 実行手順
1. **計算機を最新化**  
   - 各インポートマクロ（SETUPREPORT_Import, EG_Import, HAIRETSU_Import）を実行  
   - 計算結果_整形シートに最新データが反映されていることを確認  
1. **FaildSplice マクロ実行**
   - マクロ一覧から `FaildSplice` を選択し実行  
   - 19列目が「◯」の行を抽出
1. **印刷プレビュー確認**
   - 抽出結果をプレビューで確認
   - 必要に応じてフィルタ･ソート  
4. **出力**  
   - プリンター印刷または PDF 保存  
   - 保存先フォルダ/ファイル名を記録  
1. **現場対応**  
   - 印刷リストを現場担当者へ渡す  
   - 現物のリール確認・スプライシング是正を実施  
   - 対応結果を記録（処置者・日時・内容）  
6. **再照合**  
   - セットアップレポートを再出力 → 再取込  
   - 19列目のマークが消えたことを確認

## 抽出条件（確定/要確認）
- 確定：計算結果_整形シート19列目が「◯」  
- 要確認：  
  - 19列目以外の追加条件（部品番号非空、テーブル番号除外など）があるか  
  - ◯ が付与されるロジック詳細

## 出力項目（推奨/要確認）
| 項目               | 内容                               |
|--------------------|------------------------------------|
| テーブル番号       | 設備上の位置                       |
| Z                  | Z軸/PU番号                        |
| 部品番号           | 品番                               |
| シリアル番号       | 材料バーコード                     |
| スプライシング状態 | ◯ または ●後側など                 |
| EGPro在庫          | 現状在庫数またはステータス         |
| ロケーション       | 現EG-Proロケーション              |
| 備考               | 現場記入用（処置内容/担当者/日時） |

- マクロ実装により列名・順序が異なる場合があるため、実装内容を参照して確定すること。  

## 注意事項
- **FaildSplice_OK** は例外用マクロ。通常は使用禁止。  
- 印刷リストを使わずに Excel 書換や SQL 更新をしない。  
- 実行ログ（実行者・日時・対象件数・保存場所）を必ず作業記録に残す。  

## 運用フロー（現場対応後）
1. 印刷リストに現場対応結果を記入  
2. 再取込・再照合 → 19列目マーク除去を確認  
3. 必要に応じて idouSQL 等の次工程を実行  

## 未確定・要確認事項

- 印刷/PDF保存先フォルダの標準パス  
- FaildSplice_OK の使用承認フロー  
- ◯ 判定ロジックの詳細
