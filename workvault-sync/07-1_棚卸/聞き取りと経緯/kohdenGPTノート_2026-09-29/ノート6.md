現在の列定義と入力使い分けは [[固定テーブル棚卸し_詳細設計・仕様書]] の2026-09-29訂正を参照する。今回の全件確認で、WhereHouse11列版には0確認ありとなしの両方があり、Tanaoroshi8列版にも0確認が含まれることを確認した。棚卸用にないのは発注番号・入荷日時・最終更新日時。棚卸用は在庫数4列目、ロケーション名称6列目であり、11列版の固定位置とは異なる。

今回のCSV集計では、DB側の生成テーブルや抽出条件までは確定していない。以下の既存DB調査は当時の根拠に基づく記録として保持する。

# 【KB用】棚卸方法解説 ナレッジ登録用サマリ v3

前回どこまで: 固定テーブル棚卸の手順と計算機（TEC56.xlsm）／idouSQL の仕様を整理していた。SMT_result は別バッチで作成される旨を確認済み。要確認: CSVの物理的な出力プロセス（どのジョブが書き出すか）。
更新日: 2026-09-03（v3）。出典: 実運用スクリプト・DB定義・サンプルCSV（添付ファイル）。
要点（結論）

*   在庫CSV（EGProWhereHouse形式）は EG-Pro 系 DB の在庫ログテーブル群から出力されており、出力元候補は主に T_在庫ログ とそれを加工するワークテーブル／ビュー（W_在庫ログ, W_棚卸用在庫ログ, V_棚卸用シリアルデータ）である[6][10][3][9]。サンプルCSVの列定義はこれらテーブルのカラムと対応している[2][6]。

*   SMT_result を作るバッチは EGPro のビュー T_計画データLog をODBCで取得して nksv560 の SMT_result テーブルへ書き込む独立プロセスであり、在庫CSVの出力処理とは別物である[1]。


詳細（追記・更新箇所）

1.  在庫データの出力元候補と役割


*   T_在庫ログ: 在庫の主要な履歴／属性を保持するテーブル。CSVの多くの列（シリアル番号／品番／発注番号／入荷日時／受入数／在庫数／ステータス名／ロケーション等）がここから抽出される想定で最有力候補である[6]。

*   W_在庫ログ / W_棚卸用在庫ログ: 在庫エクスポートや棚卸処理用のワークテーブル。CSV生成前後の一時格納や抽出に使われる運用が想定される[10][3]。

*   V_棚卸用シリアルデータ: 複数テーブルを UNION しているビューで、棚卸用途に適したシリアル一覧を作るための抽象レイヤーとなっている。CSVの棚卸出力に使われる可能性がある[9]。

*   T_実棚卸データ: 実棚卸のカウント結果を保持するテーブル。現場カウント結果の格納先／比較先として使われる[8]。


2.  出力プロセス（現時点で判明している流れ）


*   EG-Pro 側の SELECT を用いて在庫情報を抽出し、何らかの方法で CSV 化している。実装例としては SQL Server からの SELECT を外部スクリプトで CSV に書き出す、あるいは管理画面／ツールでエクスポートする運用が考えられるが、物理的にどのジョブ／スクリプトが生成しているかは現段階では未特定（要確認）[6][2]。

*   在庫出力前後にデータ補正パッチ（ロット桁揃え等）が適用されるケースがある。既存のパッチ群（ロット入力ミス修正、後ろ0のパッチ等）はデータ整形や桁揃えのために運用されている[4][5][7]。


3.  idouSQL / 計算機（TEC56.xlsm）連携の更新点


*   計算機側の取込フロー（EG_Import / SETUPREPORT_Import 等）と GenbaList→idouSQL の順序は従来どおりで、idouSQL はロケーション付け替え（在庫数は変更しない）を行う。改修点・注意点は既存ノートのまま有効である（バックアップ取得・トランザクション制御・実行前確認等）[11]。


4.  SMT_result の位置づけ


*   SMT_result は crontab で定期実行される Perl スクリプトが EGPro のビュー（T_計画データLog）から実装計画／実績を取得して nksv560 の SMT_result に書き込む仕組みで、在庫CSVを生成する処理とは別プロセスである[1]。


確定情報（現時点で確定できる事項）

*   CSV列定義と T_在庫ログ のカラムの対応関係が存在する（サンプルCSVとSELECT例を比較して確認）[2][6]。

*   W_～ 系テーブルと V_棚卸用シリアルデータは棚卸作業のために用意された DB オブジェクトである[3][9][10]。

*   データ修正用パッチが運用に存在する（桁揃え・誤入力補正）[4][5][7]。
