このフォルダについて

ここは、固定テーブル棚卸しで使うデータと資料の置き場です。
棚卸しの回ごとにフォルダを分け、在庫データとセットアップレポートを同じ回のフォルダにまとめます。


■ フォルダの分け方

・2026_10、2026_3 など … 棚卸しの回ごとのフォルダです。在庫データ(EGProWhereHouse)とセットアップレポートをここへ入れます。
・AED_20261026、NKV_20261026 など … 製品ごとの作業用フォルダです。配列へのリンク、QRコード、手動入庫処理バーコードなどを置きます。
・★固定マスタ … 製品別の配列CSVの正本です。製品ごとのサブフォルダ(例: L1_NKV)に分かれています。
・セットアップレポート計算機原本_v2.0.xlsm … 計算機の原本です。使い方は下の「計算機の使い方」を読んでください。
・固定テーブル棚卸し方法_v2.pptx … 棚卸し手順のスライドです。


■ ファイル名の付け方

棚卸しの回フォルダへ入れるファイルは、次の名前にしてください。

・セットアップレポート
  L2_セットアップレポート_<製品>_<YYYY-MM-DD>.csv
  例: L2_セットアップレポート_TEC5600_2026-10-26.csv

・在庫データ
  <YYYY_MM_DD_HHMMSS>_EGProWhereHouse.csv
  例: 2026_10_27_192519_EGProWhereHouse.csv
  EGProから取得したときの名前のままで構いません。ダウンロードで「 (3)」のような番号が付いても、そのまま置いて構いません(取込はファイル名の一部で判定します)。

・配列
  ★固定マスタ\<製品フォルダ>\<製品>_配列.csv
  例: ★固定マスタ\L1_NKV\NKV_配列.csv
  配列は回フォルダへコピーしません。★固定マスタの1か所で管理します。


■ 計算機の使い方(コピーして使う)

1. このフォルダにあるセットアップレポート計算機原本_v2.0.xlsmは、直接開かないでください。原本がその場で書き換わると、どの版が正しいか分からなくなります。
2. 計算機を使うときは、E:\など自分の作業場所へコピーし、コピーの方を開いてください。
3. 計算結果のリスト(PDF・CSV)は、計算機のブックと同じフォルダへ出力されます。作業した回のフォルダへ移して保管してください。倉庫移動SQLはメモ帳で開きます。内容を確認して手動で実行し、残す場合は回のフォルダへ保存してください。
4. 計算機そのものを直す必要が出たときは、原本を直接編集せず、管理者へ相談してください。変更は検証したうえで正本へ反映します。

一括取込は、回フォルダ(在庫データとセットアップレポート)と、★固定マスタの配列CSVを選んで実行します。④対応表はこれまでどおり手動で貼り付けてください。


■ 注意

・ブックやCSVを開いたままにすると、取込や配備が失敗します。使い終わったら閉じてください。
・「~$」で始まるファイルは、Excelが作る一時ファイルです。消しても構いません。
・ファイルを入れ替えるときは、古いファイルを消す前に、本当に不要か確認してください。
