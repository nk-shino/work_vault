nksv560の設定状況
	OS：Ubuntu 16.04.6 LTS
	Python：Python 2.7.12(Preinstall)
	Python：Python 3.5.2(Preinstall)

Python Package Install（必須）
	・pip3（パッケージ管理ツール：python3以降のみ対応）
		端末で、”sudo apt install python3-pip”を入力する。

	・MySQLDB（データベース接続）
		端末で、”sudo apt install python-dev default-libmysqlclient-dev”を入力する。
		　※ダメなら、”sudo apt install python-dev libmysqlclient-dev”を入力する。
		端末で、”sudo apt install python3-dev”を入力する。
		端末で、”pip3 install mysqlclient”を入力する。
		端末で、”sudo mysql”を入力する。
		端末で、”SET GLOBAL local_infile=on;”を入力する。
		端末で、”exit”を入力する。

	・pysmb（ファイル共有モジュール）
		端末で、”pip3 install pysmb”を入力する。

	・datetime（時間モジュール）
		端末で、”pip3 install datetime”を入力する。

	・tkinter（表示）
		端末で、”sudo apt install python3-tk”を入力する。
