実行ポリシー（そのセッションだけ許可）を緩める（コピーして実行）

Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned

モジュール確認／インストール（Invoke‑Sqlcmd が必要）

まずモジュールがあるか確認:

Get-Module -ListAvailable SqlServer

無ければ（管理者またはCurrentUserスコープで）:

Install-Module -Name SqlServer -Scope CurrentUser -Force

変数・出力フォルダの準備（コピーして実行）

$server = "EGPROSRV1"

$db = "EGProKOHDEN-Warehouse"

$outDir = "C:\\Users\\Videos"

New-Item -Path $outDir -ItemType Directory -Force | Out-Null



注意: 実行するアカウントのユーザフォルダを使うと意図しない場所に出る可能性があるため、フルパスで指定しています（C:\\Users\\Videos）。



テーブル一覧（確認） — 実行前に対象テーブルがあるか確認

例: T\_在庫データ の存在を確認（参照先の SELECT はファイルにある）:

Invoke-Sqlcmd -ServerInstance $server -Database $db -Query "SELECT TOP 1 \* FROM dbo.\[T\_在庫データ];"----------------------------------------------------------------------------------

\# 管理者PowerShellで実行

$server = "EGPROSRV1"

$db     = "EGProKOHDEN-Warehouse"

$outDir = "C:\\Users\\Administrator\\Videos"



\# 出力先ディレクトリ作成（既存でもOK）

New-Item -Path $outDir -ItemType Directory -Force | Out-Null



Import-Module SqlServer -ErrorAction Stop



$map = @{

&#x20; "T\_在庫データ"       = "T\_在庫データ.csv"

&#x20; "T\_PanaCIM連携"     = "T\_PanaCIM連携.csv"

&#x20; "T\_在庫ログ"         = "T\_在庫ログ.csv"

&#x20; "T\_実棚卸データ"     = "T\_実棚卸データ.csv"

&#x20; "T\_棚卸原票データ"   = "T\_棚卸原票データ.csv"

&#x20; "T\_棚卸制御"         = "T\_棚卸制御.csv"

&#x20; "W\_在庫ログ"         = "W\_在庫ログ.csv"

&#x20; "W\_棚卸用在庫ログ"   = "W\_棚卸用在庫ログ.csv"

&#x20; "LOG\_棚卸"           = "LOG\_棚卸.csv"

&#x20; "LOG\_廃棄"           = "LOG\_廃棄.csv"

&#x20; "LOG\_ロケーション移動" = "LOG\_ロケーション移動.csv"

&#x20; "LOG\_出庫"           = "LOG\_出庫.csv"

&#x20; "LOG\_棚登録"         = "LOG\_棚登録.csv"

&#x20; "LOG\_入庫"           = "LOG\_入庫.csv"

&#x20; "T\_作業ロス数"       = "T\_作業ロス数.csv"

}



foreach ($tbl in $map.Keys) {

&#x20; $outFile = Join-Path $outDir $map\[$tbl]

&#x20; Write-Host ("Exporting {0} -> {1}" -f $tbl, $outFile)

&#x20; $sql = "SET NOCOUNT ON; SELECT \* FROM dbo.\[$tbl];"

&#x20; try {

&#x20;   $dt = Invoke-Sqlcmd -ServerInstance $server -Database $db -Query $sql -QueryTimeout 0 -ErrorAction Stop

&#x20;   if ($dt -and $dt.Rows.Count -gt 0) {

&#x20;     $dt | Export-Csv -Path $outFile -NoTypeInformation -Encoding UTF8

&#x20;   } else {

&#x20;     $cols = Invoke-Sqlcmd -ServerInstance $server -Database $db -Query "SELECT TOP 0 \* FROM dbo.\[$tbl];"

&#x20;     $cols | Export-Csv -Path $outFile -NoTypeInformation -Encoding UTF8

&#x20;   }

&#x20; } catch {

&#x20;   Write-Error ("Failed to export {0}: {1}" -f $tbl, $\_.Exception.Message)

&#x20; }

}

Write-Host "Export complete. Files in: $outDir"

\----------------------------------------------------------------------------------

実行ログ（PowerShell の出力）をファイルに保存:

Start-Transcript -Path "C:\\Users\\Videos\\export\_log\_$(Get-Date -Format yyyyMMdd\_HHmmss).txt"

（処理終了後）Stop-Transcript
