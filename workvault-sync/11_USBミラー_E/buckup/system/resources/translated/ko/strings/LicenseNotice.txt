# Translation notes
#
# 1. All lines beginning with the # character are comments.  Do not translate them.
#    All remaining lines require translation.
# 2. On translatable lines:
#      a. The first word, up to the equal sign (=), is the string name used by the
#        program.  Do not change it or the equal sign.
#      b. The text following the equal sign needs to be translated.
#      c. Translatable text may contain one or more substitution words.  These
#         always begin with a { character followed by a digit (1-9) OR a string,
#         and end with the } character. The substitution words should not be
#         translated.
#
