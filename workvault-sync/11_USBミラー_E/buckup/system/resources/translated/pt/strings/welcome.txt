Welcome to System Update.

You can use this tool to search for new updates for your computer, review them, then select the ones you want to download and install.

Select Schedule Updates in the left pane to download and install updates automatically or receive notifications when updates are available.

View Installation History shows the status, version, and dates of the updates you already installed.

You can also select to download updates but defer installation until a more convenient time. Select Install Deferred Updates for installing the deferred updates.

In addition, you can “hide” updates so that they do not show up in subsequent searches; yet have the ability to restore the hidden updates if you ever need them. Go to the Restore Hidden Items for restoring the hidden updates.
