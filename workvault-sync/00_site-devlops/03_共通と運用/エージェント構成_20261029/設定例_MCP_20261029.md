# MCP 接続設定例（2026-10-29 実測に基づく）

Kohden Code（opencode.json）向けの接続設定例。**いずれも未接続。** 接続・トークン入力は運営者の承認後に実施する。公式性の出典は lib-1 調査（確認日 2026-10-29）による。

## 1. Playwright MCP（Microsoft 公式）

実画面検証の公式選択肢。環境に Playwright のブラウザ操作ツールが既に搭載されている場合（Kohden Code 1.18.33-nk.11 では利用可・確認日 2026-10-29）、重複するため用途を分けて判断する: 既存ツールは対話的検証、この MCP は自動化スクリプト・headless 実行用。

```jsonc
{ "mcp": { "playwright": { "type": "local",
    "command": ["npx", "@playwright/mcp@latest", "--headless", "--isolated"],
    "enabled": true } } }
```

- `--headless --isolated` を固定にする（既定は headed・プロファイル永続化で、認証情報が保持されうるため）
- 接続先を限定する場合は `--allowed-origins`／`--blocked-origins` を追加する
- スクリーンショットの保存先は `--output-dir` でワークスペース配下に限定する

## 2. GitHub 公式 MCP（技術スタック監視用）

```jsonc
{ "mcp": { "github": { "type": "remote",
    "url": "https://api.githubcopilot.com/mcp/",
    "enabled": true,
    "oauth": { "scopes": ["repo", "read:user"] } } } }
```

- toolsets は dependabot・security_advisories・repos に絞る。read-only モードを推奨
- トークン・OAuth の値はユーザーが環境変数等へ設定する（エージェントは値を扱わない）

## 3. Analytics MCP（Google 公式・GA4 読み取り用）

```jsonc
{ "mcp": { "ga4": { "type": "local",
    "command": ["uvx", "analytics-mcp"],
    "enabled": true,
    "environment": { "GOOGLE_APPLICATION_CREDENTIALS": "{env:GOOGLE_APPLICATION_CREDENTIALS}" } } } }
```

- 前提: Google Cloud プロジェクト・Admin API と Data API の有効化・ADC 認証
- **読み取り専用（analytics.readonly）でのみ接続する。** 設定変更（プロパティ・ストリームの追加・更新・削除）は GA4 管理画面で運営者が行う
- 未デプロイのサイトには計測対象が無いため、導入判断はデプロイ承認（S-15）の後に行う

## 4. 接続時の共通ルール

- トークン・鍵の値はエージェントが閲覧・出力・文書化しない。環境変数参照の形で用意し、値の入力はユーザーが行う
- 接続先へ送るデータの種類（コード・パッケージ名・利用状況）を、承認時に台帳へ記録する
- 接続後は各担当の定義（site-security・site-techwatch・site-analytics）に沿って使う。用途の外で使わない
