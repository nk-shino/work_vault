# 動画制作ツール 購入検討メモ(業務時間に読む用)

目的: 既存動画から短尺と要約版を作る自動化に、追加で購入する価値のあるツールがあるかを判断する材料。
結論の先出し: **現時点で購入が必要なものはない。** 無料の道具と契約済みの Adobe で試作まで進められる。購入は「試して、時間短縮が月額に見合うと分かってから」。

調査日は 2026-10-06。金額は公式ページで確認した値。二次情報は明記した。為替・税は含まない(米ドル)。

## 1. すでに手元にある(追加費用なし)

| 道具 | 用途 |
|---|---|
| FFmpeg | カット、結合、縦横変換、書き出し |
| faster-whisper | 日本語の文字起こし(GPU、無料) |
| PySceneDetect | 場面転換の検出(無料) |
| Adobe(Premiere / Media Encoder / After Effects) | 編集と書き出し。契約内 |
| Claude Pro(月20ドル) | 判断と開発。Claude Code 含む |

## 2. 購入候補と、買ってよい条件

| 候補 | 価格 | 買う条件 | 買わない理由 |
|---|---|---|---|
| OpusClip Pro | 月29ドル | **API が使えるのは Pro 以上のみ**(Starter 月15ドルには無い)。無料枠で同じ素材を処理し、自作の試作より手直し時間が明確に減ったら | 横長の10分要約は不得意の可能性。無言の画面中心の動画は未検証 |
| Klap | 年払い換算で月14〜94ドル(クリップ100〜1000本) | OpusClip と同じ試験で優ったら | 同種のため1社に絞る。日本語の精度は未検証 |
| Vizard Creator | 月29ドル(年払い換算で月14.5ドル)。二次情報 | 同上 | 公式ページから価格が取れなかった |
| DaVinci Resolve Studio | 295ドル(買い切り) | **Premiere の自動化がどうしても通らない場合のみ**。Python 自動化は Studio 専用 | Adobe 契約済みなので重複投資 |
| Gemini API | 従量(動画1時間の入力で約0.3ドル程度の見込み) | 動画をそのまま読ませて話題の区切りを探す精度が、文字起こし経由より良い場合 | 購入ではなく従量課金。上限を決めて使う |
| Claude 追加利用(Fable) | 従量課金 | 設計の行き詰まり時のみ | 常用はしない |

## 3. 買わない(今は)

- 生成動画 API(Runway、fal.ai 等): 既存映像の編集には効かない。補助カットを作る用途のみ。
- Descript: 日本語の文字起こしに制約がある。
- Remotion: 3人までの個人・小企業は無料。会社の人数の数え方を確認してから。有料なら月100ドル最低。

## 4. 判断の基準(目安)

購入の判断は **月額 ÷ 短縮できる時間** で見る。
たとえば月29ドルのツールが、月に3時間の手直しを減らすなら、1時間あたり約10ドル。
自分の時間単価がそれより高ければ買う価値がある。**まず無料枠で1本ずつ測る。測らずに契約しない。**

## 5. 業務時間に確認したいこと

1. 会社として、動画・音声を外部サービス(AI、クラウド)へ送ってよいか。社内規程や情報の取り扱いルール。
2. 外部サービスの学習利用の設定(オプトアウト可否)と、データ保持期間。
3. 月額の購入に承認が要るか。承認ライン。
4. Adobe の契約内容(Creative Cloud のプラン、書き出し自動化の可否)。
5. Remotion の無料条件(3人まで)に、会社の人数がどう当たるか。
6. 公開先(自社サイト)で使える動画形式と、字幕(WebVTT)の対応状況。
