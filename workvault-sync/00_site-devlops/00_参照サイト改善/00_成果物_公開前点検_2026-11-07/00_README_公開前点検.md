# README：公開前点検（2026-11-07）

## 何があったか

運営者の指示は「push してデプロイまで進めて」。

**push は済んだ**（`origin/master` が `7d24a8f`。リポジトリは非公開のまま）。
**デプロイは止めた。** このサイトは一度も公開されたことがなく、今回が初回になる。
初回の公開は、上げた瞬間に検索エンジンやウェブの保存庫が写しを取り始めるので、後から直しても写しは消えない。
台帳にも、公開の前に決めておく約束になっている不可逆の項目（S-25）が残っていた。
だから先に「上げたら何が世に出るか」と「その上げ方で本当に通るか」を確かめた。

どの担当も、何も入れない・何も上げない・どこにもログインしない、で動いている。

### 上げ方（こちらで直した・コミット前）

- **`npm run deploy` は通らない。** Void を通していたが、Void は Node 24.22 以上を要求し、この端末は 24.18。
  版も固定しておらず、走らせるとその日いちばん新しい版（点検の2日前に出たもの）を取ってくる。
  しかも Cloudflare ではなく別の会社の道具で、導入前の監査もしていない
- **README の逃げ道のコマンドも、そのままでは不足。** 上がりはするが、無いURLに中身の無い 404 を返し、`404.html` が出ない。
  版ごとに別の公開URLも作られ、直す前の版がそのURLで読まれ続ける
- **設定ファイルが無いまま `wrangler deploy` を素で走らせると、根のフォルダを丸ごと上げにいく。**
  wrangler は設定が無いと index.html のあるフォルダを自分で探して静的サイトとして上げる。根には APIキーを扱う別アプリ（`server/`）がある
- 直したもの: `wrangler.jsonc` を足し（配るのは `dist/` だけ・無いURLに `404.html`・版ごとのURLを止める）、
  `npm run deploy` を wrangler 4.153.0 に固定して付け替え、`.wrangler/` を git の対象外にし、README の公開の節を書き直した

### 名義（運営者にしか確かめられない）

- 公開URLは `name-info-site.<アカウントのサブドメイン>.workers.dev`。**サブドメインが公開URLのすべてに出る。**
  メールアドレスや本名に似ていれば、それが公開される。ダッシュボードで変えられる
- wrangler の `whoami` はアカウントのメールアドレスを表示する。こちらのシェルで走らせると対話ログに残り、保管庫へ書き出される。
  **サインインと公開は、運営者が自分の端末で行う**
- サインイン（`wrangler login`）は既定で28種類の権限をまとめて求め、鍵を平文のファイルに置く。`--use-keyring` で Windows の資格情報マネージャーに置ける

### 検索エンジン（判断が要る）

`robots.txt`・`sitemap.xml`・「索引に載せない」指示のどれも無い。公開した日から全ページが拾われうる。
**最初の1週間ほどは「載せない」（`X-Robots-Tag: noindex`）で出し、実物を確かめてから外す**ことを推奨する。
リンクを渡した相手は普通に読める。

## 公開の手順（判断が済んでから）

1. S-30 の4件を直す（元の `data/*.json` で直し、`dist/` は作り直す）。`npm run check`・`npm test`・`npm run build:site`
2. 「載せない」で出すなら、`tools/build-site.js` が書く `_headers` に1行足して作り直す
3. コミットと push
4. **運営者が** ダッシュボードにサインインし、Workers & Pages の「Your subdomain」を確かめる。名義に繋がるなら変える
5. **運営者の端末で** `npx wrangler@4.153.0 login --use-keyring` → `whoami` で意図したアカウントか確かめる
6. `npx wrangler@4.153.0 deploy --dry-run`（上げずに、何を上げるかだけ見る）→ `npm run deploy`
7. 公開後に確かめる: 応答ヘッダーに CSP があるか、`/_headers` が 404 か、無いURLで `404.html` が出るか、
   全ページで CSP違反0件か（Cloudflare が HTML を書き換えてハッシュが外れていないか）、直した引用が配信物から消えているか

wrangler 4.153.0 の取得は、展開後で約150MB（本体16MB・実行環境の workerd 101MB・esbuild 12MB ほか）。
Cloudflare 公式のリポジトリから公開されたもので、本体は取り付け時にスクリプトを走らせない。
esbuild と workerd は取り付け時に自分の環境用の実行ファイルを用意するスクリプトを走らせる。

## 戻し方
