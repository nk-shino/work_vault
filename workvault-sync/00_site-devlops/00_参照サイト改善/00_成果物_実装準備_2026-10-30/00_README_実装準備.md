## この3本の作り方（信頼度の根拠）

数値はすべて実測で、推定を混ぜていない。作る過程は実測 → 起草 → 独立検証 → 改訂 → 再検証 → 確定。
**独立検証は起草と別の担当が行い、数値を自分で測り直している。**

検証で見つかって直したものの例:

- 件数・行数の取り違え（行番号をファイル長として書いていた等）
- 資料内で同じ値が別の節で食い違っていた箇所
- 改訂の過程で、前回正しかった記述を壊した後退1件（改行コードの分布）
- 落とし穴の表に、最大の落とし穴が載っていなかったこと

固有名称の混入は、禁止語109件（データから機械抽出）＋絶対パス・連絡先の形で機械走査した。
