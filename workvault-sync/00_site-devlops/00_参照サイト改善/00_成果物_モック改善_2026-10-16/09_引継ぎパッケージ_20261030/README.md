# 引継ぎパッケージ（claude codemax 向け）

08_取り込み指示書 §6 の最終プロンプトを、本番リポジトリを保持する外部エージェント（claude codemax・Claude Code・Maxプラン・別マシン）へ渡すための一式。内容は既存資料の集約と、実装に入れるための体裁の調整が主で、新しい技術判断は含まない。

## 収録物

| ファイル | 役割 |
|---|---|
| 00_必読リスト.md | 作業開始前に読む資料の順序つき一覧。各資料に1行の要旨と、その順序の根拠を付けた |
| 01_環境準備_MCPとスキル.md | Claude Code 側の事前設定。Playwright MCP の .mcp.json 例・GitHub MCP の要否・スキルの代替方法。トークンの値の入力はユーザーが行う |
| 02_最終プロンプト_v2.md | 08 §6 を拡充した最終プロンプト1枚。ユーザーが claude codemax へ貼る |

## claude codemax が読む順

1. この README（収録物の把握だけ。ここから実作業は始まらない）
2. 00_必読リスト.md — 読む資料と順序が決まっている。指示どおりに通読する
3. 01_環境準備_MCPとスキル.md — 接続設定。トークン入力の区分はユーザーと確認する
4. 00 の一覧どおり、保管庫の資料を通読する
5. ユーザーが 02_最終プロンプト_v2.md を貼り、実行を開始する

- 08 §6 に残るプロンプトは初版。最新版は本パッケージの 02 で、08 §6 冒頭に注記を追記済みである
- 件数などの実測値は 09_段階0_現状照合_20261029.md（10-29 実測）が最新。02 対応表（10-16時点の値が残る）と 01_実装状況_本番リポジトリ.md（10-21実測）の数値は、09 の値を優先して読む
