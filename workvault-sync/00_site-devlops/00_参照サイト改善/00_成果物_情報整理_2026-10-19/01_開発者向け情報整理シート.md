# 開発者向け情報整理シート

**このシートは正本ではない。** 既存の正本を尊重した、索引と確認・審査の入口である。
開発者が最初に開く1枚で、判断に必要な要点と根拠の場所を示す。詳細な原文・長い履歴は
リンク先の資料に任せる。新しい記載はまず「確認待ちの提案」として受ける（§H）。

- このシート内の ID（TG-・R-・REL-・IS-・UC-）は**文書内の管理ID**であり、アプリ・データの ID ではない
- 編集日（updated）と内容確認日（最終内容確認日）は別の値。内容を再点検しないまま日付だけ進めない

## H. 運用設計（情報追加から関連ページ更新まで）

```
情報追加・訂正案 → 根拠確認 → 同一性・関係・影響先の確認 → 人による承認
→ 正本への反映 → 関連ページへの反映 → 検証 → 履歴記録
```

**本設計は文書の設計であり、更新処理は実装しない。**「シートに追記すればページが更新される」では
ない。シートに追記できるのは「確認待ちの提案」までで、承認と反映は人が実施する。

## J. 保存・編集の安全条件とこのシートの扱い
