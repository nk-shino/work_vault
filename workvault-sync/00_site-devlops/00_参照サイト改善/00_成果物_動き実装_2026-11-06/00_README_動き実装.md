# README：動き実装（2026-11-06〜07）

## 何をしたか

運営者の指示は3つ。

1. 試作「動き最大活用」を優先し、「動き適用」から取れるものを取る。色の要素も考える
2. 試作「動き案B 遷移と幕」の、表示したときの動き（割れ扉）を原案に、**本に近づける**
3. 実装まで。点検ルールブックに従う

途中で運営者が方針を変えた。**「動作が保証されていて、素早い動作がするなら動きは付けていく」。**
これを確かめられる条件（保証の5条件・素早さの3条件と上限）に直して、`docs/project-rules.md` §9 に置いた。

## できたもの

| | 中身 |
|---|---|
| HOME の表紙 | 閉じた本が中央にあり、紋章が箔で押してある。表紙が背を軸に返り、見返し（深紅に箔の点）と扉頁の題が見え、HOME の題の位置へ寄って HOME になる。**このタブで最初の1回だけ**・1.32秒・押せば畳む。前の読み込み画面（毎回出て2秒あまり）を置き換えた |
| 全ページの見出し | 1字ずつ浮かび上がる。動き終わったら元の文字列に戻るので、検索・コピー・改行は変わらない |
| その他 | 画面の外の節の出現・押下の沈み・額の灯り・読んだ量の線・押した所から丸く開くページ遷移 |
| 付けなかったもの | ばねで追うカーソル・吸い付くボタン・スクロールの乗っ取り・ページを離れる前の幕・光り続ける字。理由は `ui-design-spec.md` §9 |

「本に近づける」は、割れ扉を**背のある1枚の表紙**に替えることで応えた。扉は扉であって本に見えない。
画面いっぱいの表紙を左端で返すと開いた表紙が画面の外へ出て見返しが見えないので、本は手に取れる大きさにした。
試作の金の縦帯は、背の金箔として残っている。

色はサイトの配色の決まり（語り部の赤×金）の中で収めた。表紙の布と見返しは、黒帯と同じくテーマの外側に置いている。
