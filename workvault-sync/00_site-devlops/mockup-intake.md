## 3. ユーザー向け受け入れテンプレート

既存文書（検査確認.md §3.2・手引き §9）を統合したテンプレート。
すべて必須ではなく、**必須（M）と任意（O）** を区別してある。
既存コード・既存資料から埋められる項目は根拠つきで先に埋めてある。
**権利・データの意味・ユーザーの意図は推測で埋めない**（空欄のまま残す）。

### 受け入れ票（コピーして使う）

```markdown
## 受け入れ票

- モックアップ名（M）:
- 版・日付（M）: 2026-10-16 版 / 更新:
- 対象ファイル（M）:
- 対象画面（M）:
- 目的・想定利用者（M）:
- 優先する操作（M）:
- 必ず再現する部分（M）:
- 参考扱い・変更可能な部分（M）:
- 基準の画面幅・デバイス・表示状態（M）: [既定: 1280px / 768px / 390px、ライトとダーク両方]
- 期待する操作と画面遷移（O）:
- データは実データか（M）: [サンプル / 実データ]
- 値の意味・型・単位・タイムゾーン・必須/任意（M）:
- 出典・公開/更新/確認日時（M）:
- 画像・文章・フォントの利用条件（M・画像があるときのみ）:
- 個人情報・秘密情報・公開前情報の有無（M）:
- 既存仕様と競合したときの判断者（M）: [既定: ユーザー]
- 完了条件（M）:
```

### 既知の情報だけで先に埋められる部分（提案値）

| 項目 | 先に埋めた値 | 根拠 |
|---|---|---|
| 基準の画面幅 | 1024px と 768px の2折返し（モックは390px も見本に含む） | 手引き §3 には無く、設計論点.md 前提4（1024/768）が正本。**モックの 390px 見本は参考扱い** |
| 出典の扱い | 「主張と根拠の対応表」の形を維持 | 手引き §2（sources）・§1 の優先1 |
| 検証状態の4区分 | 確認済／要補足／未検証／出典なし | 実行ログ_20261015 §4 の本家実測（分布の実測あり） |
| 画像の方針 | 空欄のまま。代用画像を作らない | 手引き §2 の素材方針（生成画像で代用しない） |
| 競合時の判断者 | ユーザー | 検査確認.md §3.2・開発方針.md §2 の承認境界 |

## 4. 取り扱い条件

| 条件 | 内容 |
|---|---|
| 保存先 | このノートとワークスペースのラウンドフォルダのみ。**公開ディレクトリ・サイトのコンテンツ読み込み対象には置かない**（検査確認.md §3.3） |
| fixture の識別 | 全ページに「モック（模擬データ）」の表記あり。**本番混入防止の前提条件として識別表記を必須とする**（§7） |
| 元ファイルの保護 | モックの元ファイルを加工結果で上書きしない。取り込み検証は写しで行う |
| 秘密情報 | モック内に秘密値・個人情報なし（静的調査で確認済）。新規に混入させない |
| 権利 | 模擬データの人物名・作品名は架空。ただし**本家サイトの固有名詞を使う権利確認は未着手**（取り込み時にユーザー確認が必要） |
