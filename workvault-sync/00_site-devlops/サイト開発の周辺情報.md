### 本番リポジトリ（16頁・実測 2026-10-21）

| 項目 | 内容 |
|---|---|
| 構成 | 静的HTML＋素のJavaScript＋fetch でJSON取得。ビルド工程なし・フレームワーク不使用 |
| TypeScript | 開発時のみ。src/*.ts → js/*.js に変換し、変換後の .js もリポジトリに置く |
| ライブラリ | 全て自前同梱・CDN 不使用（訪問者の IP を第三者へ渡さない） |
| テーマ | 明暗2種。CSS 変数＋localStorage。<head> の短いスクリプトで描画前に決定 |
| 画面数 | 16枚（入口1・下層14・404） |
