# エージェント設定_一括更新プロンプト

## プロンプト

```markdown
保管庫の `01_Templates/プロンプト/エージェント設定_一括更新プロンプト.md` を読み、「対象の一覧」に従ってエージェント設定の複製を正本に合わせて更新する。

1. 各組について正本と複製の差分を取る。差分ゼロの組は次へ進む
2. 差分がある組は内容を判断する。正本が新しいと確認できた組だけ複製を更新する。複製側に正本へ未反映の修正が見つかったら、上書きせず差分を利用者に示して指示を求める
3. 上書きの前に git status と git log を確認し、並行セッションの変更を消さない
4. プロンプトA埋め込み（対象4）は、frontmatter を除いた SKILL 本文をコードブロック内にそのまま差し替える。要約・言い換え・省略をしない
5. このPCに無い配布先（対象5・6）は直接更新できない。対応する控えを更新したうえで、利用者に手動手順を一行で伝える
6. 更新後、全組の差分を再確認し、結果を報告する。残った差分があれば理由を添える
7. 更新したファイルを実行ログ（指示1件＝エントリ1件）に記録する。保管庫側の変更は vault-sync スキルで GitHub へ反映する（利用者承認のあとに実行）

98_Pass（認証情報）を含むフォルダには触れない。保管庫のリポジトリは Private を維持する。
```

## 更新のしかた

- 端末・配置が変わったら、先にこのファイルの対象一覧を直してから使う
- 正本側を直した内容は、同日のうちにこの手順で複製へ反映する。反映を翌日に回すと、どちらが正しいか確認しづらくなる
- 2026-10-29 実測時点の乖離: プロンプトA埋め込みが旧版（質問台帳の項目なし・解決済みの未決事項が残存）、AGENTS.md 保管庫控えに 2026-10-26 の保管庫出力ルールがない、SKILL 保管庫控えの1行が PC 側より詳細（旧参照先の記録）。次回実行で解消する
