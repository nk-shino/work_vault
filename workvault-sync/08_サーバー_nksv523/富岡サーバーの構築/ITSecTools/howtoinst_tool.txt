■Ubuntu と Debian
================================================================================
①python、curl、gbgパッケージのインストール

sudo apt-get install python3
sudo apt-get install curl
sudo apt-get install libplist-utils

②セキュリティツールをtmpディレクトリに配置して解凍する
（以下作業はtmpディレクトリで行ってください　cd ../tmpで移動）
Unzip　WindowsDefenderATPOnboardingPackage.zip

<<WindowsDefenderATPOnboardingPackage.zip>>

③下記コマンドを順に実行してセキュリティツールのインストールを行う
1,curl -o microsoft.list https://packages.microsoft.com/config/ubuntu/18.04/prod.list
※/ubuntu/18.04/→ディストリビューションとバージョンは環境に合わせて変更をおねがいいたします。

2,sudo mv ./microsoft.list /etc/apt/sources.list.d/microsoft-prod.list
3,sudo apt-get install gpg
4,curl https://packages.microsoft.com/keys/microsoft.asc | sudo apt-key add -
5,sudo apt-get install apt-transport-https
6,sudo apt-get update
7,sudo apt-get install mdatp
8,cat /etc/apt/sources.list.d/*
9,sudo apt -t bionic install mdatp

10,python MicrosoftDefenderATPOnboardingLinuxServer.py
項番②でtmpディレクトリ配置後に解凍したMicrosoftDefenderATPOnboardingLinuxServer.pyが必要

11,完了後30分程度経過してから下記コマンドを実行して結果がすべてtrueであることを確認する
mdatp health --field healthy
mdatp health --field real_time_protection_enabled
mdatp health --field real_time_protection_enabled
