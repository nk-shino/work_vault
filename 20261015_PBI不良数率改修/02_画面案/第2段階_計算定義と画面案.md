### 1.1 用語と数式(対象2ページ共通)

| 項目 | 定義 | 検算値(全期間) |
|---|---|---|
| 検査数(分母) | 日報シートの B列「合計」= 良品判定C + 不良判定D | 243,586 |
| 良品数 | C列 | 227,598 |
| 不良数 | D列 = E〜O列(原因11種)の合計 | 15,988 |
| **虚報数** | Q列「虚報判定」(AOI不良のうちレビューで虚報と判定された数) | 14,933 |
| **NG数** | R列「不良判定2」(レビューでNGと判定された数) | 1,022 |
| **虚報率** | 虚報数 ÷ 検査数 × 100(小数3桁・ExcelのS列と同一定義) | 6.130% |
| **NG率** | NG数 ÷ 検査数 × 100(小数3桁・ExcelのT列と同一定義) | 0.420% |

**根拠**: Excel内の既存の率の計算式 `S列=ROUND(Q/B*100,3)`・`T列=ROUND(R/B*100,3)`。分母を検査数B列とする定義は日報運用と整合。

**未確定(質問2の回答待ち)**: Q列(虚報判定)とR列(不良判定2)の業務上の使い分け。実データでは `Q+R≠P(レビュー合計)` の行が2件あり(20261014・9000-064776_CN3276 R_010_0 と 20260903・9000-066063_TR1006AR_008_0)、Q/R列は完成していない仮区分の疑い。→ 内田さんへ確認する質問文案を§6に用意。

### 1.2 表示系の定義

- **パレートの軸**: 原因11種(E〜O列)。順位=件数降順・同件数は原因名(五十音)昇順・累積率=全期間の総不良数を分母にフィルター後の値で再計算
- **上位N・その他**: 行わない(全原因を表示。0件の原因も0本で表示し欠落させない)
- **検査数ゼロの行**: 表示しない(BLANK扱い。率は空白)
- **分母ゼロ・データなし**: 率カードに「0件」と出さず空白表示(0%と混同しないため)
- **部品/パッケージの区別**: A列は「図番_パッケージ_方向_面」の複合文字列。**パッケージ別に見る場合の軸はA列全体**(747ユニーク)を使う。パッケージ名部分だけの抽出(436ユニーク)は表記ゆれ(15パターン・17行)で正確に分割できないため、**第1版では採用しない**(質問4の回答待ち。必要なら分割規則を合意した上でPower Query側で列追加)

## 2. データ読み込み方針(新規たたき台)

```
ソース: 部品別(虚報).xlsx / 部品別(NG).xlsx  ← 元ファイルは変更しない
  ├─ フォルダ内の2ファイルを指定(相対パス不可→絶対パス)
  ├─ 日付シート(YYYYMMDD8桁)のみ読み取り(空のSheet1は除外)
  ├─ 各シート: 日付列を追加(シート名→日付型)・ヘッダ行を指定
  ├─ 型変換: B〜R列=整数型 / S,T列=小数(Excelの数式列は読み込まずDAXで再計算)
  └─ 縦持ち(1行=日付×パッケージ)のまま読み込み(横持ちE〜Oは表とグラフで展開)
```

- **E〜O原因列のグラフ化**: ビジュアルで「値=合計・カテゴリ=原因名」を素直に作るには縦持ち(原因列を行方向へ)が容易。ただし縦持ちにすると検査数(分母)が原因の数だけ重複する → **メジャー側で対処**(DIVIDE(虚報数, DISTINCTな検査数) 等)するか、**横持ちのまま「フィールドパラメータ」で11列を切り替え表示**する。→ **推奨: 横持ち+フィールドパラメータ**(分母重複の問題が起きない。§3の画面案A/Bはこの前提)
- 虚報とNGの2ファイルはA〜R列が完全一致(実測) → **1つのテーブルに読み込み、虚報数・NG数をメジャーで切替**可能。それでも2ファイルを読む設計にする場合は列の一致を毎回検証

## 3. 簡易画面案

### 共通

- 期間フィルター: 日付スライサー(範囲)。既定=全期間
- 集計カード: 検査数・虚報数・虚報率・NG数・NG率

### ページ「不良数」

```
┌─────────────────────────────────────────────────────┐
│ [日付スライサー 2026/09/01〜10/14]        [カード5枚] │
│  検査数 243,586 | 虚報数 14,933 | 虚報率 6.130%      │
│  | NG数 1,022 | NG率 0.420%                          │
├──────────────────────────┬──────────────────────────┤
│ ①折れ線: 日別の虚報数・NG数      │ ②積み上げ縦棒:         │
│   (日付が横軸・系列=虚報/NG)      │   日別の不良数を原因で積み上げ │
├──────────────────────────┴──────────────────────────┤
│ ③表(下部・既存のチャート下部を置き換える領域):        │
│  パッケージ名 | 検査数 | 虚報数 | 虚報率 | NG数 | NG率 │

```

### ページ「不良率」

```
┌─────────────────────────────────────────────────────┐
│ [日付スライサー]                          [カード5枚] │
├──────────────────────────┬──────────────────────────┤
│ ④縦棒+折れ線: パッケージ別の    │ ⑤パレート(原因別):      │
│   虚報率(棒)とNG率(棒)          │   原因11種の件数(棒)と    │
│   + 平均虚報率(折れ線)          │   累積率(折れ線・100%基準)│

│ ⑥表: パッケージ別の検査数・虚報率・NG率・原因別内訳   │
│  (虚報率降順・検査数≥100で絞るオプション付き)        │
└─────────────────────────────────────────────────────┘
```

- 「部品別(虚報)データへの置き換え」= ③⑥の表と②⑤のデータソースを実データに接続(既存ページでは日付表示になっている部分をパッケージ名軸に変更、という要件に相当)
