## 不採用・見送り（理由）

- **Lucide / Font Awesome / Google Fonts**: 外部配信への接続、または素材ファイルの追加が必要。外部リクエスト禁止の方針と依存追加は承認事項のため、今回入れない。
- **動画背景**（素材集 3-5）: 転送量と自動再生への配慮が、この規模の静的頁に見合わない。
- **View Transitions API**: 効果が小さく、ブラウザ差が大きい。次ラウンドで再評価する。
- **余白・角丸トークンへの全面置換**: 既存規則の書き換えが大きく、可逆性を損なう。R1 の枠に含めて次ラウンドへ。
- **本編モック（improve/mock）への展開**: 提案モックで形式を確めてからにする（バックログ）。

## 検証（2026-10-20 実施）

- 11頁一括: console 0 / pageerror 0 / 外部リクエスト 0。
- スキップリンク: Tab で出現し、Enter で本文へ移動。
- 読込中: 応答を遅延させて `aria-busy` と回転印を確認、完了で外れることを確認。
- 縮退: prefers-reduced-motion で全アニメ停止（[ANIM-1〜11]）。
