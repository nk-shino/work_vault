## 検出された findings

### F-1（ITA・中）: improve の人物頁から実在しない catalog.html へのリンク

  `href="works.html"` を出力するが mock/ に works.html は無い

足りていない領域（未実施。重要度順）:

1. データ間参照整合性 — works.json.characters → characters.json の ID 実在や catalog の ref ↔ 元データの突合を機械検査していない（ID の取り違えは表示が崩れにくく気づきにくい）。run-tests.js に追加可能

3. 履歴操作 — ブラウザ戻る/進む・リロードでの状態復元（catalog-b?q= の戻り）が未検証
4. アクセシビリティの定量測定 — 色彩コントラスト比（WCAG AA）の計測・axe-core 等の自動検査・スクリーンリーダ実機は未実施（ARIA 属性の構造確認のみ）
5. 人間による UAT — 自動シナリオは操作の再現で、使用感の判定は現場ユーザーの目が必要
6. CDN 障害時の mockup — Tailwind CDN が利用できない環境での見え方（フォールバック無し）を未確認
7. 中間ビューポートと印刷 — 390px と 1280px のみ。768px 等の中間幅・印刷様式は未確認
8. エンデュランス本番 — 26頁1回巡回のみ。長時間反復とメモリ使用の継続観測は未実施
9. サーバー設定由来の指摘の残置 — ディレクトリリスティングは本番サーバー設定で対処する事項として残置中
10. CI 組み込み — run-tests.js は手動実行。コミット時の自動実行は未設定
11. js 配下の UT — 描画関数（linksFor 等）は DOM 依存で Node 単体テスト不可。モジュール化が前提の設計改善課題
12. 実ネットワーク条件下の性能 — ローカル計測のみ。公開帯域・遅延での初期表示は未測定
