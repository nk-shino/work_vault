## 検出された findings

### F-1（ITA・中）: improve の人物頁から実在しない catalog.html へのリンク
- `improve/js/chara-b.js` と `improve/js/chara-c.js` が `href="catalog.html"` を出力する
- improve/ に catalog.html は無く、実クリックで HTTP 404 を確認済み
- 修正案: chara-b.js → `catalog-b.html`、chara-c.js → `catalog-c.html` に修正

### F-2（ITA・中）: mock の works.html / work-detail.html へのリンク
- `mock/catalog.html`・`chara.html`・`events.html`・`index.html`・`work-detail.html` が
  `href="works.html"` を出力するが mock/ に works.html は無い
- 修正案: 実在しない遷移先は `#`（リンク無しを明示）にするか、works 相当の頁を別途用意する
