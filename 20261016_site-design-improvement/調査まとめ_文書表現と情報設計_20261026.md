## 2. 現状の実測（提案の根拠となる実装状態）

- 日本語組版の設定は line-height 1.85（`mock/css/style.css:70`）のみ。word-break・overflow-wrap・line-break・text-wrap の指定は無い。
- 禁則処理は利用環境の既定（行頭の「、」「。」等は現状の実装で適切に処理）。表示領域マトリクス 21組合せで溢れ・不自然な折返しは未発生（2026-10-22・V-2 の列折返しのみ）。

- badge（確認済/要補足/未検証/出典なし）は色と文字ラベルの併記（G14 準拠）。
- 検証状態の定義 `const VERIFY = {...}` が js 3重複（catalog-a・catalog-c・chara-c）。
- 出典台帳 `data/sources.json` は14項・URL 未記録が9項・status は confirmed 8/supplement 2/none 2/unverified 2。作品側の `catalog.json` の verify は unverified 49/confirmed 1。両者で語彙と粒度が異なる。

## 4. 見送りとその理由

- hyphens: auto — 日本語本文では効果がなく、英字列は A-3 で対処。
- hanging-punctuation・text-autospace — 対応が1系統のみか草案段階。対応が広がった時点で再評価。
- line-break: strict・word-break: break-all の全面適用 — 既定の禁則処理で問題が未発生。全面適用は既存トーンを変える恐れがあるため不採用。
- WCAG 1.4.8（行長・行間の AAA 基準）— 対象外（AAA は任意基準。line-height 1.85 は既に実質充足）。
