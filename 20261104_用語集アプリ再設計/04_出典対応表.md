## 2. 不採用とした主な項目と理由

| 出典（参照リンク一覧の項目） | 項目 | 不採用の理由 |
|---|---|---|
| §1「Awwwards（animation）」・§2「GSAP Showcase」 | 読み込み幕・スクロール語り・華やかな遷移の実例群 | 業務ツールでは入力と読解を妨げる。§4 の前提（遷移 150〜300ms・待たせない）に反する |
| §1「Awwwards（animation）」・§5「Stripe」 | 漂い・常時運転の装飾・グラデーションの動くヒーロー | 情報密度の高い画面で視線を奪う。用語集は長時間の使用を前提とする |
| §7「GSAP SplitText」・§7「ICS MEDIA（1 文字ずつ変化するテキスト）」 | 1 文字ずつのテキストリビール | 見出し語は copy・検索・読み上げの対象。分割がアクセシビリティと選択に悪影響。**ICS MEDIA は All Rights Reserved のためコード転載不可**（参照リンク一覧 §7） |
| §6「Cursor Gallery」 | アニメーションカーソル | 業務でのポインタ精度を落とす・キーボード利用者に無意味 |
| §2「GSAP Showcase」・§8「Anime.js」 | ライブラリ同梱（GSAP・Anime.js・Motion 等） | 本設計の全パターンがネイティブ API で実装可能。同梱は容量と依存の増加だけで必要性を説明できない（NFR-002）。MIT のものでも同梱しない |
| §8「LottieFiles」 | Lottie アニメ | 依存（lottie-web）＋ライセンスの層構造（Simple License/プラン）の管理コストが効果を上回る |
| §8「React Bits」・§8「Aceternity UI」・§8「Magic UI」 | React 前提の装飾コンポーネント | 現行スタック（Jinja2＋素の JS）に不適合。**React Bits は Commons Clause（再配布・販売制限）**・Aceternity は Pro ライセンスのみ明記で利用条件が限定。流用しない |
| §7「Animate.css」 | 汎用 keyframes の一式導入 | **Hippocratic 2.1 は MIT ではない**（参照リンク一覧 §7）。個別の keyframes を自作するため同梱しない |
| §7「Hover.css」 | hover 効果 100 種の導入 | **商用は有料**（参照リンク一覧 §7）。業務利用にあたり許諾の確認が必要になるため使わない。必要な hover は CSS で自作 |
| §7「Animista」「uiverse.io」「CSSFX」 | 生成 CSS の取り込み | 手法は採用判断の参考に留め、コードは自作（出自の混入を避けるため）。uiverse/CSSFX は MIT だが、コピーの積み重ねは規律（§4 トークン）と矛盾する |
| §1〜§4 のショーケース全般 | 「動きで探せるギャラリー」の直接流用 | 業務ツールの動きは機能の変化に紐付くべきで、ショーケース的な演出の写しは目的に合わない |
