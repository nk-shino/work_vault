# README

作成日: 2026-10-15 ／ 作成: Kohden Code(AI)

## これは何

分析済み4つのExcelを1つの draw.io ファイル(5ページ)に可視化したもの。

| 対象 | 役割 |
|---|---|
| 0494-913473 実装プログラム手順(DGS)_P1.xls / _P2.xlsx | DGS実装プログラム手順書(表紙・変更履歴+本文34シート) |
| PanaCIM管理手順書_草案(会議中に手を加えたもの).xlsx | Pana-CIM 管理手順書 草案 版0.11(16シート・会議メモ入り) |
| LNB管理手順書_草案(会議中に手を加えたもの).xlsx | LNB 管理手順書 草案 版0.9(19シート) |

## ページ構成

| ページ | 内容 |
|---|---|
| Page1 | 4ファイルの全体構成と目的(役割・シート区分) |
| Page2 | 各シート内の内容構成(章・表・記録欄のまとまり) |
| Page3 | ファイル・シート・項目の関係(包含/実リンク/文字参照/矛盾を線種で区別) |
| Page4 | 書式・図形・印刷の構造(NR4030様式・図形統計・印刷設定の実測) |
| Page5 | 不整合・未確認事項(K-01〜K-14) |

## 閲覧方法

- draw.io で `分析済みExcel構造関係図.drawio` を開く(ページタブで切替)
- PNG画像は同梱の `p1.png`〜`p5.png`(全ページ目視検査済み)

## 根拠の制限(必読)

- 図の内容は **対象Excel内の記載・リンク・構造の実測** と、対象Excelに根拠をたどれる分析結果のみ
- 「実機確認済み」ではなく「Excel内に記載あり」の精度で記載
- 参照先(0494-912039(06)等)は「参照の記載がある」まで(参照先自体は未確認)
- DGS起動の認証情報は **マスク表記のみ**(値は転記しない)

## 関連ファイル

- `根拠_関係対応表.md`(evidence/): 図に載せた全要素のExcel上の所在(ID/セル/確認状態)+課題K-01〜K-14
- `excel_facts.json`(evidence/): 4ファイルの再実測データ(原本Read Onlyで取得)
- `品質検証レポート.md`: 検証項目・判定・修正サイクル記録
